# হাদিসের সারাংশ ("মূল কথা") — টেস্টের ধাপ

ব্রাঞ্চ `feature/ai-summarizer` · ডেমো ১ (অ্যাপের ধরন: কার্ডে অনুবাদের ওপরে বক্স, বিস্তারিত পেজে আলাদা কার্ড)

## চালানোর আগে
```bash
git checkout feature/ai-summarizer
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ নেই। নতুন অ্যাসেট `assets/demo/ai_summarizer/summaries.json`, তাই hot reload না, পুরো রিস্টার্ট দিন।
- অ্যাপের ভাষা বাংলা। নমুনা পয়েন্ট শুধু বাংলায় আছে।
- নমুনা আছে শুধু দুটো হাদিসে: সহীহ মুসলিম ১ (জিবরীলের হাদিস, প্রথম অধ্যায়) আর সহীহ মুসলিম ৪২২ ("পবিত্রতা ঈমানের অর্ধেক", পবিত্রতা অধ্যায়)। সহীহ বুখারী ১-এর পয়েন্ট `draft`, তাই দেখাবে না।
- সহীহ মুসলিম ডাউনলোড করা আর না-করা (অনলাইন) দুই অবস্থাতেই দেখুন।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| বই → সহীহ মুসলিম → অধ্যায় ১ → হাদিস ১-এর কার্ড | আরবির নিচে, বর্ণনাকারী আর অনুবাদের ওপরে হালকা সবুজ বক্স: ⓘ "মূল কথা", ৩টা বুলেট, নিচে ধূসর "এটা সারাংশ, মূল হাদিস পড়ুন" |
| কার্ডের ৩-ডট → "বিস্তারিত" | অনুচ্ছেদের নামের নিচে, হাদিস কার্ডের ওপরে আলাদা সাদা কার্ড: সবুজ শিরোনাম "মূল কথা", একই বুলেট আর লেখা। হাদিস কার্ডের ভেতরে বক্স আর থাকে না |
| পয়েন্ট নেই এমন হাদিস | বক্স নেই, কার্ড আগের মতো |

## ধাপগুলো
- [ ] সহীহ মুসলিম → অধ্যায় ১ → হাদিস ১: আরবির পরে "মূল কথা" বক্স, বুলেট: "ইসলাম, ঈমান আর ইহসান কী", "তাকদীরে বিশ্বাস ঈমানের অংশ", "কিয়ামতের কিছু আলামত"। নিচে "এটা সারাংশ, মূল হাদিস পড়ুন"। তারপর বর্ণনাকারী আর পুরো অনুবাদ।
- [ ] একই অধ্যায়ের অন্য হাদিস (২, ৩, ৫…): কোনো বক্স নেই, কার্ড আগের মতো।
- [ ] পবিত্রতা অধ্যায় → হাদিস ৪২২: বক্সে ৩টা পয়েন্ট ("পবিত্রতা ঈমানের অর্ধেক।" …)।
- [ ] সহীহ বুখারী → হাদিস ১: বক্স নেই (পয়েন্ট `draft`, যাচাই হয়নি)।
- [ ] হাদিস ১-এর ৩-ডট → "বিস্তারিত": হাদিস কার্ডের ওপরে "মূল কথা" কার্ড। হাদিস কার্ডের ভেতরে দ্বিতীয় বক্স নেই।
- [ ] বিস্তারিত পেজে সোয়াইপ করে হাদিস ২-এ যান: "মূল কথা" কার্ড নেই, ফাঁকা জায়গাও নেই।
- [ ] লিস্টে কার্ডে ট্যাপ করে বিস্তারিত খুললেও একই।
- [ ] ৩-ডট → "রিপোর্ট": আগের মতো রিপোর্ট শিট খোলে (পয়েন্টে ভুল জানানোর পথ এটাই)।
- [ ] ৩-ডট → শেয়ার (ছবি): ছবিতে "মূল কথা" বক্স নেই।
- [ ] সেটিংস থেকে অনুবাদের ফন্ট সাইজ বাড়ান/কমান: বক্সের লেখাও সাথে বাড়ে/কমে।
- [ ] সেটিংসে আরবি বন্ধ: বক্স হেডারের ঠিক নিচে, তারপর অনুবাদ।
- [ ] অ্যাপের ভাষা English (বা অন্য কোনো ভাষা): কোথাও বক্স নেই (নমুনা শুধু বাংলায়)।
- [ ] বিমান মোড, সহীহ মুসলিম ডাউনলোড করা: বক্স আগের মতোই আসে।
- [ ] বিষয়ভিত্তিক হাদিসের তালিকা, বুকমার্ক, ডেইলি হাদিস, হাদিস ফিড, সার্চ রেজাল্ট: কোথাও বক্স নেই।
- [ ] ডার্ক মোড: বক্সের রং, শিরোনাম (সবুজ) আর ধূসর লেখা পড়া যায়।
- [ ] ট্যাবলেট (পাশাপাশি লেআউট): বক্স বাঁ দিকের অনুবাদের কলামে, আরবির কলামে না। কিছু ভাঙে না।
- [ ] TalkBack/VoiceOver: বক্স এক জায়গা হিসেবে পড়ে, "মূল কথা", পয়েন্টগুলো আর মনে করানোর লেখা।

## অ্যানালিটিক্স (DebugView)
- `hadith_summary_view`: হাদিস প্যারাম (`book_id`, `book_slug`, `hadith_ref`, `chapter_id`, `content_source`), `scope` = `hadithList` / `hadithDetails`।
- একটা হাদিসের বক্স এক সেশনে প্রতি `scope`-এ একবারই যায়। স্ক্রল করে ফিরে এলে বা অধ্যায় আবার খুললে আবার যায় না। অ্যাপ বন্ধ করে খুললে আবার যাবে।
- লিস্ট পর্দার ঠিক বাইরের কয়েকটা কার্ডও আগেভাগে বানায়, তাই কার্ড পুরো পর্দায় আসার একটু আগেই ইভেন্ট যেতে পারে।
- পয়েন্টবিহীন হাদিস, শেয়ারের ছবি বা অন্য ভাষা থেকে কিছু যায় না। পয়েন্টের লেখা কোনো প্যারামে নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "মূল কথা (হাদিসের সারাংশ)" সেকশন।

## জানা সীমাবদ্ধতা
- পয়েন্টগুলো নমুনা, আলেমরা যাচাই করেননি। অ্যাপে "নমুনা" লেখা দেখায় না (ডেমো ১-এ ছিল না)। রিলিজের আগে আলেমদের দেখিয়ে নিতে হবে, নয়তো JSON থেকে সরাতে হবে।
- আসল ডেটা এলে শুধু `DemoHadithSummaryDataSource` বদলাতে হবে (`lib/core/di/modules/hadith/hadith_module.dart`-এ রেজিস্ট্রেশন)। আসল ডেটায় শুধু `review_status: verified` দেখাবে।
- কোন হাদিস "লম্বা", অ্যাপ মাপে না। যে হাদিসের পয়েন্ট ডেটায় আছে, সেটাতেই বক্স আসে।
- পয়েন্ট মেলে ভাষা + বই + হাদিসের id দিয়ে। অনলাইন আর ডাউনলোড করা বইয়ে একই id ধরে নেওয়া হয়েছে, দুটোতেই দেখে নিন।
- শুধু অধ্যায়ের হাদিস লিস্ট আর বিস্তারিত পেজে আসে, বিষয়ভিত্তিক তালিকায় না।
- বক্স লোড হওয়ার সময় বা লোড ব্যর্থ হলে কিছু দেখায় না, কার্ড আগের মতো থাকে।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
