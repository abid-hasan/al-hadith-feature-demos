# আরবি উচ্চারণ — টেস্টের ধাপ

ব্রাঞ্চ `feature/arabic-transliteration` · ডেমো ১ (অ্যাপের ধরন: পড়ার পেজের সেটিংস আইকন → ড্রয়ার, আরবির নিচে ইটালিক উচ্চারণ)

## চালানোর আগে
```bash
git checkout feature/arabic-transliteration
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ নেই। নতুন অ্যাসেট `assets/demo/arabic_transliteration/hadith_transliterations.json` (pubspec-এ যোগ করা)।
- ডেমো ডেটা আছে শুধু **সহীহ বুখারী**-র ৬টা হাদিসে: **১, ৩৭, ৩৮, ৪৮, ৬৯, ১০৬**। বাকি সব হাদিসে উচ্চারণ নেই, সেখানে কিছুই দেখাবে না।
- উচ্চারণ শুধু হাদিসের মূল বক্তব্যের (মতন), সনদের না। তাই আরবি লম্বা দেখালেও উচ্চারণ ছোট হবে, এটা স্বাভাবিক।
- অ্যাপের ভাষা বাংলা বা English রাখুন। বই ডাউনলোড থাকুক বা না থাকুক, দুটোতেই চলে (ডেটা অ্যাপের ভেতরে)।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| সেটিংস → কন্টেন্ট সেটিংস | "আরবি দেখান"-এর ঠিক নিচে নতুন সুইচ "আরবির উচ্চারণ দেখান", শুরুতে বন্ধ |
| পড়ার পেজ (অধ্যায়ের হাদিস তালিকা / হাদিস ডিটেইলস) → ওপরের সেটিংস আইকন → ড্রয়ার | একই সুইচ, একই জায়গায় |
| হাদিস কার্ড, "আরবি" ট্যাবে | আরবির ঠিক নিচে ইটালিক উচ্চারণ, তার নিচে বর্ণনাকারী আর অনুবাদ |
| "শব্দে শব্দে" ট্যাব | আগের মতো; শব্দের নিচের উচ্চারণ চলে "শব্দের উচ্চারণ দেখান" দিয়ে |

## ধাপগুলো
- [ ] নতুন ইনস্টল বা আগের ডেটা: সেটিংস → কন্টেন্ট সেটিংস → "আরবি দেখান"-এর নিচে "আরবির উচ্চারণ দেখান", বন্ধ।
- [ ] বুখারী → প্রথম অধ্যায় খুলুন। সুইচ বন্ধ থাকলে হাদিস ১-এ আরবির পরেই অনুবাদ (আগের মতো)।
- [ ] পড়ার পেজের সেটিংস আইকন → ড্রয়ারে সুইচ চালু → পেজ না ছেড়েই হাদিস ১-এ আরবির নিচে বাংলা হরফে উচ্চারণ ("ইন্নামাল আ'মালু বিন-নিয়্যাত…")। ইটালিক, অনুবাদের চেয়ে একটু ছোট, হালকা রঙের।
- [ ] যে হাদিসে উচ্চারণ নেই (যেমন বুখারী ২, ৩): আরবির পরেই অনুবাদ, কোনো ফাঁকা জায়গা বা লেবেল নেই।
- [ ] হাদিস ৩৭, ৩৮, ৪৮, ৬৯, ১০৬ খুলুন (অধ্যায় বা "হাদিসে যান" দিয়ে) → প্রতিটায় উচ্চারণ আসে।
- [ ] কার্ডে "শব্দে শব্দে" ট্যাব → পুরো হাদিসের উচ্চারণ নেই, শব্দের গ্রিড আগের মতো। "শব্দের উচ্চারণ দেখান" চালু/বন্ধ করলে শুধু শব্দের নিচের লাইন বদলায়, পুরো হাদিসের সুইচ বদলায় না। "আরবি" ট্যাবে ফিরলে উচ্চারণ আবার আসে।
- [ ] শব্দে ট্যাপ → "শব্দের বিস্তারিত" বটমশিটে উচ্চারণ আর অর্থ আগের মতো।
- [ ] কার্ডে ট্যাপ করে হাদিস ডিটেইলস → সেখানেও আরবির নিচে উচ্চারণ।
- [ ] "আরবি দেখান" বন্ধ → "আরবির উচ্চারণ দেখান" সুইচ লুকায়, কার্ডে আরবি আর উচ্চারণ দুটোই নেই। আবার চালু করলে সুইচ আগের অবস্থায় ফিরে আসে।
- [ ] ভাষা English → একই হাদিসে রোমান হরফে উচ্চারণ ("Innamal a'malu bin-niyyat…")।
- [ ] ভাষা আরবি, উর্দু বা অন্য কোনো ভাষা → সুইচ দেখায় না, কোনো কার্ডে উচ্চারণ নেই। বাংলায় ফিরলে আগের অবস্থা (চালু থাকলে উচ্চারণ) ফেরে।
- [ ] সুইচ চালু রেখে হাদিস ১-এর ⋮ → কপি (পুরো হাদিস) → কোথাও পেস্ট করুন: আরবি, তারপর উচ্চারণ, তারপর বর্ণনাকারী আর অনুবাদ। শুধু আরবি কপিতেও আরবির নিচে উচ্চারণ থাকে, শুধু অনুবাদ কপিতে থাকে না।
- [ ] একই হাদিস শেয়ার (লেখা হিসেবে) → উচ্চারণ সাথে যায়। সুইচ বন্ধ করে কপি/শেয়ার → উচ্চারণ নেই।
- [ ] ছবি হিসেবে শেয়ার (স্ক্রিনশট) → কার্ডে যা দেখা যায় তাই ছবিতে, উচ্চারণসহ।
- [ ] সোশ্যাল পোস্টার → কখনো উচ্চারণ দেখায় না (পোস্টারের নিজের লেআউট)।
- [ ] সার্চের রেজাল্ট, বুকমার্ক/কালেকশন, হাদিস ফিড: বুখারী ১ বা ৬৯ এলে সেখানেও আরবির নিচে উচ্চারণ (সুইচ চালু আর আরবি দেখানো থাকলে)।
- [ ] ফন্ট সাইজ বাড়ান/কমান → উচ্চারণের সাইজ অনুবাদের সাথে বাড়ে-কমে, লেখা কাটে না।
- [ ] ডার্ক মোড → উচ্চারণ পড়া যায়।
- [ ] ট্যাবলেট (পাশাপাশি লেআউট) → উচ্চারণ ডান দিকের আরবি কলামে, আরবির নিচে। লেআউট ভাঙে না।
- [ ] TalkBack/VoiceOver → উচ্চারণ "উচ্চারণ: …" পড়ে।
- [ ] অ্যাপ বন্ধ করে আবার খুলুন → সুইচের অবস্থা মনে থাকে।

## অ্যানালিটিক্স (DebugView)
- সুইচ চালু/বন্ধ → `setting_change{setting_name: show_arabic_transliteration, old_value, new_value, source}`; সেটিংস পেজে `source: settings_page`, পড়ার পেজের ড্রয়ারে `mini_drawer`।
- "শব্দের উচ্চারণ দেখান" আগের মতো `setting_name: show_transliteration`; একটা বদলালে অন্যটার ইভেন্ট আসে না।
- উচ্চারণ দেখানো বা কপি/শেয়ারে কোনো নতুন ইভেন্ট নেই; শেয়ারে আগের `share` ইভেন্ট।
- নতুন user property নেই (GA4-এর ২৫টার সীমা ভরা)।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "আরবি উচ্চারণ" সেকশন।

## জানা সীমাবদ্ধতা
- ডেমো উচ্চারণ আলেমদের যাচাই করা না। রিলিজের আগে যাচাই করাতে হবে, নইলে ডেমো ডেটা রিলিজ বিল্ডেও দেখাবে।
- শুধু বাংলা আর ইংরেজিতে চলে। অন্য ভাষায় সুইচই নেই।
- হাদিস ফিডের ড্রয়ারে সুইচ নেই; ফিড অ্যাপের মূল সেটিং মানে (মূল "আরবি দেখান" বন্ধ থাকলে ফিডেও উচ্চারণ নেই)।
- আসল ডেটা এলে শুধু `DemoArabicTransliterationDataSource` বদলাতে হবে (`lib/data/data_sources/arabic_transliteration_data_source.dart`)।
