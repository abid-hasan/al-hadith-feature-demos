# অটো রিজিউম — টেস্টের ধাপ

ব্রাঞ্চ `feature/auto-resume` · PR #257 · ডেমো ৩ (স্ক্রলে ছোট কার্ড)

## চালানোর আগে
```bash
git checkout feature/auto-resume
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ, পারমিশন বা `--dart-define` নেই। `pod install` লাগবে না।
- অ্যাপের ভাষা বাংলা রাখুন। পরে ইংরেজি, আরবি আর উর্দুতে বদলে দেখবেন।
- অন্তত একটা বই ডাউনলোড করা রাখুন। আরেকটা বই ডাউনলোড ছাড়া রাখুন (অনলাইনে পড়ার জন্য)।
- পুরোনো "সর্বশেষ" এন্ট্রি থাকলে রাখুন। পুরোনো এন্ট্রিতে প্রথম লাইন সেভ নেই, কার্ড সেটা বই থেকে খুঁজে আনে।

## কোথায় দেখবেন
| কী | কোথায় |
|---|---|
| রিজিউম কার্ড | হোমের "বই" ট্যাব, নিচে ভাসমান। অন্য ট্যাবে বা অন্য পেজের নিচে কার্ড থাকে না |
| পজিশন সেভ | যেকোনো অধ্যায়ের রিডার। বিষয়ভিত্তিক রিডারে পজিশন সেভ হয় না |
| আগের সব পড়া | কার্ডের "সব দেখুন", বা হোমের "সর্বশেষ" বাটন |
| পরীক্ষার হাদিস | ডাউনলোড করা বইয়ের কোনো লম্বা হাদিস, যেটা এক স্ক্রিনে আঁটে না |

## ধাপগুলো
- [ ] নতুন ইনস্টলে কিছু না পড়ে হোমে যান → কোনো কার্ড নেই।
- [ ] একটা লম্বা হাদিস খুলে মাঝামাঝি স্ক্রল করে থামুন, ব্যাক করে হোমে আসুন → নিচে "যেখানে ছেড়েছিলেন" কার্ড আসে।
- [ ] কার্ড দেখুন → বইয়ের ছয়কোনা ব্যাজ, "<বই>, হাদিস <নম্বর>", "অধ্যায়: <নাম>", হাদিসের প্রথম দুই লাইন, "চালিয়ে যান" বাটন।
- [ ] কার্ডের যেকোনো জায়গায় বা "চালিয়ে যান" ট্যাপ → সেই হাদিস খোলে, ঠিক থামার জায়গায়। হাদিসটা প্রায় ৩ সেকেন্ড হালকা হাইলাইট থাকে।
- [ ] রিডারে গিয়ে স্ক্রল করে থামুন, তারপর অ্যাপ ব্যাকগ্রাউন্ডে পাঠিয়ে বন্ধ করুন। আবার খুলুন → কার্ড নতুন জায়গা দেখায়।
- [ ] অন্য বইয়ের হাদিস পড়ে ফিরুন → কার্ড সবচেয়ে নতুন পড়াটা দেখায়।
- [ ] দ্রুত দুবার কার্ড ট্যাপ করুন → রিডার একবারই খোলে। খোলার সময় কার্ডের নিচে লোডিং বার দেখায়।
- [ ] হোম নিচে স্ক্রল করুন → কার্ড ছোট হয়ে এক লাইনে আসে (ব্যাজ, নাম-নম্বর, "চালিয়ে যান", ✕)। ওপরে স্ক্রল করলে বা একদম ওপরে গেলে আবার বড় হয়।
- [ ] হোমের একদম নিচে যান → শেষ আইটেম কার্ডের নিচে ঢাকা পড়ে না।
- [ ] "সব দেখুন" ট্যাপ → "সর্বশেষ" পেজ খোলে। সেখান থেকে কোনো এন্ট্রি খুললে সেটাও থামার জায়গায় খোলে, হাইলাইটসহ।
- [ ] "সর্বশেষ" পেজে সব এন্ট্রি ডিলিট করে ফিরুন → হোমে কার্ড চলে যায়।
- [ ] ✕ ট্যাপ → কার্ড সরে যায়। অন্য পেজ ঘুরে ফিরলে বা ভাষা বদলালেও এই সেশনে আর আসে না।
- [ ] অ্যাপ পুরো বন্ধ করে আবার খুলুন → কার্ড ফিরে আসে।
- [ ] অন্য বটম ট্যাবে যান → কার্ড নেই। "বই" ট্যাবে ফিরলে আবার আছে।
- [ ] বাংলায় পড়ে ভাষা ইংরেজি করুন → বাংলার কার্ড আর দেখায় না। ইংরেজিতে আগে না পড়লে কার্ড নেই।
- [ ] ইংরেজিতে পড়ে বাংলায় ফিরুন → বাংলার আগের কার্ডই আসে, বাংলা নিয়মে খোলে।
- [ ] ডাউনলোড ছাড়া বইয়ের হাদিস অনলাইনে পড়ে ফিরুন, তারপর ইন্টারনেট বন্ধ করে কার্ড ট্যাপ → টোস্ট "আপনার মোবাইলের ইন্টারনেট অন করা আছে কিনা দেখুন।" কার্ডের ওপরে দেখায়, ঢাকা পড়ে না।
- [ ] ইন্টারনেট বন্ধ রেখে ডাউনলোড করা বইয়ের কার্ড ট্যাপ → স্বাভাবিকভাবে খোলে।
- [ ] অনলাইনে হাদিসটা আর না পাওয়া গেলে → ডায়ালগ: বইয়ের নাম, "এই হাদিসের বইটি ডাউনলোড করা নেই। বইটি আগে ডাউনলোড করুন।", "বাতিল করুন" / "বই ডাউনলোড করুন"।
- [ ] ডায়ালগে "বই ডাউনলোড করুন" → ডাউনলোড ম্যানেজার বইটা আগে থেকে সিলেক্ট করে খোলে। ডাউনলোড শেষে পেজ বন্ধ হয়, হাদিস নিজে থেকে খোলে।
- [ ] কার্ড লোড করতে এরর হলে → এরর মেসেজ আর "আবার চেষ্টা করুন" বাটন।
- [ ] রিডিং প্ল্যানের হাদিস পড়ে ফিরুন → কার্ডে হাদিসের নিজের অধ্যায় দেখায়, অথবা অধ্যায়ের লাইন থাকে না।
- [ ] ডার্ক মোড → কার্ডের রং, শিরোনাম আর হাইলাইট ঠিক দেখায়।
- [ ] আরবি আর উর্দু → কার্ড ডান থেকে বাঁয়ে সাজানো, লেখা কাটা পড়ে না।
- [ ] ট্যাবলেট পোর্ট্রেট আর ল্যান্ডস্কেপ → কার্ড মাঝখানে সীমিত চওড়ায়, হোমের শেষ আইটেম ঢাকা পড়ে না।
- [ ] রিডারে স্ক্রিন ঘুরিয়ে পড়ে ফিরুন → কার্ড ট্যাপে একই হাদিসের একই অংশে যায়।
- [ ] বড় ফন্ট সাইজ → "চালিয়ে যান" আর নাম কাটা পড়ে না।
- [ ] TalkBack/VoiceOver → ✕ বাটন "কার্ড লুকান" পড়ে।
- [ ] সিস্টেমে "Remove animations" চালু → কার্ড আসা-যাওয়া আর ছোট-বড় হওয়া অ্যানিমেশন ছাড়া হয়।

## অ্যানালিটিক্স (DebugView)
- কার্ড দেখা গেলে `auto_resume_shown`। একই হাদিসে স্ক্রল বা ছোট-বড় হলে আবার আসে না।
- কার্ড বা "চালিয়ে যান" → `auto_resume_open`, তারপর `reader_open{entry_point: auto_resume}`। ডাউনলোড শেষে নিজে খুললে `auto_resume_open` দ্বিতীয়বার আসে না।
- "সব দেখুন" → `auto_resume_history_open`। ✕ → `auto_resume_dismiss`।
- চারটি ইভেন্টেই `book_id`, `book_slug`, `chapter_id`, `content_source` (`local` / `remote`, সেভ করা এন্ট্রির উৎস)। হাদিসের লেখা বা স্ক্রল পজিশন যায় না।
- ডায়ালগ থেকে ডাউনলোড ম্যানেজার → `download_manager_open{entry_point: auto_resume, preselected_count: 1}`।
- `hadith_read` এখন স্ক্রল ৩৫০ms থামলে, রিডার ছাড়লে বা ব্যাকগ্রাউন্ডে গেলে আসে। একই হাদিসে বারবার আসে না।
- চেকলিস্ট: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "## কালেকশন" সেকশনের প্রথম পাঁচটা বুলেট।
