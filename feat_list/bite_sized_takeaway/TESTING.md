# ছোট টেকঅ্যাওয়ে ("মূল শিক্ষা" বক্স) — টেস্টের ধাপ

ব্রাঞ্চ `feature/bite-sized-takeaway` · PR #258 · ডেমো ১ (অ্যাপের ধরন, `html/demo1.html`)

## চালানোর আগে
```bash
git checkout feature/bite-sized-takeaway
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন কোনো নেটিভ প্যাকেজ বা পারমিশন নেই, তাই `pod install` লাগবে না। `--dart-define` বা রিমোট কনফিগও নেই।
- অ্যাপের ভাষা **বাংলা** রাখুন। ডেমো ডেটা শুধু `bn`-এর জন্য, অন্য ভাষায় বক্স আসবেই না।
- "সহীহ মুসলিম" ডাউনলোড করে নিন (অফলাইন টেস্টের জন্য দরকার)।
- হাদিসে পৌঁছাতে: বইয়ের লিস্ট → "সহীহ মুসলিম" → প্রথম অধ্যায় → হাদিস নম্বর ১। অথবা "হাদিসে যান" দিয়ে সরাসরি।

## কোথায় দেখবেন
| কী | মান (`assets/demo/bite_sized_takeaway/takeaways.json`) |
|---|---|
| বই | সহীহ মুসলিম (`book_id: 2`) |
| হাদিস | `hadith_id: "1"` |
| ভাষা | `bn` |
| পয়েন্ট | ১. ইসলাম কী · ২. ঈমান কী · ৩. ইহসান কী |
| অবস্থা | `is_demo: true`, `verified: false` |

ডেটায় এই একটাই হাদিস আছে। "লম্বা হাদিস" মাপার কোনো লজিক নেই, ডেটায় থাকলেই বক্স আসে।

- [ ] অন্য বই (যেমন সহীহ বুখারী ১) → কোনো বক্স নেই।

**হাদিসের বিস্তারিত**

## অ্যানালিটিক্স (DebugView)
- ইভেন্ট: `hadith_takeaway_toggle`। শুধু শিরোনামে ট্যাপ করলে আসে। প্রথম render-এ, লিস্ট থেকে বিস্তারিতে একই অবস্থা দেখালে, বা "শিক্ষণীয় বিষয়" কার্ড থেকে আসে না।
- প্যারাম: `book_id: 2`, `book_slug`, `hadith_ref` (`2:<chapter_id>:1`), `chapter_id`, `content_source`, `content_language: bn`, `scope: hadithList` / `hadithDetails`, `expanded: true` / `false` (ট্যাপের পরের অবস্থা)।
- পয়েন্টের লেখা কোনো প্যারামে যায় না।
- চেকলিস্ট: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "## মূল শিক্ষা" সেকশন। ইভেন্টের সারি 02-এর "৩.৪.১ মূল শিক্ষা"-তে।

## জানা সীমাবদ্ধতা
- পয়েন্টগুলো ডেমো লেখা, আলেমদের যাচাই হয়নি। ডেটা অ্যাপের ভেতরের JSON থেকে আসে, আসল API/বইয়ের ডেটা এখনও নেই।
- ডেমো ডেটা শুধু বাংলায়। তাই আরবি/উর্দুর RTL বক্স বাস্তবে দেখা যাবে না।
- বক্স মেলে `ভাষা|book_id|hadith_id` দিয়ে। অনলাইন সোর্সের হাদিস আইডি "1" না হলে অনলাইনে বক্স না-ও আসতে পারে।
- গোটানো/খোলা অবস্থা শুধু মেমরিতে থাকে, অ্যাপ বন্ধ করলে মুছে যায়।
- লোডিং বা "মূল শিক্ষা লোড হয়নি। আবার চেষ্টা করুন।" শুধু বিস্তারিত পেজে আসে। ডেটা অ্যাপের ভেতর থেকে আসে বলে সাধারণত এটা দেখা যাবে না।
- PR অনুযায়ী এই ব্রাঞ্চে বিল্ড বা analyze আলাদা করে চালানো হয়নি।
