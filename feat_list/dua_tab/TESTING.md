# দোয়া — টেস্টের ধাপ

ব্রাঞ্চ `feature/dua-tab` · PR #262 · ডেমো ১ (`demo1.html`, "অ্যাপের ধরন")

## চালানোর আগে
```bash
git checkout feature/dua-tab
flutter pub get && flutter gen-l10n
(cd ios && pod install)   # নতুন প্যাকেজ just_audio (নেটিভ কোড আছে)
flutter run
```
- কোনো `--dart-define`, Remote Config বা নতুন পারমিশন লাগে না।
- অ্যাপের ভাষা বাংলা রাখুন। পরে ইংরেজিতেও দেখবেন।
- দোয়ার ডেটা অ্যাপের ভেতরেই আছে (`assets/dua/dua-bn.sqlite`, `dua-en.sqlite`)। কিছু নামাতে হবে না।
- অডিও আর হাদিস-লিংকের জন্য নেট লাগবে। লিংক অফলাইনে টেস্ট করতে আগে তিরমিযী বই ডাউনলোড করে রাখুন।

## ধাপগুলো
- [ ] হোম খুলুন → প্রথম সারি: সর্বশেষ, জাম্প, ওয়াক্ত, সাদাকা। দ্বিতীয় সারির শুরুতে "দোয়া" টাইল, নতুন আইকনসহ।
- [ ] "দোয়া" ট্যাপ → অ্যাপ বারে "দোয়া", ওপরে সার্চ বক্স ("সার্চ করুন"), নিচে ২০টা ক্যাটাগরি।
- [ ] তালিকা দেখুন → হেক্সাগনে ১ থেকে ২০ নম্বর, নিচে "৩ টি দোয়া" বা "৪ টি দোয়া"। শেষে "আরও দোয়া দেখুন দোয়া ও রুকিয়াহ অ্যাপে"।
- [ ] "সফর" ট্যাপ → অ্যাপ বারে "সফর", ৪টা কার্ড। প্রতিটায় শিরোনাম, কোণায় শোনার বাটন, আরবি, "উচ্চারণ", "অর্থ", "রেফারেন্স", নিচে "কপি | শেয়ার"।
- [ ] সেটিংসে আরবি ফন্ট, আরবি সাইজ আর অনুবাদের সাইজ বদলান → কার্ডে আরবি আর উচ্চারণ/অর্থের লেখা সাথে সাথে বদলায়।
- [ ] অনলাইনে শোনার বাটন ট্যাপ → ছোট স্পিনার, তারপর বাটন ভরা রঙে পজ আইকন, অডিও বাজে।
- [ ] বাজার সময় আবার ট্যাপ → থামে, প্লে আইকন ফেরে। পুরো শুনলে নিজে থেকেই প্লে আইকন ফেরে।
- [ ] একটা বাজার সময় আরেক কার্ডের বাটন → আগেরটা থামে, নতুনটা বাজে।
- [ ] "সকাল-সন্ধ্যার যিক্‌র"-এর দ্বিতীয় কার্ডে শোনা → বাজে। প্রথম কার্ডে → টোস্ট "এই দোয়ার অডিও এখনো যোগ হয়নি।"
- [ ] নেট বন্ধ করে শোনার বাটন → টোস্ট "ইন্টারনেট সংযোগ নেই। সংযোগ চালু করে আবার চেষ্টা করুন।"
- [ ] অডিও বাজার সময় Back → অডিও থামে, ক্যাটাগরির তালিকা আগের জায়গাতেই থাকে।
- [ ] "তিরমিযীঃ ৩৪৪৬" (আন্ডারলাইন করা) ট্যাপ → ওপরে পাতলা প্রগ্রেস বার, তারপর হাদিসের পেজে তিরমিযী ৩৪৪৬। "সহীহ।" অংশ লিংক নয়।
- [ ] বই না নামিয়ে অনলাইনে লিংক → তবু হাদিস খোলে। বই না নামিয়ে অফলাইনে → কারণসহ টোস্ট, পেজ খোলে না। বই নামানো থাকলে অফলাইনেও খোলে।
- [ ] "ঘুম"-এর তৃতীয় কার্ডে মুসলিমের লিংক → মুসলিম ৬৭৮০ খোলে।
- [ ] "কপি" → "কপি হয়েছে"। পেস্ট করলে শিরোনাম, আরবি, "উচ্চারণ: …", "অর্থ: …", "রেফারেন্স: …" আলাদা প্যারায়।
- [ ] "শেয়ার" → ফোনের শেয়ার মেনু, কপির মতো একই লেখা।
- [ ] সার্চে "আশ্রয়" লিখুন → "সার্চ রেজাল্ট", ডানে দোয়ার সংখ্যা, কার্ডের ওপরে ক্যাটাগরির চিপ।
- [ ] "যাকাত" লিখুন → "কোন সার্চ রেজাল্ট পাওয়া যায়নি"।
- [ ] "যিক্র" (হসন্তসহ) আর "যিক্‌র" → একই ফল (১৫টা দোয়া)। শিরোনামে মিল আগে, অর্থে মিল পরে আসে।
- [ ] সার্চের ফলে অডিও চালু রেখে লেখা বদলান → অডিও থামে।
- [ ] ✕ ট্যাপ → ক্যাটাগরির তালিকা ফেরে। পেজ বন্ধ করে আবার খুললে সার্চ বক্স খালি।
- [ ] ৪০ অক্ষরের বেশি লেখার চেষ্টা → বক্স ৪০-এ থেমে যায়।
- [ ] নিচের "আরও দোয়া দেখুন…" ট্যাপ → শিট: "আরও দোয়া", অ্যাপের আইকন আর নাম, বর্ণনা, "ডাউনলোড অ্যাপ"। ✕ দিয়ে বন্ধ হয়।
- [ ] "ডাউনলোড অ্যাপ" → Android-এ Play Store, iOS-এ App Store-এ দোয়া ও রুকিয়াহ অ্যাপ।
- [ ] ভাষা English → হোমে "Dua" টাইল থাকে। ক্যাটাগরি "Morning & Evening" দিয়ে শুরু। "Sleep"-এর তৃতীয় কার্ডে "Muslim 4/2083 no. 2711" → মুসলিম ২৭১১ খোলে। সার্চে "travel" → ৩টা ফল।
- [ ] ভাষা আরবি, উর্দু বা অন্য কোনো ভাষা → হোমে দোয়ার টাইল নেই।
- [ ] ডার্ক মোড → কার্ড, চিপ, শিট, সার্চ বক্স পড়া যায়, কোনো সাদা ব্লক নেই।
- [ ] ট্যাবলেট → লেখা মাঝে, সর্বোচ্চ ৬০০ চওড়া। ছোট ফোনে শিরোনাম বা বাটন কাটে না।
- [ ] TalkBack/VoiceOver → শোনার বাটন "শুনুন" / "থামান" পড়ে।

## অ্যানালিটিক্স (DebugView)
- হোমের টাইল → `home_quick_action{action: dua}`, তারপর `screen_view{screen_name: dua_categories}`।
- ক্যাটাগরি খোলা → `dua_category_open{dua_category_id}`, `screen_view{screen_name: dua_category}`।
- সার্চ থামার ১.২ সেকেন্ড পরে একবার → `dua_search{query_length, result_count}`। লেখা পাঠানো হয় না। বক্স মুছলে ইভেন্ট নেই।
- অডিও বাজা শুরু → `dua_audio_play{dua_id, dua_category_id, dua_list: category | search}`। থামা বা শেষের ইভেন্ট নেই।
- অডিও ব্যর্থ → `dua_audio_error{dua_id, reason: no_audio | offline | failed}`।
- কপি → `dua_copy{dua_id, dua_category_id, dua_list}`। শেয়ার → `share{content_type: dua, item_id: dua:<id>, method: system, dua_list}`।
- লিংক → `dua_reference_open{dua_id, book_id, book_slug, found}`। "তিরমিযীঃ ৩৪৪৬"-এ `book_id: 5, book_slug: tirmidhi`। খুললে `screen_view{screen_name: hadith_details}`।
- অ্যাপের লিংক → `dua_app_link{action: sheet_open}`, "ডাউনলোড অ্যাপ" → `dua_app_link{action: store_open}`। শিটের `screen_view` নেই।
- পুরো তালিকা: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "দোয়া" অংশ।

## জানা সীমাবদ্ধতা
- ডেটা দোয়া ও রুকিয়াহ ডেটাবেসের ছাঁটা কপি: ২০টা ক্যাটাগরি, ৬৪টা দোয়া। পুরো ডেটাবেস পরে বসবে।
- হাদিস-লিংক মাত্র ২০টা (`assets/dua/dua_hadith_links.json`)। বাকি রেফারেন্স শুধু লেখা।
- "যিকর" (হসন্ত ছাড়া) লিখলে কিছু পায় না। শুধু ZWNJ আর য়-এর দুই বানান মেলায়।
- অডিও শুধু অনলাইনে, ক্যাশ নেই। ব্যাকগ্রাউন্ড বা লক-স্ক্রিনে বাজানো যোগ হয়নি।
- হাদিসের পেজে শুধু হাদিস কার্ড, অধ্যায়/সেকশনের কার্ড নেই।
- দোয়ার ডেটাবেস `BundledAssetDatabaseVersions`-এ নেই। নিজের ভার্সন `DuaAssetDataSource.databaseVersion = 1`; ফাইল বদলালে এটা বাড়াতে হবে।
- ফোন বা সিমুলেটরে এখনো চালানো হয়নি। iOS-এ `pod install` বাকি ছিল।
