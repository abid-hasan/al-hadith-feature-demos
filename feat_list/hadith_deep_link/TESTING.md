# হাদিস ডিপ লিংক — টেস্টের ধাপ

ব্রাঞ্চ `feature/deep-link` · PR #260 · ডেমো নেই (ডেমো ১–৫-এর "লিংক শেয়ার"/"লিংক কপি" মেনু এই ব্রাঞ্চে আসেনি; শুধু শেয়ারের লেখায় লিংক আর লিংক থেকে অ্যাপ খোলা)

## চালানোর আগে
```bash
git checkout feature/deep-link
flutter pub get && flutter gen-l10n
(cd ios && pod install)   # নতুন প্যাকেজ app_links-এর নেটিভ কোড আছে
flutter run
```
- অ্যাপের ভাষা বাংলা রাখুন। পরে ইংরেজি, আরবি, উর্দুতেও একবার দেখবেন।
- একটা বই ডাউনলোড রাখুন (যেমন সহীহ বুখারী), আরেকটা ডাউনলোড ছাড়া রাখুন।
- লিংকের আকার: `https://ihadis-link.web.app/<book-slug>/<number>`। শুধু `https`, শুধু এই host, ঠিক দুইটা path অংশ। slug-এ শুধু ছোট হাতের ইংরেজি অক্ষর, সংখ্যা আর `-`। শেষে `?lang=..` থাকলেও অ্যাপ সেটা দেখে না।
- লিংক সাইট এখনো ডিপ্লয় হয়নি (PR-এ বলা; `https://ihadis-link.web.app/.well-known/assetlinks.json` আর `apple-app-site-association` এখন 404)। তাই ফোন নিজে থেকে লিংকটা অ্যাপে পাঠাবে না। নিচের কমান্ড দিয়ে চালান।

**Android** (প্যাকেজের নাম শেষে দিলে verify ছাড়াই অ্যাপে যায়):
```bash
adb shell am start -a android.intent.action.VIEW -d 'https://ihadis-link.web.app/bukhari/10' com.ihadis.ihadis
```
- প্যাকেজ ছাড়া চালাতে চাইলে আগে একবার: `adb shell pm set-app-links-user-selection --user cur --package com.ihadis.ihadis true ihadis-link.web.app`। তারপর চলে `adb shell am start -a android.intent.action.VIEW -d '<url>'`, আর অন্য অ্যাপে লিংক ট্যাপ করলেও অ্যাপ খোলে।
- debug বিল্ডের সাইনিং `assetlinks.json`-এর fingerprint-এ নেই। সাইট ডিপ্লয়ের পরেও আসল verify শুধু release/Play বিল্ডে দেখা যাবে।

**iOS সিমুলেটর:**
```bash
xcrun simctl openurl booted 'https://ihadis-link.web.app/bukhari/10'
```
- Universal Link শুধু AASA লাইভ হলে কাজ করে। এখন এটা Safari-তে খুলবে (404)। কোনো custom scheme নেই, কোড শুধু `https` + এই host নেয়। তাই iOS-এ অ্যাপ খোলা সাইট ডিপ্লয়ের আগে টেস্ট করা যাবে না।

## কোথায় দেখবেন
| লিংক | কী হওয়ার কথা |
|---|---|
| `/bukhari/10` | সহীহ বুখারী, হাদিস ১০ খোলে |
| `/abu-dawud/1` | সুনানে আবূ দাউদ (slug-এ `-`) |
| `/muslim/1` (বই ডাউনলোড ছাড়া, অনলাইন) | ইন্টারনেট থেকে এনে খোলে |
| `/bukhari/999999`, `/xyz/1` | "হাদিস খুঁজে পাওয়া যায়নি" |
| `/bukhari`, `/bukhari/10/x`, `/Bukhari/10`, `/bukhari/0`, অন্য host | কিছুই হয় না, শুধু অ্যাপ খোলে |

## ধাপগুলো
- [ ] কোনো হাদিসের মেনু → "টেক্সট শেয়ার" → লেখার শেষে "সোর্স: আল হাদিস অ্যাপ, …" লাইনের নিচে `https://ihadis-link.web.app/bukhari/<নম্বর>` আছে।
- [ ] বাংলায় লিংকের শেষে `?lang=` নেই। ইংরেজি/ইন্দোনেশিয়ান/আরবি/উর্দুতে শেষে `?lang=en` / `id` / `ar` / `ur`। অন্য ভাষায় কিছু নেই।
- [ ] "অনুবাদ কপি", "আরবি কপি", "হাদিস কপি" → কপি করা লেখার শেষেও একই লিংক আছে।
- [ ] যে হাদিসের নম্বর `১৫২২-[১]`-এর মতো → লিংকে শুধু `1522`। ছাপা নম্বর না থাকলে hadith id বসে। সেটাও কাজের না হলে (surrogate id) লিংকের লাইনই নেই।
- [ ] অ্যাপ পুরো বন্ধ → Android কমান্ড `/bukhari/10` → অ্যাপ খোলে, হোম আসার পর রিডারে বুখারীর হাদিস ১০-এ যায়।
- [ ] অ্যাপ background-এ, অন্য স্ক্রিনে → একই কমান্ড → রিডার ওই হাদিসে খোলে।
- [ ] রিডার থেকে ব্যাক → হোমে আসে, অ্যাপ বন্ধ হয় না।
- [ ] ডাউনলোড ছাড়া বই, অনলাইনে → `/muslim/1` → হাদিসটা খোলে।
- [ ] একই লিংক অফলাইনে, বই ডাউনলোড ছাড়া → "হাদিস খুঁজে পাওয়া যায়নি" টোস্ট, রিডার খোলে না, ক্র্যাশ নেই।
- [ ] `/bukhari/999999` আর `/xyz/1` → একই টোস্ট।
- [ ] টেবিলের ভুল আকারের লিংকগুলো → অ্যাপ খোলে, কোনো মেসেজ বা রিডার নেই।
- [ ] অ্যাপের ভাষা আরবি → `/bukhari/10` → ছাপা নম্বর ১০-এর হাদিসই খোলে (আরবি বুখারীর id আর নম্বর আলাদা, তবু ঠিকটা আসে)।
- [ ] উর্দু (RTL) → লিংক খুলে রিডার ঠিকমতো আসে।
- [ ] নতুন ইনস্টল, অনবোর্ডিং চলাকালীন লিংক → অনবোর্ডিং শেষে হোম আসার পর হাদিস খোলে।
- [ ] ডার্ক মোডে লিংক খুলে রিডার আর টোস্ট স্বাভাবিক দেখায়।
- [ ] ট্যাবলেটে একবার লিংক খুলে দেখুন রিডার ঠিক আছে।
- [ ] সাইট ডিপ্লয়ের পর: অ্যাপ ছাড়া ফোনে লিংক → Play Store / App Store। কম্পিউটারে → `https://ihadis.com/bukhari/hadith/10` (ভাষা থাকলে `/en/...` ইত্যাদি)।

## অ্যানালিটিক্স (DebugView)
- লিংক থেকে হাদিস পেলে: `hadith_link_open{book_slug: bukhari, outcome: opened}`, তারপর `reader_open{entry_point: deep_link}`।
- না পেলে (ভুল বই/নম্বর, অফলাইন): `hadith_link_open{book_slug: <লিংকের slug>, outcome: not_found}`, `reader_open` নেই।
- লিংকের আকারই ভুল হলে কোনো ইভেন্ট নেই।
- চেকলিস্ট: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md` → "শেয়ার করা হাদিস লিংক" সেকশন।

## জানা সীমাবদ্ধতা
- `link_site/` (assetlinks, AASA, index.html) ডিপ্লয় হয়নি, হোস্টিং কনফিগও নেই। তাই আসল App Links / Universal Links এখন কাজ করে না।
- iOS-এ entitlement `applinks:ihadis-link.web.app` যোগ হয়েছে। Apple Developer-এ App ID-তে Associated Domains চালু আছে কি না PR-এ বলা নেই।
- রিকোয়ারমেন্টের "লিংক শেয়ার"/"লিংক কপি" বাটন, অফলাইন মেসেজের "ডাউনলোডে যান" বাটন এই ব্রাঞ্চে নেই। না পেলে শুধু টোস্ট।
- লিংক বইয়ের slug আর ছাপা নম্বর দিয়ে বানানো, অ্যাপের নিজের id দিয়ে না। ওয়েবসাইটের নম্বর আর অ্যাপের নম্বর আলাদা হলে ভুল হাদিসে যেতে পারে।
- PR অনুযায়ী এই ব্রাঞ্চের বিল্ড বা analyze আলাদা করে চালানো হয়নি।
