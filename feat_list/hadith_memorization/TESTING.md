# হাদিস মুখস্থ কোর্স — টেস্টের ধাপ

ব্রাঞ্চ `feature/hadith-memorization` · ডেমো ১ (অ্যাপের ধরন: সাধারণ অ্যাপ বারের পেজ, কার্ড আর লিস্টের সারি)

## চালানোর আগে
```bash
git checkout feature/hadith-memorization
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন কোনো প্যাকেজ নেই। নতুন অ্যাসেট `assets/demo/hadith_memorization/memorization_courses_bn.json` আর হোমের আইকন `ic_home_memorization.svg`।
- অ্যাপের ভাষা বাংলা রাখুন। শর্টকাট শুধু বাংলায় দেখায়, কারণ ডেমো কোর্স শুধু বাংলায় আছে।
- কোর্সের হাদিস সব সহীহ বুখারী থেকে (১, ৯, ১০, ১৩, ২৪, ৬৯, ৫০২৭, ৬০১৩, ৬০২১, ৬১১৪, ৬১১৬, ৬১৩৩, ৬১৩৬, ৬৪৬৪)। প্রথমবার নেট চালু রাখুন, অথবা বুখারী (বাংলা) ডাউনলোড করে রাখুন।
- অগ্রগতি, কুইজের ফল আর সার্টিফিকেটের নাম শুধু ফোনে থাকে (Hive)। নতুন করে দেখতে অ্যাপ মুছে আবার ইনস্টল করুন।
- সার্টিফিকেট সেভ করতে গ্যালারির অনুমতি লাগবে (অ্যাপে আগে থেকে থাকা `gal` প্যাকেজ)।

|---|---|

| কোর্সের তালিকা | "১০ হাদিস" আর "৪ হাদিস: নিজেকে গড়া" কার্ড: হাদিস আর পাঠের সংখ্যা, "০/১০ মুখস্থ", অগ্রগতির বার |
| কোর্সের পেজ | বড় সংখ্যা "/ ১০টি হাদিস মুখস্থ", বার, "০টি পাঠ শেষ, ৫টি বাকি", "শুরু করুন: পাঠ ১"; "পাঠ" লিস্ট; "কোর্সের শেষে" কুইজের সারি |
| পাঠের পেজ | "২টি হাদিস", পাঠের নাম, অ্যাপের সাধারণ হাদিস কার্ড; নিচে "নিজে পরীক্ষা দিন" |
| নিজে পরীক্ষা | টিপস, কার্ডে অনুবাদের কিছু অংশ ঢাকা, "সব খুলুন", নিচে "আবার পড়ব" / "মনে ছিল" |
| কুইজ | "প্রশ্ন ১/৫", "সঠিক: ০", অপশন কার্ড, "পরের প্রশ্ন" / "ফলাফল দেখুন" |
| সার্টিফিকেট | নাম, কোর্স, হাদিসের সংখ্যা, তারিখ আর "আল হাদিস"; "নাম লিখুন / নাম বদলান"; "সেভ করুন" / "শেয়ার করুন" |

## ধাপগুলো
- [ ] হোমে "হাদিস মুখস্থ" বাটনে লাল ডট। ট্যাপ → কোর্সের তালিকা, ডট চলে যায়, অ্যাপ বন্ধ করে খুললেও আর আসে না।
- [ ] অ্যাপের ভাষা English (বা অন্য যেকোনো) → হোমে বাটনটাই নেই।
- [ ] তালিকায় দুটো কোর্স কার্ড, প্রতিটায় "০/N মুখস্থ" আর খালি বার।
- [ ] "১০ হাদিস" → কোর্সের পেজ। পাঠ ১-এ "পরের পাঠ" ট্যাগ, পাঠ ২–৫ ঝাপসা আর তালা। তালা দেওয়া পাঠে ট্যাপ → "আগের পাঠগুলো শেষ হলে এই পাঠ খুলবে"।
- [ ] কুইজের সারি ঝাপসা আর তালা। ট্যাপ → "সব পাঠ শেষ হলে কুইজ খুলবে"।
- [ ] "শুরু করুন: পাঠ ১" → পাঠের পেজে প্রথমে স্কেলিটন, তারপর বুখারী ১ আর ৯ নম্বর হাদিস। আরবি দেখায় সেটিং মেনে (সেটিংসে আরবি বন্ধ করলে এখানেও বন্ধ)। বুকমার্ক, পিন, ⋮ মেনু আর গ্রেড চিপ আগের মতো কাজ করে।
- [ ] "নিজে পরীক্ষা দিন" → অনুবাদে কয়েকটা জায়গা হালকা সবুজ ঘরে ঢাকা (যেমন "নিয়ত অনুযায়ী", "প্রতিফল পাবে")। ঢাকা ঘরে ট্যাপ → লেখা সবুজে দেখায়।
- [ ] "সব খুলুন" → সব ঢাকা অংশ একসাথে খোলে।
- [ ] "আবার পড়ব" → কোর্সের পেজে ফেরে, মেসেজ "পাঠটা বাকি রইল, পরে আবার পড়ুন", পাঠ ১-এ "আবার পড়ুন" ট্যাগ। বাটন এখন "চালিয়ে যান: পাঠ ১"।
- [ ] আবার পাঠ ১ → নিজে পরীক্ষা → "মনে ছিল" → মেসেজ "পাঠ ১ শেষ · ২টি হাদিস মুখস্থ"। পাঠ ১-এ সবুজ চেক আর "মুখস্থ হয়েছে", পাঠ ২ খুলে যায়, ওপরে "২ / ১০টি হাদিস মুখস্থ"।
- [ ] Back করে তালিকায় → কার্ডে "২/১০ মুখস্থ" আর বার একটু ভরা।
- [ ] অ্যাপ পুরো বন্ধ করে আবার খুলুন → অগ্রগতি থেকে যায়, বাটন "চালিয়ে যান: পাঠ ২"।
- [ ] মুখস্থ হওয়া পাঠ ১ আবার খুলে "আবার পড়ব" → পাঠটা মুখস্থই থাকে, কোনো মেসেজ নেই।
- [ ] পাঠ ২–৫ শেষ করুন → ওপরের বাটন "কোর্সের কুইজ দিন", কুইজের সারিতে "খোলা"।
- [ ] কুইজ: অপশনে ট্যাপ করলেই ঠিক উত্তর সবুজ, ভুল বাছলে সেটা লাল। উত্তর না দিলে "পরের প্রশ্ন" বন্ধ। সেগমেন্টের বার প্রতি উত্তরে রং পায়, "সঠিক: n" বাড়ে।
- [ ] ইচ্ছে করে ২টা ভুল করুন (৫টায় ৩টা সঠিক) → "৫টির মধ্যে ৩টি সঠিক", "পাস করতে ৪টি সঠিক উত্তর লাগবে…", "আবার চেষ্টা করুন" → প্রথম প্রশ্ন থেকে আবার।
- [ ] ৪টা বা বেশি সঠিক → "অভিনন্দন! আপনি কুইজে পাস করেছেন।" → "সার্টিফিকেট দেখুন" → সার্টিফিকেট পেজ। Back → সরাসরি কোর্সের পেজ, সেখানে "সার্টিফিকেট" সারি।
- [ ] সার্টিফিকেটে নামের জায়গায় "—", নিচে "নাম লিখুন"। "সেভ করুন" চাপলে আগে নামের ডায়ালগ; "বাতিল করুন" দিলে কিছু হয় না।
- [ ] নাম লিখে "সেভ করুন" → সার্টিফিকেটে নাম আসে, গ্যালারির অনুমতি চায় (প্রথমবার), তারপর "সার্টিফিকেট ছবি হিসেবে গ্যালারিতে সেভ হয়েছে"। গ্যালারিতে ছবিটা দেখুন: পুরো কার্ড, কাটা নেই।
- [ ] অনুমতি না দিলে → "সার্টিফিকেট সেভ করা যায়নি"।
- [ ] "শেয়ার করুন" → ফোনের শেয়ার মেনুতে সার্টিফিকেটের ছবি।
- [ ] "নাম বদলান" → ডায়ালগে আগের নাম, বদলালে সার্টিফিকেটে নতুন নাম। নাম ৪০ অক্ষরের বেশি লেখা যায় না।
- [ ] তারিখ হলো প্রথম পাসের দিন। পরে আবার কুইজ দিলে তারিখ বদলায় না।
- [ ] "৪ হাদিস: নিজেকে গড়া" কোর্সেও একই পথ (২টা পাঠ, ৩ প্রশ্ন, পাস ২)। এক কোর্সের অগ্রগতি অন্যটায় যায় না।
- [ ] বুখারী ডাউনলোড নেই আর বিমান মোড → এখনো না খোলা কোনো পাঠ → "বইটি ডাউনলোড করুন" আর "ডাউনলোডে যান"। ডাউনলোড পেজে বুখারী আগে থেকে বাছা; নামানো শেষে পাঠ নিজে লোড হয়।
- [ ] একবার অনলাইনে খোলা পাঠ বিমান মোডে আবার খুলুন → হাদিস দেখায় (ক্যাশ থেকে)।
- [ ] ডার্ক মোড: কার্ড, ট্যাগ, ঢাকা অংশ, কুইজের অপশন আর সার্টিফিকেট পড়া যায়।
- [ ] ট্যাবলেট: পেজগুলো মাঝখানে ৬০০-এর মধ্যে, কিছু ভাঙে না।
- [ ] TalkBack/VoiceOver: পাঠের সারি এক জিনিস হিসেবে পড়ে (নাম, সংখ্যা, অবস্থা); ঢাকা অংশ "লুকানো অংশ, ট্যাপ করে দেখুন" পড়ে।

## অ্যানালিটিক্স (DebugView)
- হোমের বাটন → `home_quick_action{action: memorization}`, তারপর `screen_view{memorization_courses}`।
- স্ক্রিন: `memorization_course`, `memorization_lesson`, `memorization_self_test`, `memorization_quiz`, `memorization_certificate`।
- "মনে ছিল" / "আবার পড়ব" → `memorization_lesson_result{course_id, lesson_index (0 থেকে), outcome: remembered / read_again, hidden_count, revealed_count}`।
- কুইজ শেষ → `memorization_quiz_complete{course_id, correct_count, question_count, passed}`।
- সার্টিফিকেট → `memorization_certificate_action{course_id, action: save / share}`। নামের ডায়ালগ বাতিল করলে কিছু যায় না।
- বই নেই আর অফলাইন → `content_unavailable{reason: book_not_downloaded, screen_name: memorization_lesson}`; "ডাউনলোডে যান" → `download_manager_open{entry_point: memorization_missing}`।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "হাদিস মুখস্থ কোর্স" সেকশন।

## জানা সীমাবদ্ধতা
- কোর্স, পাঠের নাম, কোন অংশ ঢাকা থাকবে আর কুইজের প্রশ্ন সব ডেমো ডেটা। আলেমরা আসল ডেটা দিলে `DemoAssetHadithMemorizationDataSource` বদলাতে হবে (`HadithMemorizationModule`-এ এক লাইন)।
- ঢাকা অংশ খোঁজা হয় বইয়ের অনুবাদের লেখায়। লেখা বদলে গেলে বা না মিললে অ্যাপ নিজে প্রতি চতুর্থ শব্দ ঢাকে।
- অডিও নেই: ডেটায় `audio_url` রাখার জায়গা আছে, কিন্তু প্লেয়ার বানানো হয়নি, তাই শোনার বাটন দেখায় না।
- শুধু অনুবাদ ঢাকা হয়, আরবি না।
- পাঠ খোলে ক্রমে: আগের সব পাঠ "মনে ছিল" হলে পরেরটা।
- সার্টিফিকেট ফোনেই বানানো ছবি, কোনো সার্ভার থেকে যাচাই হয় না। নাম ইউজার নিজে লেখে, অ্যাকাউন্ট থেকে আসে না। অগ্রগতি সিঙ্ক হয় না।
- ডার্ক মোডে সার্টিফিকেটের ছবিও ডার্ক রঙে সেভ হয়।
- কুইজ মাঝপথে ছাড়লে শুরু থেকে আবার; বিরতি বা চালিয়ে যাওয়া নেই।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
