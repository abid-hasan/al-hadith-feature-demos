# হুকম / গ্রেড ট্যাগ — টেস্টের ধাপ

ব্রাঞ্চ `feature/hukm-grade-tag` · PR #261 · ডেমো ১ (অ্যাপের গ্রেড ডায়ালগ, পছন্দের স্ক্রিন "সহিহ · মতসহ")

## চালানোর আগে
```bash
git checkout feature/hukm-grade-tag
flutter pub get && flutter gen-l10n
flutter run            # debug: ডেমো মত দেখায়
flutter run --release  # রিলিজ: ডেমো মত দেখায় না (শেষের ধাপগুলো)
```
- নতুন প্যাকেজ বা পারমিশন নেই, `pod install` লাগবে না।
- অ্যাপের ভাষা বাংলা রাখুন। ডেমো মত শুধু `bn`-এ আছে, আর ভাষা নেওয়া হয় অ্যাপের বাছাই করা ভাষা থেকে।
- নিচের ৪টা বই ডাউনলোড করে রাখুন। হাদিসে যেতে হোমের "জাম্প" ডায়ালগে বই আর নম্বর দিন।
- মত পড়া হয় বান্ডেল করা JSON থেকে, তাই ইন্টারনেট লাগে না।

## ধাপগুলো
- [ ] বুখারী ১-এর "সহিহ হাদিস" ব্যাজে ট্যাপ → ডায়ালগে ছবি, নাম, অর্থ। অর্থ ৪ লাইনের বেশি হলে কাটা, নিচে "আরো পড়ুন"।
- [ ] একই ডায়ালগে "তাহকিক" শিরোনাম, ২টা সারি: বৃত্তে ১/২, নাম বোল্ড, বইয়ের আইকনসহ কিতাব, ডানে সবুজ "সহিহ হাদিস" ব্যাজ।
- [ ] তার নিচে শিল্ড আইকনসহ "আলেমদের যাচাই করা তথ্য"। "কেন দুর্বল" বক্স নেই।
- [ ] একদম নিচে "সব মান দেখুন" (টেক্সট বাটন) আর "ঠিক আছে"।
- [ ] "আরো পড়ুন" ট্যাপ → পুরো অর্থ খোলে, বাটন চলে যায়। অর্থ ছোট হলে বাটন আসেই না।
- [ ] "সব মান দেখুন" → ডায়ালগ বন্ধ, "তাহকিক" পেজ খোলে, "সহিহ হাদিস" সারি খোলা আর স্ক্রল করে সামনে আনা। ব্যাক দিলে আগের পেজে ফেরে।
- [ ] "ঠিক আছে" বা বাইরে ট্যাপ → শুধু ডায়ালগ বন্ধ, কোথাও যায় না।
- [ ] তিরমিযী ১০ → ৩টা লাল-কমলা ব্যাজ, নিচে "কেন দুর্বল" বক্স, বাঁ পাশে লাল-কমলা দাগ।
- [ ] তিরমিযী ১০-এ "সব মান দেখুন" → "দুর্বল ও জাল" গ্রুপে স্ক্রল হয়ে "দুর্বল হাদিস" খোলা।
- [ ] জাল ও যঈফ হাদীস সিরিজ ১ → "জাল হাদিস" আর "বাতিল" ব্যাজ, বক্সের শিরোনাম তবুও "কেন দুর্বল"।
- [ ] ইবনে মাজাহ ৫ → ৩টা সবুজ সারি, একটায় "সহিহ লিগাইরিহি"।
- [ ] বুখারী ২ → শুধু ছবি, নাম, অর্থ আর দুই বাটন। "তাহকিক" অংশ নেই, যাচাইয়ের লাইনও নেই।
- [ ] বুখারী ১ সার্চ রেজাল্ট, হাদিসের বিস্তারিত পেজ, বুকমার্ক, নোট, ফিড আর হাদিস যাচাই রেজাল্ট থেকে খুলুন → একই ডায়ালগ, একই মত।
- [ ] ফ্ল্যাশকার্ড সেশনে ব্যাজ ট্যাপ → ডায়ালগে মত থাকে, কিন্তু "সব মান দেখুন" নেই।
- [ ] হোম থেকে সরাসরি "তাহকিক" পেজ খুলুন → কোনো সারি আগে থেকে খোলা নেই, আগের মতোই।

- [ ] অ্যাপের ভাষা ইংরেজি → বুখারী ১-এ কোনো মত নেই, শুধু অর্থ; বাটন "View all grades", অর্থ লম্বা হলে "Read more"।

- [ ] ট্যাবলেট (পোর্ট্রেট/ল্যান্ডস্কেপ, কালেকশনের ল্যান্ডস্কেপ বিস্তারিতও) → ডায়ালগ লম্বা হলে স্ক্রল হয়; "সব মান দেখুন" ঠিক সারিতে নিয়ে যায়।

## অ্যানালিটিক্স (DebugView)
- নতুন ইভেন্ট `grade_info_action`: `action` = `read_more` / `view_all_grades`, `grade_id` (ক্যাটালগ id), `opinion_count` (ডায়ালগে দেখানো মত, না থাকলে `0`)।
- বুখারী ১-এ "আরো পড়ুন" → `grade_info_action{action: read_more, grade_id: 2, opinion_count: 2}`। একই ডায়ালগে দ্বিতীয়বার আসে না।
- "সব মান দেখুন" → `grade_info_action{action: view_all_grades, grade_id: 2, opinion_count: 2}`, তারপর `screen_view` `tahkik_list`। `tahkik_details_toggle` আসে না।
- `opinion_count`: ইবনে মাজাহ ৫ → `3`, তিরমিযী ১০ → `3`, জাল সিরিজ ১ → `2`, বুখারী ২ → `0`। রিলিজে সবসময় `0`।
- ব্যাজ ট্যাপে `grade_info_open` আগের মতোই আসে। ফ্ল্যাশকার্ডে `view_all_grades` আসে না।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "## তাহকীক ও গ্রেড" অংশ।

## জানা সীমাবদ্ধতা
- মতগুলো ডেমো: নাম আর কিতাব নমুনা, "কেন দুর্বল" লেখা কোনো আলেম যাচাই করেননি, অথচ আসল হাদিসে বসানো। তাই data source `kReleaseMode`-এ কিছু ফেরত দেয় না। JSON ফাইল রিলিজ বান্ডেলেও থাকে, শুধু পড়া হয় না।
- `flutter run --profile`-এও ডেমো মত দেখায় (`kReleaseMode` false)।
- ডেমো ডেটা শুধু বাংলায়, ৪টা হাদিসে। অন্য ভাষায় মত নেই।
- অর্থ এখন সব হাদিসেই ৪ লাইনে কাটা, মত না থাকলেও। আগে পুরো অর্থ দেখাত।
- আগে অর্থ খালি হলে ডায়ালগ খুলত না। এখন অর্থ খালি হলেও মত থাকলে খোলে।
- জাল হাদিসেও বক্সের শিরোনাম "কেন দুর্বল"।
- আসল ডেটা কোথা থেকে আসবে (বইয়ের DB না API) এখনো ঠিক হয়নি। এলে শুধু data source বদলাবে।
- PR অনুযায়ী ফোন বা সিমুলেটরে এখনো চালানো হয়নি।
