## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হাদিসের কার্ডের বাংলা অনুবাদ | দাগানো শব্দের নিচে সবুজ ডট দাগ |
| শব্দে ট্যাপ করলে বটমশিট | হ্যান্ডেল, নাম (যেমন "পবিত্রতা (তাহারাত)"), ধরনের ট্যাগ, ডানে আরবি রূপ, ব্যাখ্যা, "বন্ধ করুন" আর "গ্লোসারিতে দেখুন" |

## ধাপগুলো
### হাদিসে ডট দাগ
- [ ] বুখারী ২০১ খুলুন → "এক সা‘ (চার মুদ)"-এ "সা‘" আর "মুদ"-এর নিচে ডট দাগ। পরের "পাঁচ মুদ"-এ দাগ নেই।
- [ ] মুসলিম ৪২২ → "পবিত্রতা" আর "ঈমানের"-এ দাগ। "সাদাকা"-য় দাগ নেই (ডেটায় নেই)।
- [ ] বুখারী ১৫০৩ → শুধু "এক সা পরিমাণ"-এর "সা"-তে দাগ, "সালাতের" বা "রাসূল"-এর ভেতরে না।
- [ ] দাগের ডট শব্দের ু-কার (মুদ) বা অন্য নিচের চিহ্নের সাথে মিশে যাচ্ছে কিনা দেখুন। ফল PR-এ লিখুন।
- [ ] অন্য যেকোনো হাদিস (যেমন বুখারী ২) → কোনো দাগ নেই, লেখা আগের মতো।
- [ ] সেটিংসে অনুবাদের ফন্ট সাইজ বাড়ান/কমান → দাগসহ শব্দও একই সাইজে, লাইন আগের মতো ভাঙে।
- [ ] অনুবাদের ভেতরের আরবি অংশ (যেসব হাদিসে আছে) আর ﷺ আগের মতো ঠিক দেখায়।

### বটমশিট
- [ ] "সা‘"-এ ট্যাপ → শিট উঠে আসে: "সা'", ট্যাগ "মাপ ও ওজন", ডানে صَاع, ব্যাখ্যা "শস্য মাপার বড় পাত্র…"।
- [ ] দাগের বাইরে অনুবাদে ট্যাপ → আগের মতো (অধ্যায়ের তালিকায় হাদিস ডিটেইলস খোলে)। দাগ দেওয়া শব্দে ট্যাপ করলে শুধু শিট, ডিটেইলস না।
- [ ] "বন্ধ করুন", শিটের বাইরে ট্যাপ, নিচে টেনে নামানো আর Back → শিট বন্ধ, একই হাদিসে ফেরে।
- [ ] অনুবাদে লম্বা চাপ দিয়ে লেখা সিলেক্ট/কপি আগের মতো চলে।
- [ ] হাদিস ডিটেইলস পেজেও দাগ আছে, ট্যাপে একই শিট।

### গ্লোসারিতে যাওয়া
- [ ] শিটে "গ্লোসারিতে দেখুন" → শিট বন্ধ, "পরিভাষা" পেজ খোলে। "সা'"-এর সারি খোলা (পুরো ব্যাখ্যা আর ট্যাগ), স্ক্রল করে সামনে, ওপরে "স" অক্ষরের হেডিং।
- [ ] Back → হাদিসে ফেরে।
- [ ] ড্রয়ার → "ইসলামিক পরিভাষা" → পেজ খোলে, কোনো সারি খোলা নেই, সার্চ খালি, "সব" চিপ বাছা।

### গ্লোসারি পেজ
- [ ] তালিকা অক্ষর ধরে ভাগ: ঈ, উ, ও, দ, ন, প, ফ, ম, য, র, স। হেডিংয়ের পাশে সংখ্যা (স-এ ৩টা)। স্ক্রল করলে হেডিং ওপরে আটকে থাকে।
- [ ] সারিতে ট্যাপ → নিচে নেমে পুরো ব্যাখ্যা আর ধরনের ট্যাগ, তীর ঘোরে। আবার ট্যাপ → বন্ধ। অন্য সারিতে ট্যাপ → আগেরটা বন্ধ, নতুনটা খোলা।
- [ ] সার্চে "সা'" লিখুন → সা', সারীদ, সাওয়ীক আসে। ✕ চাপলে বক্স খালি, পুরো তালিকা।
- [ ] সার্চে আরবি "صاع" বা হরকত ছাড়া "طهارة" → মিলে যায়।
- [ ] সার্চে "তাহারাত" → "পবিত্রতা" আসে (অন্য নাম)।
- [ ] সার্চে "যাকাত" → "কোন সার্চ রেজাল্ট পাওয়া যায়নি"।
- [ ] চিপ "খাবার ও পানীয়" → শুধু নাবীয, সারীদ, সাওয়ীক। সার্চে কিছু লেখা থাকলে দুটো একসাথে মেলে। "সব" → সব ফেরে।
- [ ] কিবোর্ড খোলা অবস্থায় তালিকা টানলে কিবোর্ড নামে।
- [ ] পেজ থেকে বেরিয়ে আবার ঢুকুন → সার্চ আর চিপ আবার শুরু থেকে।

### অন্য অবস্থা
- [ ] সার্চ পেজে "মুদ" লিখে সার্চ → রেজাল্টে কমলা হাইলাইট আগের মতো, সেখানে ডট দাগ নেই।
- [ ] বুখারী ২০১-এর ⋮ → ছবি শেয়ার → ছবিতে ডট দাগ নেই।
- [ ] অ্যাপের ভাষা English (বা অন্য যেকোনো) → কোনো দাগ নেই, ড্রয়ারে "Islamic glossary" নেই। আবার বাংলায় ফিরলে দাগ আর এন্ট্রি ফেরে।
- [ ] সেটিংসে আরবি বন্ধ/চালু, তাশকিল বন্ধ → হাদিসের আরবি আগের মতো, দাগে কোনো প্রভাব নেই।
- [ ] ডার্ক মোড: ডট দাগ, শিট, ট্যাগ, চিপ আর খোলা সারির হালকা রং পড়া যায়।
- [ ] ট্যাবলেট (পোর্ট্রেট আর ল্যান্ডস্কেপ): শিট মাঝখানে, চওড়া ৫২০-এর বেশি না। পেজ মাঝখানে, চওড়া ৬০০-এর বেশি না। ট্যাবলেটের ড্রয়ারেও এন্ট্রি আছে। ট্যাবলেটের দুই কলামের রিডারে দাগ আসে।
- [ ] ছোট ফোনে (৩২০/৩৬০ চওড়া) শিটের দুই বাটন এক লাইনে না ধরলে নিচে নেমে যায়, কাটে না।
- [ ] TalkBack/VoiceOver: সারি "<নাম>: ব্যাখ্যা দেখুন" পড়ে আর খোলা/বন্ধ বলে, সার্চ বক্স "পরিভাষা খুঁজুন: নাম বা আরবি রূপ", চিপে বাছা অবস্থা।

## অ্যানালিটিক্স (DebugView)
- দাগ দেওয়া শব্দে ট্যাপ → `glossary_term_open{term_id, term_category, book_id, book_slug, hadith_ref, chapter_id, content_source}`। বুখারী ২০১-এর "মুদ" হলে `term_id: mudd`, `term_category: measure`।
- শিটের "গ্লোসারিতে দেখুন" → `glossary_open{source: term_sheet, term_id}`, তারপর `screen_view{screen_name: islamic_glossary}`। "বন্ধ করুন"-এ কিছু যায় না।
- ড্রয়ার থেকে → `glossary_open{source: drawer}` (`term_id` নেই), তারপর একই `screen_view`।
- সারিতে প্রতি ট্যাপে `glossary_term_toggle{term_id, expanded}`।
- সার্চে লেখা থামলে ~৮০০ ms পর একটা `glossary_search{query_length, result_count}`। লেখা নিজে যায় না। বক্স খালি করলে কিছু যায় না।
- চিপে ট্যাপ → `glossary_category_select{term_category}`; "সব" হলে `all`। বাছা চিপে আবার ট্যাপে কিছু যায় না।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "ইসলামিক পরিভাষা গ্লোসারি" সেকশন।

## জানা সীমাবদ্ধতা
- সব ব্যাখ্যা ডেমো ডেটা, আলেমদের যাচাই করা না। আসল তালিকা এলে শুধু `IslamicGlossaryLocalDataSource` (আর JSON ফাইল) বদলাবে।
- অনলাইনে পড়া বইয়ের হাদিস id ডাউনলোড করা বইয়ের id-র সাথে না মিললে অনলাইনে দাগ আসবে না। তখন লেখা সাধারণই থাকে।
- বইয়ের লেখায় শব্দের বানান ডেটার সাথে হুবহু না মিললে (যেমন সংশোধিত লেখা) দাগ বসে না।
- একই শব্দ এক হাদিসে কয়েকবার এলে শুধু প্রথমবারে দাগ।
- তালিকার ক্রম Unicode-এর ক্রমে, অভিধানের ক্রমে পুরো মিলবে না।
- সার্চ রেজাল্টের হাইলাইট থাকলে আর শেয়ার করা ছবিতে দাগ দেখায় না, ইচ্ছা করেই।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
