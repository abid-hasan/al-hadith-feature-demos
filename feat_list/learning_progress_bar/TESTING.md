# শেখার প্রোগ্রেস বার — টেস্টের ধাপ

ব্রাঞ্চ `feature/learning-progress-bar` · PR #259 · ডেমো ১ ("অ্যাপের ধারা")

## চালানোর আগে
```bash
git checkout feature/learning-progress-bar
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ, পারমিশন বা `--dart-define` নেই। `pod install` লাগবে না।
- পরিষ্কার শুরুর জন্য অ্যাপ নতুন করে ইনস্টল করুন, বা অ্যাপের ডেটা মুছুন। হিসাব শুধু ফোনে (Hive) থাকে, সাইন-ইন বা সাইন-আউটে বদলায় না।
- ভাষা: বাংলা দিয়ে শুরু করুন। পরে ইংরেজি, আরবি, উর্দু দিয়েও দেখুন।
- অন্তত একটা বই ডাউনলোড করা রাখুন। আরেকটা বই ডাউনলোড ছাড়া রাখুন (অনলাইন টেস্টের জন্য)।
- কোনো ডেমো ডেটা নেই। বই, অধ্যায় আর মোট সংখ্যা অ্যাপের আসল ডেটা থেকে আসে।

## কোথায় দেখবেন
| জায়গা | কী দেখাবে | মোট সংখ্যা কোথা থেকে |
|---|---|---|
| হোম, "অনলাইনে আছে" আর "ডাউনলোড করা" ট্যাবের বইয়ের কার্ড (ফোন) | সাবটাইটেলের নিচে বার আর "৩২%"; শেষ হলে টিক আর "সম্পন্ন" | বইয়ের হাদিস সংখ্যা |
| হোমের গ্রিড কার্ড (ট্যাবলেট) | শুধু পাতলা বার, লেখা নেই | বইয়ের হাদিস সংখ্যা |
| অধ্যায়ের তালিকা (ফোন আর ট্যাবলেট) | সারির ডানে "১২/৩০" আর ছোট বার; শেষ হলে টিক আর "সম্পন্ন" | ডাউনলোড করা বই: DB-র সারি; অনলাইন বই: অধ্যায়ের range |

## ধাপগুলো
- [ ] নতুন ইনস্টলে হোম খুলুন → কোনো বইয়ের কার্ডে বার নেই, তালিকা আগের মতো।
- [ ] ডাউনলোড করা একটা বইয়ের অধ্যায় তালিকা খুলুন → কোনো সারিতে সংখ্যা বা বার নেই।
- [ ] একটা অধ্যায়ে ঢুকে ৫–৬টা হাদিস স্ক্রল করে ওপরে পার করুন, তারপর ব্যাক → ওই অধ্যায়ের ডানে "৫/৩০"-এর মতো সংখ্যা আর বার। অন্য অধ্যায় খালি।
- [ ] হোমে ফিরুন → বইয়ের কার্ডে বার আর শতকরা। বড় বইয়ে অল্প পড়লেও "১%" দেখাবে, "০%" না। বারে অন্তত একটা গোল বিন্দু ভরা থাকবে।
- [ ] একই হাদিসগুলো আবার স্ক্রল করে পার করুন → সংখ্যা বাড়বে না।
- [ ] হাদিস পর্দায় এসেছে কিন্তু ওপরে পার হয়নি, এমন অবস্থায় ব্যাক করুন → সেগুলো গোনা হবে না।
- [ ] ছোট একটা অধ্যায় শেষ পর্যন্ত স্ক্রল করুন, শেষ হাদিসটা নিচ পর্যন্ত পুরো দেখা যাক → ফিরলে বারের জায়গায় টিক আর "সম্পন্ন"।
- [ ] প্রায় শেষ হওয়া অধ্যায়ে সংখ্যা কখনো মোটের বেশি দেখাবে না, আর পুরো শেষ না হলে বই "১০০%" দেখাবে না (সর্বোচ্চ "৯৯%")।
- [ ] হোমের "জাম্প" দিয়ে কোনো অধ্যায়ের মাঝের হাদিসে যান, কয়েকটা স্ক্রল করে পার করুন → শুধু যেগুলো পর্দায় এসে পার হয়েছে সেগুলো গোনা হবে। জাম্পে পার হওয়া আগের হাদিস না।
- [ ] সর্বশেষ পড়া থেকে রিডার খুলুন → খোলার সময়ের জাম্পে কিছু গোনা হবে না।
- [ ] স্ক্রলবারের হাতল টেনে অনেক নিচে যান → টানার সময় পার হওয়া হাদিস গোনা হবে না। হাতল ছেড়ে স্বাভাবিক স্ক্রল করলে আবার গোনা শুরু।
- [ ] অ্যাপ বন্ধ করুন, ইন্টারনেট বন্ধ রেখে আবার খুলুন → বার আর সংখ্যা আগের মতোই।
- [ ] ডাউনলোড ছাড়া (অনলাইন) একটা বইয়ের অধ্যায় পড়ুন → অধ্যায় আর বইয়ে বার আসবে। range নেই এমন অধ্যায়ে বার আসবে না।
- [ ] অনলাইন অধ্যায়ের শেষে যান → শেষ পেজ লোড হওয়ার পরেই শেষের হাদিসগুলো গোনা হবে।
- [ ] "হাদিস পড়ার প্ল্যান"-এর রিডারে কয়েকটা হাদিস স্ক্রল করে পার করুন → সেই বই আর অধ্যায়ের বার বাড়বে। প্ল্যান কার্ডের "মোট পড়েছেন" আগের নিয়মেই থাকবে।
- [ ] "বিষয়ভিত্তিক হাদিস" থেকে হাদিস পড়ুন → কোনো বই বা অধ্যায়ের বার বাড়বে না।
- [ ] ভাষা সেটিংসে ইংরেজি করুন → বার খালি (প্রতি ভাষায় আলাদা হিসাব)। বাংলায় ফিরলে আগের হিসাব ফেরত।
- [ ] রিডারে থাকা অবস্থায় ভাষা বদলান, কয়েকটা হাদিস পার করুন → নতুন ভাষার হিসাবে যাবে, আগের ভাষায় না।
- [ ] আরবি আর উর্দুতে (RTL) দেখুন → অধ্যায়ের সংখ্যা আর বার সারির শেষে (বাঁ দিকে), বইয়ের বার টেক্সটের নিচে ঠিক দিক থেকে ভরছে। সংখ্যা সেই ভাষার অঙ্কে।
- [ ] ডার্ক মোডে দেখুন → বার, শতকরা আর টিক পড়া যায়। লাইট মোডে শতকরা গাঢ় সবুজে।
- [ ] ট্যাবলেটে হোম খুলুন → গ্রিড কার্ডে শুধু পাতলা বার, শেষ হলেও টিক নেই। কার্ড উঁচু হবে না, ওভারফ্লো হবে না।
- [ ] ট্যাবলেটে অধ্যায় তালিকা (পোর্ট্রেট আর ল্যান্ডস্কেপ) → ফোনের মতোই "১২/৩০" আর বার।
- [ ] বড় ফন্ট সাইজে অধ্যায়ের "১২/৩০" ছোট হয়ে ঘরে ঢুকবে, সারি ভাঙবে না।
- [ ] TalkBack / VoiceOver চালু করুন → বইয়ে "৩২% পড়া হয়েছে", অধ্যায়ে "৩০টির মধ্যে ১২টি হাদিস পড়া হয়েছে", শেষ হলে "সব হাদিস পড়া হয়েছে"।

## অ্যানালিটিক্স (DebugView)
- নতুন ইভেন্ট `reading_progress_complete`। প্যারাম: `book_id`, `book_slug`, `progress_scope` = `chapter` / `book`, `chapter_id` (শুধু `chapter`-এ), `hadith_count` (সেই অধ্যায় বা বইয়ের মোট হাদিস)।
- অধ্যায় তালিকা খুলে আধা পড়া অধ্যায় শেষ করুন → প্রায় ১ সেকেন্ডের মধ্যে `reading_progress_complete{progress_scope: chapter}`।
- একই অধ্যায় আবার শেষ করলে, বা আগেই ১০০% থাকলে → ইভেন্ট আসবে না।
- এই রানে অধ্যায় তালিকা না খুলে (সর্বশেষ, জাম্প বা প্ল্যান থেকে) অধ্যায় শেষ করলে → `chapter` ইভেন্ট আসবে না। ভাষা বদলের পরে তালিকা আবার খুলতে হবে।
- হোমে কার্ড দেখা গেছে এমন বই ১০০% হলে → `reading_progress_complete{progress_scope: book}`, `chapter_id` ছাড়া। সাথে শেষ অধ্যায়ের `chapter` ইভেন্টও আসতে পারে।
- `hadith_read` আগের নিয়মেই আসে। হাদিস পার হওয়ার আলাদা ইভেন্ট নেই।
- বিস্তারিত: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md` → "শেখার প্রোগ্রেস"।

## জানা সীমাবদ্ধতা
- "পড়া" মানে পর্দায় এসে স্ক্রল করে পার হওয়া। কোনো ন্যূনতম সময় নেই, তাই খুব দ্রুত স্ক্রল করলেও গোনা হয়। নিয়ম প্রোডাক্ট এখনো চূড়ান্ত করেনি।
- বইয়ের মোট সংখ্যা বইয়ের তথ্য থেকে, অধ্যায়ের মোট DB বা range থেকে। দুটো না মিললে (যেমন ভূমিকার `intro-*` সারি) বই একটু আগে বা পরে "সম্পন্ন" হতে পারে।
- অনলাইন অধ্যায়ে `8a`, `8b`-এর মতো লেবেল থাকলে আসল সংখ্যা range-এর চেয়ে বেশি হয়। তখন সব পড়ার আগেই "সম্পন্ন" দেখাতে পারে।
- প্ল্যানে কোনো হাদিস "পড়া হয়নি" করলে বইয়ের বার থেকে কমে না।
- হিসাব সিঙ্ক হয় না। অ্যাপ ডেটা মুছলে বা নতুন ফোনে সব খালি।
- প্ল্যানের রিডারে "শেষ" মানে প্ল্যানের লোড হওয়া তালিকার শেষ হাদিস, অধ্যায়ের শেষ না।
- `hadith_list_presenter.dart` `feature/auto-resume`-এর সাথে কনফ্লিক্ট হতে পারে। ব্রাঞ্চে build বা `flutter analyze` আলাদা করে চালানো হয়নি (PR)।
- ব্রাঞ্চে `.impeccable/critique/…` ফাইলটাও কমিট হয়েছে, সম্ভবত রাখার কথা না।
