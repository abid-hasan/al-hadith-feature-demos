# জীবনের পরিস্থিতি — টেস্টের ধাপ

ব্রাঞ্চ `feature/life-situations` · PR #276 · ডেমো ১ (অ্যাপের ধরন: হোমের বাটন → তালিকা → পরিস্থিতির পেজ → পুরো হাদিস)

## চালানোর আগে
```bash
git checkout feature/life-situations
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন কোনো প্যাকেজ বা অনুমতি নেই। নতুন অ্যাসেট `assets/demo/life_situations/` (pubspec-এ যোগ করা), তাই hot reload না, পুরো রিস্টার্ট দিন।
- অ্যাপের ভাষা বাংলা রাখুন। কনটেন্ট শুধু বাংলায়, অন্য ভাষায় বাটনই দেখায় না।
- কোনো বই ডাউনলোড লাগে না। দোয়া আর হাদিস সব অ্যাপের ভেতরের ডেমো JSON থেকে আসে।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোমের কুইক বাটনের গ্রিড (তীর চেপে খোলা) | তৃতীয় সারির শুরুতে "পরিস্থিতি" (পতাকার মতো সবুজ-কমলা আইকন) |
| "জীবনের পরিস্থিতি" পেজ | ওপরে "যে অবস্থায় আছেন, সেটা বেছে নিন…", তারপর সাতটা সারি |
| পরিস্থিতির পেজ (যেমন "রাগ") | ওপরে নাম, "রাগ সামলাতে পারছি না" আর সান্ত্বনার লাইন; তারপর ভাগের শিরোনাম, দোয়া কার্ড, হাদিস কার্ড |
| পুরো হাদিসের পেজ | অধ্যায়ের কার্ড ("৭৮/৭৬. অধ্যায়ঃ ক্রোধ থেকে বেঁচে থাকা।") আর পুরো হাদিস |

## ধাপগুলো
- [ ] অ্যাপের ভাষা বাংলা → হোম। গ্রিড বন্ধ থাকলে প্রথম দুই সারি আগের মতো (প্রথম সারিতে সর্বশেষ, জাম্প, ওয়াক্ত, সাদাকা)।
- [ ] তীর চাপুন → তৃতীয় সারির শুরুতে "পরিস্থিতি", পরে পরিকল্পনা, তাহকিক, দৈনিক।
- [ ] "পরিস্থিতি" → "জীবনের পরিস্থিতি" পেজ। সারির ক্রম: ঋণ, দুশ্চিন্তা, পরীক্ষা, রাগ, চাকরি, সংসার, অসুস্থতা।
- [ ] প্রতিটা সারিতে ষড়ভুজের ভেতরে আইকন, নাম, নিচে ছোট কথা ("ঋণে ডুবে আছি") আর সংখ্যা। ঋণে "২টি দোয়া", রাগে "২টি দোয়া · ২টি হাদিস", চাকরিতে "২টি দোয়া · ১টি হাদিস"।
- [ ] "ঋণ" → ওপরে নাম, "ঋণে ডুবে আছি", সান্ত্বনার লাইন। নিচে "ঋণমুক্তির দোয়া" ভাগে দুটো দোয়া। কোনো হাদিসের ভাগ নেই।
- [ ] দোয়া কার্ডে: শিরোনাম, আরবি (ডান থেকে বাঁয়ে), "উচ্চারণ", "অর্থ", "সূত্র: …", নিচে "কপি | শেয়ার"।
- [ ] "কপি" → "কপি হয়েছে" টোস্ট। অন্য অ্যাপে পেস্ট করলে শিরোনাম, আরবি, উচ্চারণ, অর্থ, সূত্র আলাদা লাইনে।
- [ ] "শেয়ার" → ফোনের শেয়ার মেনু, একই লেখা।
- [ ] ব্যাক → তালিকা। "রাগ" → "রাগ উঠলে দোয়া" (২টা দোয়া), "নবীজি ﷺ-এর উপদেশ" (বুখারি ৬১১৬), "কথায় সংযম" (বুখারি ৬০১৮)।
- [ ] হাদিস কার্ড অ্যাপের চেনা কার্ড: বইয়ের ব্যাজ, "সহীহ বুখারী", হাদিস নম্বর, সবুজ গ্রেড চিপ, ⋮। বুকমার্ক আইকন নেই।
- [ ] গ্রেড চিপে ট্যাপ → গ্রেডের ব্যাখ্যার ডায়ালগ।
- [ ] হাদিস কার্ডে ট্যাপ → পুরো হাদিসের পেজ, ওপরে অধ্যায়ের কার্ড। পাশে সোয়াইপ করলে একই পরিস্থিতির অন্য হাদিস (৬১১৬ ↔ ৬০১৮)।
- [ ] পুরো হাদিসের পেজ থেকে ব্যাক → পরিস্থিতির পেজ, আগের স্ক্রল জায়গায়। আরেকবার ব্যাক → তালিকা।
- [ ] হাদিসের ⋮ → অ্যাপের হাদিস মেনু। কালেকশন আর নোটের অপশন নেই, কপি আর শেয়ার কাজ করে।
- [ ] "চাকরি" → দোয়ার পরে "কাজের নিয়ত" ভাগে বুখারি ১। "সংসার" → এক দোয়া আর বুখারি ৬০১৮। "দুশ্চিন্তা", "পরীক্ষা", "অসুস্থতা" → শুধু দোয়া।
- [ ] সেটিংসে আরবি বন্ধ → হাদিস কার্ডে আরবি নেই, দোয়ার আরবি থাকে। আরবি ফন্ট আর লেখার সাইজ বদলালে দুই কার্ডেই বদলায়।
- [ ] বিমান মোড চালু রেখে পুরো পথ ঘুরুন: সব খোলে।
- [ ] অ্যাপের ভাষা English (বা অন্য যেকোনো ভাষা) → গ্রিডে "পরিস্থিতি" নেই। আবার বাংলায় ফিরলে বাটন ফিরে আসে।
- [ ] ডার্ক মোড: সারি, দোয়া কার্ড, লেবেল আর হাদিস কার্ড পড়া যায়।
- [ ] ট্যাবলেট (পোর্ট্রেট আর ল্যান্ডস্কেপ): তালিকা আর পরিস্থিতির পেজ মাঝখানে সরু কলামে, কিছু ভাঙে না।
- [ ] ছোট ফোন (৩২০ চওড়া): সারির লেখা আর "কপি | শেয়ার" বাইরে যায় না।
- [ ] TalkBack/VoiceOver: সারি, কপি আর শেয়ার বাটন পড়ে।

## অ্যানালিটিক্স (DebugView)
- হোমের বাটন → `home_quick_action{action: life_situations}`, তারপর `screen_view{screen_name: life_situations}`।
- সারিতে ট্যাপ → `life_situation_open{situation_id}` (`debt` / `worry` / `exam` / `anger` / `job` / `home` / `sick`), তারপর `screen_view{screen_name: life_situation}`।
- দোয়ার "কপি" → `life_situation_dua_copy{situation_id, dua_id}`।
- দোয়ার "শেয়ার" → `share{content_type: life_situation_dua, item_id: dua:<id>, method: system, situation_id}`। শেয়ার মেনু বাতিল করলেও যায়।
- হাদিস কার্ডে ট্যাপ → `hadith_details_open{source: card_tap}` + `screen_view{screen_name: hadith_details}`। ⋮ → `hadith_more_menu_open`, মেনুর কাজগুলোর ইভেন্ট আগের মতো।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "জীবনের পরিস্থিতি" সেকশন।

## জানা সীমাবদ্ধতা
- কনটেন্ট ডেমো: সাতটা পরিস্থিতি, ১২টা দোয়া, বুখারির তিনটা হাদিস। নাম, ছোট কথা আর সান্ত্বনার লাইন আলেমদের যাচাই করা নয়।
- শুধু বাংলা। অন্য ভাষার কনটেন্ট এলে `assets/demo/life_situations/life_situations_<ভাষা>.json` আর `LifeSituationLanguage.supported`-এ ভাষা যোগ করতে হবে।
- আসল API এলে বদলাতে হবে শুধু `LifeSituationDemoAssetDataSource` (আর `LifeSituationModule`-এর register লাইন)।
- দোয়ার অডিও নেই। দোয়ার সূত্রের হাদিস লিংক হয় না।
- হাদিস কার্ডে বুকমার্ক দেখায় না; পুরো হাদিসের পেজে বুকমার্ক আর নোট আছে।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
