# মুড অনুযায়ী হাদিস — টেস্টের ধাপ

ব্রাঞ্চ `feature/mood-hadith` · PR #277 · ডেমো ১ (অ্যাপের ধরন: হোমে মুড চিপ, সব মুডের পেজ, মুডের পেজ)

## চালানোর আগে
```bash
git checkout feature/mood-hadith
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন কোনো প্যাকেজ বা অনুমতি নেই। `pubspec.yaml`-এ শুধু নতুন অ্যাসেট ফোল্ডার `assets/demo/mood_hadith/`।
- অ্যাপের ভাষা বাংলা রাখুন। মুড-ডেটা এখন শুধু বাংলায় (`mood_hadith_bn.json`), অন্য ভাষায় হোমের অংশটা দেখায় না।
- দুই অবস্থায় দেখতে হবে: বুখারি আর মুসলিম ডাউনলোড করা, আর ডাউনলোড না করা (তখন হাদিস আসে API থেকে, নেট লাগে)।
- লাইট আর ডার্ক দুই মোডেই একবার দেখুন।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোম, কুইক অ্যাকশনের ঠিক নিচে | "এখন কেমন লাগছে?" কার্ড, ডানে "সব দেখুন", নিচে পাশে স্ক্রল করা পাঁচটা চিপ: মন খারাপ, রাগ, দুশ্চিন্তা, কৃতজ্ঞ, একা |
| "সব দেখুন" → "মুড অনুযায়ী হাদিস" পেজ | ওপরে "মন এখন কেমন, সেটা বেছে নিন…", তারপর প্রতি মুডের সারি: আইকন, নাম, এক লাইন, "২টি দোয়া · ২টি হাদিস", ডানে তীর |
| মুডের পেজ | অ্যাপ বারে মুডের নাম; নাম আর এক লাইনের কার্ড; "দোয়া" কার্ড (আরবি, উচ্চারণ, অর্থ, সূত্র, কপি, শেয়ার); "হাদিস" কার্ড; কিছু মুডে শেষে "সাহায্য দরকার হলে" বক্স; নিচে "নতুন হাদিস দেখান" |

## ধাপগুলো
- [ ] হোম খুলুন → কুইক অ্যাকশনের নিচে "এখন কেমন লাগছে?" কার্ড। কুইক অ্যাকশনের ক্রম আগের মতো, সাদাকা প্রথম সারিতে। নিচে বইয়ের তালিকা আগের মতো।
- [ ] কুইক অ্যাকশন খুলুন আর বন্ধ করুন (নিচের তীর) → মুডের কার্ড ঠিকভাবে নিচে সরে, তীরের সাথে গায়ে লাগে না।
- [ ] চিপের সারি পাশে স্ক্রল হয়, প্রতিটা চিপে সবুজ লাইন আইকন আর নাম।
- [ ] "দুশ্চিন্তা" চিপ → মুডের পেজ, অ্যাপ বারে "দুশ্চিন্তা"। ওপরে "চিন্তা মাথা থেকে যাচ্ছে না? আল্লাহর ওপর ভরসা রেখে এই দোয়া পড়ুন।"
- [ ] দোয়া কার্ড: শিরোনাম "দুশ্চিন্তা ও পেরেশানিতে পতিত ব্যক্তির দোয়া #২", হরকতসহ আরবি ডানে, "উচ্চারণ", "অর্থ", শেষে "সূত্র: বুখারীঃ ২৮৯৩"।
- [ ] সেটিংসে আরবির ফন্ট বা সাইজ বদলান → দোয়ার আরবিও বদলায়। অনুবাদের সাইজ বদলালে উচ্চারণ আর অর্থের সাইজ বদলায়।
- [ ] হাদিস কার্ড: প্রথমে skeleton, তারপর অ্যাপের চেনা কার্ড, সহীহ মুসলিম, হাদিস ৪২২ ("পবিত্রতা হল ঈমানের অর্ধেক অংশ…")। সেটিংসে আরবি বন্ধ থাকলে হাদিসের আরবি দেখায় না, দোয়ার আরবি তখনো দেখায়।
- [ ] পেজের শেষে "সাহায্য দরকার হলে" বক্স, লেখা "মন অনেক দিন ধরে ভারী থাকলে…"।
- [ ] "নতুন হাদিস দেখান" → পেজ ওপরে ফেরে, নতুন দোয়া ("কঠিন কাজে পতিত ব্যক্তির দোয়া") আর সহীহ বুখারী ১। আবার চাপলে প্রথম জোড়ায় ফেরে।
- [ ] হাদিস কার্ডে ট্যাপ → পুরো হাদিসের পেজ। Back → আবার মুডের পেজ, একই দোয়া আর হাদিস।
- [ ] হাদিস কার্ডের ⋮ → অ্যাপের হাদিস মেনু (কপি, শেয়ার, বুকমার্ক…)। বুকমার্ক করলে কার্ডের বুকমার্ক চিহ্ন বদলায়।
- [ ] গ্রেডের চিপে ট্যাপ → তাহকিকের ডায়ালগ।
- [ ] দোয়ার "কপি" → সবুজ টোস্ট "কপি হয়েছে"। অন্য কোথাও পেস্ট করুন: শিরোনাম, আরবি, "উচ্চারণ: …", "অর্থ: …", "সূত্র: …", শেষে "সোর্স: আল হাদিস অ্যাপ, irdfoundation․com"।
- [ ] দোয়ার "শেয়ার" → ফোনের শেয়ার শিট, একই লেখা।
- [ ] Back করে হোমে → "সব দেখুন" → পাঁচটা মুডের সারি। সংখ্যা: মন খারাপ ২টি দোয়া · ২টি হাদিস, রাগ ২টি দোয়া · ৩টি হাদিস, দুশ্চিন্তা, কৃতজ্ঞ, একা ২টি · ২টি।
- [ ] "রাগ" সারি → রাগের পেজ, শেষে সাহায্যের বক্স নেই। "নতুন হাদিস দেখান" তিনবারে তিনটা হাদিস (৬১১৬, ৬০১৮, ১৮৯৪), তৃতীয়টায় প্রথমের দোয়া আবার আসে।
- [ ] "কৃতজ্ঞ"-তেও বক্স নেই; "মন খারাপ" আর "একা"-তে বক্স আছে।
- [ ] মুডের পেজ থেকে Back → যে পেজ থেকে এসেছিলেন সেখানে (হোম বা সব মুডের পেজ)।
- [ ] বুখারি/মুসলিম ডাউনলোড নেই, নেট চালু → হাদিস API থেকে আসে। বিশেষ করে মুসলিম ৪২২ আসে কিনা দেখুন, ফল PR-এ লিখে দিন।
- [ ] বই ডাউনলোড নেই + বিমান মোড → হাদিসের জায়গায় "হাদিসটা এখন দেখানো যাচ্ছে না। বইটা ডাউনলোড করুন বা ইন্টারনেট চালু করে আবার চেষ্টা করুন।" আর "আবার চেষ্টা করুন"। দোয়া তখনো দেখায়। নেট চালু করে "আবার চেষ্টা করুন" → হাদিস আসে।
- [ ] বই ডাউনলোড করা + বিমান মোড → সব মুডে হাদিস দেখায়।
- [ ] "নতুন হাদিস দেখান" খুব দ্রুত কয়েকবার → শেষ চাপের হাদিসই থাকে, আগেরটা পরে এসে বসে না।
- [ ] অ্যাপের ভাষা English (বা অন্য যেকোনো) → হোমে মুডের কার্ড নেই। আবার বাংলায় ফিরলে কার্ড ফিরে আসে।
- [ ] ডার্ক মোড: কার্ড, চিপ, আইকনের গোল পটভূমি, সাহায্যের বক্স আর নিচের বাটন পড়া যায়।
- [ ] ছোট ফোন (৩২০–৩৬০ প্রস্থ): শিরোনাম আর "সব দেখুন" এক লাইনে, চিপ কাটা পড়ে না (পাশে স্ক্রল হয়)।
- [ ] ট্যাবলেট portrait আর landscape: হোমে কার্ড কুইক অ্যাকশনের সমান চওড়া; মুডের পেজ মাঝখানে, চওড়া ৬০০-এর বেশি না।
- [ ] TalkBack/VoiceOver: "এখন কেমন লাগছে?" শিরোনাম হিসেবে পড়ে, প্রতিটা চিপ মুডের নাম আর বাটন হিসেবে।

## অ্যানালিটিক্স (DebugView)
- চিপে ট্যাপ → `mood_select{mood_id: worry, source: home}`; সব মুডের পেজের সারিতে ট্যাপ → `source: mood_list`। তারপর `screen_view{screen_name: mood_hadith_mood}`।
- "সব দেখুন" → শুধু `screen_view{screen_name: mood_hadith}`।
- "নতুন হাদিস দেখান" → `mood_next{mood_id}`।
- দোয়ার "কপি" → `mood_dua_copy{mood_id, item_id: dua:<id>}`; "শেয়ার" → `share{content_type: mood_dua, item_id: dua:<id>, method: system, mood_id}`।
- হাদিস না পেলে → `content_unavailable{reason: hadith_not_found, book_id, book_slug, screen_name: mood_hadith_mood}`।
- হাদিস কার্ডে ট্যাপ → `hadith_details_open{source: card_tap}`; ⋮ মেনুর কাজ আগের ইভেন্টে।
- হোম খোলা বা চিপ স্ক্রল করায় কোনো ইভেন্ট নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "মুড অনুযায়ী হাদিস" সেকশন।

## জানা সীমাবদ্ধতা
- মুড-ডেটা ডেমো, `assets/demo/mood_hadith/mood_hadith_bn.json`-এ। কোন মুডে কোন দোয়া-হাদিস, আর মুডের এক লাইনের কথা আলেমদের যাচাই বাকি। আসল ডেটা এলে শুধু `MoodHadithDemoDataSource` বদলাতে হবে।
- শুধু বাংলায় ডেটা আছে, তাই অন্য ভাষায় ফিচারটা লুকানো।
- সাহায্যের বক্সের লেখা আর কোন মুডে দেখাবে (এখন মন খারাপ, দুশ্চিন্তা, একা), প্রোডাক্ট টিম ঠিক করবে। ডেটার `show_help` আর `help_info` বদলালেই হবে।
- হাদিসের নম্বর অ্যাপের গণনায় (মুসলিম ৪২২ = প্রচলিত গণনায় ২২৩)।
- বই ডাউনলোড না থাকলে হাদিস আসে API থেকে, সেভ হয় না; তাই অফলাইনে আবার খুললে দেখাবে না।
- মুডে একটাই দোয়া-হাদিস থাকলে "নতুন হাদিস দেখান" দেখায় না (ডেমো ডেটায় সব মুডে দুটো বা তিনটা)।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
