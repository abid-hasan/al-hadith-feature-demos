# মাল্টি-ল্যাঙ্গুয়েজ অনুবাদ — টেস্টের ধাপ

ব্রাঞ্চ `feature/multi-language-translation` · PR #283 · ডেমো ১ (অ্যাপের ধরন: অ্যাপ বারে ভাষা বাটন, অ্যাপের বটমশিট, দাগের নিচে লেবেলসহ দ্বিতীয় অনুবাদ)

## চালানোর আগে
```bash
git checkout feature/multi-language-translation
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ নেই। নতুন অ্যাসেট `assets/demo/multi_language_translation/hadith_translation_links.json` (কোন বইয়ে কোন ভাষা মেলে তার ডেমো তালিকা)।
- অ্যাপের ভাষা বাংলা রাখুন। শুরুতে নেট চালু রাখুন।
- ডেমো তালিকায় যে বই আর ভাষা মেলে:
  - বুখারী আর আবু দাউদ: বাংলা, English, اردو
  - নাসাঈ, তিরমিযী, ইবনে মাজাহ, লু'লু ওয়াল মারজান, ৪০ হাদিস: বাংলা, English
  - বাকি সব বই (মুসলিমসহ): কোনো ভাষা মেলে না
- অফলাইন ধাপের জন্য: বুখারীর English বই ডাউনলোড না থাকা অবস্থা দরকার। আরেকবার English বই ডাউনলোড করে নেট ছাড়া দেখতে হবে।
- আগের অবস্থা মুছতে অ্যাপ মুছে নতুন করে ইনস্টল করুন (পছন্দ Hive-এ থাকে)।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হাদিস পড়ার পেজের অ্যাপ বার, একদম ডানে | ভাষা বাটন: অনুবাদ আইকন আর কোড ("BN", পাশাপাশিতে "BN + EN") |
| ভাষা বাটন → বটমশিট | "অনুবাদের ভাষা", নিচে "মেনু আর বাটনের ভাষা একই থাকবে"; "পাশাপাশি পড়ুন" সুইচ |
| সুইচ বন্ধ | ভাষার তালিকা: বাংলা, English, Bahasa Indonesia, اردو। না-মেলা ভাষার নিচে "এই বইয়ে এখনো মেলানো হয়নি" |
| সুইচ চালু | "প্রথম ভাষা" আর "দ্বিতীয় ভাষা" চিপ, নিচে "বাতিল করুন" / "ঠিক আছে" |
| হাদিস কার্ড | অন্য ভাষা হলে অনুবাদের ওপরে ভাষার লেবেল; পাশাপাশিতে দাগের নিচে দ্বিতীয় অনুবাদ |

## ধাপগুলো
- [ ] বুখারীর যেকোনো অধ্যায় খুলুন → অ্যাপ বারের ডানে "BN" বাটন। কার্ড আগের মতো, কোনো লেবেল নেই।
- [ ] বাটন → বটমশিট। "বাংলা" বাছা (রেডিও ভরা)। Bahasa Indonesia-র নিচে "এই বইয়ে এখনো মেলানো হয়নি"।
- [ ] "English" ট্যাপ → শিট বন্ধ, বাটনে "EN"। প্রতিটা কার্ডে আরবির নিচে "English" লেবেল, তার নিচে ইংরেজি বর্ণনাকারী আর অনুবাদ। অধ্যায়ের নাম, পরিচ্ছেদ, মেনু আর বাটন বাংলাই থাকে।
- [ ] লোড হওয়ার সময় লেবেলের নিচে লোডিং, তারপর লেখা। স্ক্রল করলে নতুন কার্ডেও আসে।
- [ ] Bahasa Indonesia ট্যাপ → টোস্ট "এই বইয়ে Bahasa Indonesia অনুবাদ এখনো মেলানো হয়নি", কিছু বদলায় না।
- [ ] আবার "বাংলা" → কার্ড আগের মতো, লেবেল নেই।
- [ ] "পাশাপাশি পড়ুন" চালু (সুইচ বা পুরো সারি) → চিপ দেখায়, প্রথম "বাংলা", দ্বিতীয় "English" বাছা। "ঠিক আছে" → বাটনে "BN + EN"। প্রতিটা কার্ডে বাংলা অনুবাদের নিচে দাগ, "English" লেবেল আর ইংরেজি অনুবাদ।
- [ ] শিট খুলে প্রথম ভাষায় "English" ট্যাপ → প্রথম আর দ্বিতীয় অদলবদল হয় (প্রথম English, দ্বিতীয় বাংলা)। "বাতিল করুন" বা ✕ → কিছু বদলায় না।
- [ ] এবার অদলবদল করে "ঠিক আছে" → ওপরে "English" লেবেলসহ ইংরেজি, দাগের নিচে "বাংলা" লেবেলসহ বাংলা।
- [ ] দ্বিতীয় ভাষা "اردو" → উর্দু অনুবাদ ডান থেকে বাঁয়ে, উর্দু ফন্টে, লেবেলও উর্দুতে।
- [ ] অ্যাপ পুরো বন্ধ করে আবার খুলে একই অধ্যায় → আগের অবস্থাই থাকে।
- [ ] শিটে সুইচ বন্ধ → সাথে সাথে একটা অনুবাদে ফেরে, শিট খোলা থাকে, তালিকা দেখায়।
- [ ] মুসলিমের অধ্যায় খুলুন (আগে English বা পাশাপাশি বাছা অবস্থায়) → কার্ড আগের মতো, বাটনে "BN"। শিটে বাংলা ছাড়া সব ভাষার নিচে "এই বইয়ে এখনো মেলানো হয়নি"। বুখারীতে ফিরলে আগের অবস্থা ফিরে আসে।
- [ ] তিরমিযী বা নাসাঈ: English মেলে, اردو মেলে না।
- [ ] কোনো হাদিস দ্বিতীয় ভাষায় না থাকলে (বা দুই ভাষার আরবি না মিললে) সেই কার্ডে দাগ আর দ্বিতীয় অংশ দেখায় না। বুখারীর শেষের দিকের অধ্যায়ে উর্দু দিয়ে দেখুন।
- [ ] English বই ডাউনলোড নেই, পাশাপাশি চালু, বিমান মোড → নতুন অধ্যায় খুলুন: দ্বিতীয় অংশে "English অনুবাদ আনা যায়নি। ইন্টারনেট চালু করে আবার চেষ্টা করুন।" আর "আবার চেষ্টা করুন"। প্রথম অনুবাদ পড়া যায়। নেট চালু করে "আবার চেষ্টা করুন" → ইংরেজি আসে।
- [ ] একই অবস্থায় প্রথম ভাষা English → মেসেজের নিচে বাংলা অনুবাদ, লেবেল "বাংলা"।
- [ ] আগে দেখা হাদিস বিমান মোডেও আসে (API cache)।
- [ ] বুখারীর English বই ডাউনলোড করে বিমান মোড → নতুন অধ্যায়েও ইংরেজি অনুবাদ নেট ছাড়াই আসে।
- [ ] কার্ডে ট্যাপ → হাদিস ডিটেইলস খোলে, সেখানে শুধু অ্যাপের ভাষার অনুবাদ (আগের মতো)।
- [ ] কার্ডের মেনু → ছবি হিসেবে শেয়ার: ছবিতে কার্ডে যা দেখা যায় তাই (লোডিং বা মেসেজ ছাড়া)।
- [ ] বিষয়ভিত্তিক হাদিসের তালিকা খুলুন → ভাষা বাটন আছে। শিটে সব ভাষা বাছা যায়; বুখারী-আবু দাউদের হাদিসে দ্বিতীয় অনুবাদ আসে, অন্য বইয়ের হাদিসে আসে না।
- [ ] অ্যাপের ভাষা English → কার্ডে English, শিটের লেখা ইংরেজিতে। দ্বিতীয় ভাষা বাংলা → বুখারীতে বাংলা অনুবাদ "বাংলা" লেবেলসহ।
- [ ] অ্যাপের ভাষা উর্দু বা আরবি (RTL) → বাটন, শিট আর লেবেল ঠিক জায়গায়। আরবিতে শিটের তালিকায় "العربية" থাকে।
- [ ] পড়ার পেজ খোলা অবস্থায় সেটিংস থেকে অ্যাপের ভাষা বদলান → বাটন আর কার্ড নতুন ভাষা মেনে চলে।
- [ ] ট্যাবলেট আড়াআড়ি, পাশাপাশি চালু → আরবি ওপরে পুরো চওড়া, নিচে বাঁয়ে প্রথম, ডানে দ্বিতীয় অনুবাদ। শুধু প্রথম ভাষা বদলালে আগের মতো বাঁয়ে অনুবাদ, ডানে আরবি।
- [ ] ট্যাবলেট খাড়া → ফোনের মতো একটার নিচে আরেকটা।
- [ ] ছোট ফোন (৩৬০dp): অ্যাপ বারের শিরোনাম কেটে "…" হয়, বাটন আর আইকন ঢাকা পড়ে না।
- [ ] ডার্ক মোড: বাটন, লেবেল, দাগ, মেসেজ পড়া যায়।
- [ ] মিনি সেটিংস থেকে "আরবি দেখান" বন্ধ → আরবি ছাড়া দুই অনুবাদ ঠিক দেখায়।
- [ ] TalkBack/VoiceOver: বাটন পড়ে "অনুবাদের ভাষা: বাংলা, English"; সুইচের সারি এক জিনিস হিসেবে পড়ে।

## অ্যানালিটিক্স (DebugView)
- বাটন চাপলে `reader_translation_open{book_id, book_slug}`। বিষয়ভিত্তিক তালিকায় `book_id`/`book_slug` নেই।
- একক তালিকায় ভাষা ট্যাপ → `reader_translation_apply{translation_layout: single, first_language, book_id, book_slug}`।
- পাশাপাশিতে "ঠিক আছে" → `reader_translation_apply{translation_layout: side_by_side, first_language, second_language}`।
- চালু থাকা পাশাপাশি বন্ধ করলে `translation_layout: single`। "বাতিল করুন", ✕, না-মেলা ভাষায় ট্যাপ করলে কিছু যায় না।
- প্রতিটা হাদিসের অনুবাদ লোডের জন্য আলাদা ইভেন্ট নেই। শিটে `screen_view` নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "রিডারের অনুবাদের ভাষা" সেকশন।

## জানা সীমাবদ্ধতা
- কোন হাদিসের সাথে কোনটা মিলবে, সেই আসল তালিকা এখনো ডেটাবেস টিম দেয়নি। ডেমো তালিকা লাইভ API-তে নমুনা মিলিয়ে বানানো (প্রতি জোড়া ভাষায় ~৭৫টা হাদিস)।
- একই নম্বরের বইয়েও মাঝে মাঝে নম্বর সরে যায়। তাই দুই ভাষার আরবি মিলিয়ে দেখা হয়, না মিললে ওই হাদিসে অনুবাদ দেখায় না।
- মুসলিম আর বাকি বইয়ে এখন কোনো ভাষা মেলে না। ইন্দোনেশিয়ান কোনো বইয়ে মেলে না।
- অধ্যায়, পরিচ্ছেদ আর ফুটনোট অ্যাপের ভাষাতেই থাকে। শুধু বর্ণনাকারী আর অনুবাদ বদলায়।
- হাদিস ডিটেইলস, কপি আর টেক্সট শেয়ারে শুধু অ্যাপের ভাষার অনুবাদ।
- ডাউনলোড না থাকা বইয়ে প্রতিটা দেখা হাদিসের জন্য একটা করে API কল।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
