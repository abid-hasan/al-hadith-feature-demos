# পার্সোনাল সাজেশন — টেস্টের ধাপ

ব্রাঞ্চ `feature/personal-suggestion` · ডেমো ১ (অ্যাপের ধরন: হোমের "এটাও পড়তে পারেন" কার্ড, "আগ্রহের বিষয়" পেজ, সেটিংসের সারি)

## চালানোর আগে
```bash
git checkout feature/personal-suggestion
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ নেই, কোনো ডেটাবেস বদলায়নি। ডেমো ডেটাও নেই: সব হাদিস আসে "বিষয়ভিত্তিক হাদিস"-এর আসল ডেটা থেকে (ডাউনলোড করা `subjectwise_<lang>.db` থাকলে সেখান থেকে, না থাকলে API থেকে)।
- অ্যাপের ভাষা বাংলা। প্রথমে নেট চালু রাখুন।
- একদম নতুন অবস্থা দেখতে অ্যাপ মুছে নতুন করে ইনস্টল করুন। বাছা বিষয়, পড়ার হিসাব আর খোলা সাজেশনের গণনা লোকাল ক্যাশে থাকে (`personal_suggestion_*` key), কোথাও sync হয় না।
- বই পড়ে "সম্প্রতি পড়ছেন" বা বুকমার্ক থেকে কারণ দেখতে "বিষয়ভিত্তিক হাদিস ডেটাবেস" ডাউনলোড থাকতে হবে। ডাউনলোড ছাড়া শুধু বিষয়ভিত্তিক পেজ থেকে পড়া আর কার্ড থেকে খোলা হাদিস গোনা হয়।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোম, কুইক বাটনের গ্রিডের নিচে | "এটাও পড়তে পারেন" কার্ড: কারণের লাইন, বইয়ের ব্যাজ, কিতাব, নম্বর, গ্রেড, অনুবাদের প্রথম ৩ লাইন, "পুরো হাদিস →" |
| নতুন ইউজারের হোম | একই কার্ডে "কোন বিষয়ের হাদিস পড়তে ভালো লাগে, বেছে নিন…" আর "আগ্রহের বিষয় বাছুন" বাটন |
| "আগ্রহের বিষয়" পেজ | ওপরে "কোনো বিষয় বাছা হয়নি" / "Nটি বিষয় বাছা হয়েছে" আর হিন্ট, নিচে বিষয়ভিত্তিক ক্যাটাগরির তালিকা (হাদিস সংখ্যা সহ, টিক বক্স), একদম নিচে "সেভ করুন" |
| সেটিংস → কন্টেন্ট সেটিংস | সবার নিচে "আগ্রহের বিষয়" সারি: বাছা বিষয়ের নাম (৩টার বেশি হলে "+N"), না থাকলে "কোনো বিষয় বাছা হয়নি" |

## ধাপগুলো
- [ ] নতুন ইনস্টল, নেট চালু → হোমে কুইক গ্রিডের নিচে প্রথমে একটু শিমার, তারপর "আগ্রহের বিষয় বাছুন" কার্ড। কুইক গ্রিডের ক্রম আগের মতোই (সাদাকা প্রথম সারিতে)।
- [ ] "আগ্রহের বিষয় বাছুন" → "আগ্রহের বিষয়" পেজ, ক্যাটাগরির তালিকা লোড হয়। "সেভ করুন" বন্ধ।
- [ ] "সাওম (রোযা)" আর "সালাত (নামায)"-এ টিক → ওপরে "২টি বিষয় বাছা হয়েছে", "সেভ করুন" চালু। আবার একটা টিক তুলে আগের অবস্থায় ফিরলে বাটন আবার বন্ধ।
- [ ] দুটোতে টিক রেখে "সেভ করুন" → "আগ্রহের বিষয় সেভ হয়েছে" টোস্ট, হোমে ফেরে। কার্ডে "আপনার বাছা বিষয়: সাওম (রোযা)" (বা সালাত), নিচে সেই বিষয়ের একটা হাদিস।
- [ ] কার্ডের হাদিসে ট্যাপ → সেই হাদিসের অধ্যায় খোলে, হাদিসটা সামনে। Back → হোমের কার্ডে নতুন হাদিস, এবার কারণ সম্ভবত অন্য বিষয়ের (বিষয়গুলো পালা করে আসে)।
- [ ] যে হাদিস একবার খুলেছেন, সেটা আর কার্ডে আসে না (কয়েকবার খুলে দেখুন)।
- [ ] হোম → বিষয়ভিত্তিক ট্যাব → অন্য একটা বিষয়, যেমন "আদব, আখলাক ও সামাজিক শিষ্টাচার" → কয়েকটা হাদিস স্ক্রল করে পড়ুন → হোমে ফিরুন। কার্ডে "আপনি সম্প্রতি আদব, আখলাক ও সামাজিক শিষ্টাচার নিয়ে পড়ছেন"।
- [ ] বিষয়ভিত্তিক ডেটাবেস ডাউনলোড করে কোনো বই থেকে (যেমন বুখারির রোযার অধ্যায়) কয়েকটা হাদিস পড়ুন → হোমে ফিরলে "সম্প্রতি …" লাইনে সেই বিষয়। ডেটাবেস ছাড়া বই পড়লে কারণ বদলায় না (জানা সীমা)।
- [ ] কিছু না বেছে শুধু বই পড়ুন/বুকমার্ক করুন (ডেটাবেস ডাউনলোড করা): কার্ডে হাদিস আসে, নিচে ছোট "আগ্রহের বিষয় বাছুন" লিংকও থাকে। বুকমার্কের বিষয় থেকে এলে লাইন "আপনি … নিয়ে হাদিস বুকমার্ক করেছেন"।
- [ ] গ্রেডের চিপে ট্যাপ → গ্রেডের ব্যাখ্যা থাকলে ডায়ালগ খোলে, না থাকলে কিছু হয় না।
- [ ] সেটিংস → কন্টেন্ট সেটিংস খুলুন → নিচে "আগ্রহের বিষয়" সারিতে "সাওম (রোযা), সালাত (নামায)"। ট্যাপ → একই পেজ, আগের টিক দেওয়া।
- [ ] সেখানে "সালাত (নামায)"-এর টিক তুলে "সেভ করুন" → টোস্ট, সেটিংসে ফেরে, সারিতে শুধু "সাওম (রোযা)"। হোমে ফিরলে কার্ড নতুন বাছাই মেনে চলে।
- [ ] চারটার বেশি বিষয় বেছে সেভ → সেটিংসের সারিতে ৩টা নাম আর "+N"।
- [ ] সব টিক তুলে সেভ → সেটিংসে "কোনো বিষয় বাছা হয়নি"। পড়ার হিসাব না থাকলে হোমে আবার "আগ্রহের বিষয় বাছুন" কার্ড।
- [ ] পেজে টিক বদলে সেভ না করে Back → কিছু সেভ হয় না।
- [ ] মিনি সেটিংস ড্রয়ার (রিডারের ⚙) আর ফিডের সেটিংসে "আগ্রহের বিষয়" সারি নেই।
- [ ] বিষয়ভিত্তিক ডেটাবেস ছাড়া বিমান মোডে অ্যাপ খুলুন → হোমে কার্ডটাই নেই (আগের API ক্যাশ থাকলে কার্ড আসতে পারে)। "আগ্রহের বিষয়" পেজ খুললে অফলাইনের নোটিশ আর "আবার চেষ্টা করুন"।
- [ ] ডেটাবেস ডাউনলোড করা অবস্থায় বিমান মোড → কার্ডে হাদিস আসে, পেজও লোড হয়। কার্ডের হাদিস খুলতে বই ডাউনলোড না থাকলে অ্যাপের আগের নিয়মে ডাউনলোড ম্যানেজার খোলে।
- [ ] অ্যাপের ভাষা English → কার্ড "You may also read", বিষয়ের নাম ইংরেজিতে, সেটিংসের সারিও। আরবি/উর্দু → RTL, তীর উল্টো দিকে, লেখা কাটে না।
- [ ] ভাষা বদলালে কার্ড কিছুক্ষণের মধ্যে নতুন ভাষার হাদিস আনে।
- [ ] ডার্ক মোড: কার্ড, ভেতরের হাদিসের বক্স, টিক বক্স আর বাটন পড়া যায়।
- [ ] ট্যাবলেট (পোর্ট্রেট আর ল্যান্ডস্কেপ): কার্ড কুইক গ্রিডের নিচে, ল্যান্ডস্কেপে গ্রিডের সমান চওড়া। পেজটা দুই কলামের গ্রিড।
- [ ] TalkBack/VoiceOver: টিক বক্সের সারি checked/unchecked পড়ে।
- [ ] দৈনিক নোটিফিকেশন আর নোটিফিকেশনের সময় আগের মতোই চলে, নোটিফিকেশনের হাদিস বাছা বিষয় দেখে আসে না।

## অ্যানালিটিক্স (DebugView)
- `suggestion_show`: কার্ডে নতুন হাদিস এলে একবার। `suggestion_reason` = `recent` / `picked` / `bookmark`, `subject_id`, সাথে হাদিস প্যারাম (`book_id`, `book_slug`, `hadith_ref`, `chapter_id`, `content_source`)।
- `suggestion_open`: কার্ডের হাদিসে ট্যাপ, একই প্যারাম। তারপর `reader_open{entry_point: personal_suggestion}`।
- `interest_topics_open`: `source` = `home_card` / `settings`। তারপর `screen_view{screen_name: interest_topics}`।
- `interest_topics_save`: `source`, `topic_count` (সব তুলে দিলে 0)।
- টিক দেওয়া-তোলায় আলাদা ইভেন্ট নেই। "আগ্রহের বিষয় বাছুন" কার্ড দেখানোয় কোনো ইভেন্ট নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "পার্সোনাল সাজেশন" সেকশন।

## জানা সীমাবদ্ধতা
- বই থেকে পড়া হাদিস আর বুকমার্ক কোন বিষয়ের, সেটা শুধু ডাউনলোড করা বিষয়ভিত্তিক ডেটাবেস থেকে জানা যায়। API-তে উল্টো খোঁজার উপায় নেই।
- "সম্প্রতি পড়ছেন" = শেষ ২০টা পড়া হাদিসে যে বিষয় সবচেয়ে বেশি। পড়ার হিসাব সর্বোচ্চ ৩০০টা হাদিস রাখে।
- কারণের লাইনের লেখা অস্থায়ী, প্রোডাক্ট টিম ঠিক করবে। বিষয়ের পুরো নাম দেখায় (যেমন "সাওম (রোযা)"), ডেমোর মতো ছোট নাম নয়।
- বাছা বিষয়গুলোর সব হাদিস পড়া হয়ে গেলে কার্ডটা আর দেখায় না।
- API থেকে আসলে একটা বিষয়ে এক পিকে সর্বোচ্চ ৮টা টপিক দেখে; সেগুলোর সব পড়া হলে পরের বিষয়ে যায়।
- `suggestion_show` হোম লোড হলেই যায়, কার্ড স্ক্রিনে দেখা গেছে কিনা দেখে না।
- নেট ছাড়া প্রথম অবস্থায় শিমার একটু দেখিয়ে তারপর কার্ড লুকায়।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
