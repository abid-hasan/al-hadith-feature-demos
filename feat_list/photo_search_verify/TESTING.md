# ছবি তুলে হাদিস যাচাই — টেস্টের ধাপ

ব্রাঞ্চ `feature/photo-search-verify` · PR #286 · ডেমো ১ (অ্যাপের ধরন: "পেস্ট করুন"-এর পাশে "ছবি থেকে", ছবি বাছার বটম শিট)

## চালানোর আগে
```bash
git checkout feature/photo-search-verify
flutter pub get && flutter gen-l10n
(cd ios && pod install)   # নতুন pod: ML Kit Text Recognition আর image_picker, Podfile.lock বদলেছে
flutter run
```
- নতুন প্যাকেজ `google_mlkit_text_recognition: ^0.17.1` (ফোনেই লেখা পড়ে) আর `image_picker: ^1.2.4` (ক্যামেরা আর গ্যালারি)।
- **iOS-এর সর্বনিম্ন ভার্সন 15.0 থেকে 15.5:** ML Kit 15.5-এর নিচে চলে না। Podfile-এর `platform` আর Runner-এর deployment target দুটোই বদলেছে।
- iOS: নতুন `NSCameraUsageDescription`। `NSPhotoLibraryUsageDescription`-এর লেখায় যাচাইয়ের কথা যোগ হয়েছে। লেখা ইংরেজিতে।
- Android: নতুন কোনো অনুমতি নেই। গ্যালারি খোলে সিস্টেমের photo picker দিয়ে, ক্যামেরা খোলে ফোনের ক্যামেরা অ্যাপ দিয়ে। "Verify Hadith" শেয়ার টার্গেট এখন ছবিও নেয় (`image/*`)।
- অ্যাপের ভাষা বাংলা। লেখা পড়া ফোনেই হয়, নেট লাগে না। কিন্তু "যাচাই করুন" আগের মতো শুধু অনলাইনে।
- **যাচাই পেজে ঢোকার পথ:** `development`-এ হোমের "যাচাই" শর্টকাট আর সার্চ পেজের লিংক লুকানো (`RESTORE_HADITH_VERIFY`)। তাই:
  - Android: যেকোনো অ্যাপ থেকে একটু লেখা বা একটা ছবি শেয়ার করে "Verify Hadith" বাছুন।
  - iOS (আর Android-এও চাইলে): `lib/presentation/home/ui/book_list/home_small_dashboard.dart`-এ `RESTORE_HADITH_VERIFY`-এর লাইনগুলো শুধু নিজের মেশিনে আনকমেন্ট করে চালান। কমিট করবেন না।
- কয়েকটা ছবি রেখে দিন: বাংলা ফেসবুক পোস্টের স্ক্রিনশট, শুধু ইংরেজি লেখার পোস্টার, লেখা ছাড়া একটা ছবি (প্রাকৃতিক দৃশ্য)।
- **আগে জেনে রাখুন:** ML Kit বাংলা হরফ পড়ে না। তাই এখন বাংলা ছবি দিলেও "ছবি থেকে এখনো বাংলা লেখা পড়া যায় না" মেসেজ আসবে, লেখা ঘরে বসবে না। কোন রিডার নেওয়া হবে, সেটা টিমের সিদ্ধান্ত (নিচে "জানা সীমাবদ্ধতা")।

## ধাপগুলো
- [ ] যাচাই পেজ খুলুন → ঘরের নিচে ডানে "ছবি থেকে" আর "পেস্ট করুন"। "পেস্ট করুন" আগের মতো কাজ করে।
- [ ] "ছবি থেকে" → শিট খোলে: শিরোনাম, "ছবি তুলুন", "গ্যালারি থেকে নিন", নিচে "বাতিল করুন"। কীবোর্ড খোলা থাকলে বন্ধ হয়।
- [ ] "বাতিল করুন" আর শিটের বাইরে ট্যাপ → শিট বন্ধ, কিছু বদলায় না।
- [ ] "গ্যালারি থেকে নিন" → সিস্টেমের ছবি বাছার পেজ, কোনো অনুমতি চায় না (Android আর iOS দুটোতেই)। কিছু না বেছে ফিরে এলে কিছু হয় না, কোনো মেসেজ নেই।
- [ ] বাংলা স্ক্রিনশট বাছুন → ঘরের ওপর "ছবি থেকে লেখা পড়া হচ্ছে…" দেখায়, তখন "ছবি থেকে", "পেস্ট করুন" আর "যাচাই করুন" বন্ধ থাকে → তারপর টোস্ট "ছবি থেকে এখনো বাংলা লেখা পড়া যায় না। লেখাটি পেস্ট করুন বা টাইপ করুন।" ঘরের আগের লেখা যেমন ছিল থাকে।
- [ ] শুধু ইংরেজি পোস্টার → একই টোস্ট (লেখা পাওয়া গেছে, বাংলা নেই)।
- [ ] লেখা ছাড়া ছবি → টোস্ট "ছবিতে কোনো লেখা পাওয়া যায়নি। লেখা পরিষ্কার দেখা যায় এমন আরেকটা ছবি দিন।"
- [ ] "ছবি তুলুন" (Android) → ফোনের ক্যামেরা অ্যাপ খোলে, অনুমতি চায় না। ছবি তুলে OK → পড়ার লেখা, তারপর ওপরের মতো মেসেজ। ক্যামেরা থেকে ফিরে এলে (না তুলে) কিছু হয় না।
- [ ] "ছবি তুলুন" (iPhone, নতুন ইনস্টল) → সিস্টেম প্রম্পটে ক্যামেরার অনুমতি চায়, লেখা `NSCameraUsageDescription`-এর। Allow → ক্যামেরা খোলে।
- [ ] iPhone: প্রম্পটে Don't Allow (বা সেটিংস থেকে ক্যামেরা বন্ধ) → "ছবি তুলুন" → টোস্ট "ক্যামেরার অনুমতি বন্ধ আছে। অ্যাপ সেটিংস থেকে চালু করুন।"
- [ ] পড়া চলার সময় "ছবি থেকে" আবার চাপা যায় না, দুবার দ্রুত ট্যাপে একটাই শিট।
- [ ] Android: গ্যালারি থেকে একটা ছবি Share → লিস্টে "Verify Hadith" → অ্যাপ খুলে যাচাই পেজ, নিজে থেকে পড়া শুরু, তারপর মেসেজ। অ্যাপ বন্ধ থাকা অবস্থায় আর খোলা অবস্থায়, দুবারই দেখুন।
- [ ] Android: লেখা শেয়ার করে "Verify Hadith" আগের মতো কাজ করে (লেখা ঘরে বসে)।
- [ ] Android: অ্যাপের ভাষা English রেখে ছবি শেয়ার → টোস্ট "Hadith Verify is currently available only when the app language is Bangla", পেজ খোলে না।

## অ্যানালিটিক্স (DebugView)
- `hadith_verify_photo_read`: প্রতিটা দেওয়া ছবির পরে একটা। `outcome` = `text_found` / `no_text` / `no_bangla` / `permission_denied` / `failed`, `source` = `camera` / `gallery` / `share`, `query_length` শুধু `text_found`-এ। শিট বা পিকার বাতিল করলে কিছু যায় না।
- এখনকার রিডারে বাংলা আর ইংরেজি দুই ধরনের ছবিতেই `no_bangla` আসবে।
- `hadith_verify`-এ নতুন `source: photo` (ঘরের লেখা ছবি থেকে পড়া)। ঘর মুছলে বা নতুন পেস্ট করলে আবার `typed` (শেয়ার করা লেখায় খোলা পেজে `share`)। এখনকার রিডারে এটা দেখা যাবে না।
- ছবি বা লেখা কোনো ইভেন্টে যায় না, শুধু দৈর্ঘ্য।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "হাদিস যাচাই" সেকশন।

## জানা সীমাবদ্ধতা
- **সবচেয়ে বড় ঝুঁকি:** Google ML Kit-এর ফোনের রিডার শুধু Latin, Chinese, Devanagari, Japanese আর Korean পড়ে। বাংলা বা আরবি নেই। তাই এখন বাংলা ছবি থেকে যাচাই হয় না। পথ দুটো, টিম ঠিক করবে:
  - ফোনেই Tesseract (বাংলা মডেল অ্যাপে রাখতে হবে, অ্যাপ বড় হবে, মান মাঝারি)।
  - সার্ভারে লেখা পড়া (ভালো মান, কিন্তু ছবি সার্ভারে যাবে, প্রাইভেসি পলিসিতে লিখতে হবে)।
  - বদলাতে হবে শুধু `HadithVerifyModule`-এর এক লাইন (`MlKitVerifyPhotoTextReaderDataSource`-এর জায়গায় নতুন রিডার)। বাকি সব একই থাকবে।
- iOS-এর সর্বনিম্ন ভার্সন এখন 15.5। iOS 15.0–15.4-এর ফোন নতুন আপডেট পাবে না।
- ML Kit-এর Latin মডেল অ্যাপের সাথে যায়, Android আর iOS দুটোতেই অ্যাপ কয়েক MB বড় হবে। মাপা হয়নি।
- ML Kit-এর iOS pod arm64 সিমুলেটর সাপোর্ট করে না (বিল্ডের সময় Flutter-এর সতর্কবার্তা)। Apple Silicon Mac-এ iOS 26+ সিমুলেটরে অ্যাপটাই হয়তো চলবে না। আসল iPhone-এ টেস্ট করুন।
- মেসেজগুলো অ্যাপের সাধারণ টোস্ট। ডেমোর মতো "আরেকটা ছবি" বা "সেটিংস" বাটন টোস্টে নেই। অ্যাপে এমন snackbar নেই।
- ক্যামেরা খোলা অবস্থায় Android অ্যাপটা মেরে ফেললে তোলা ছবি হারায়, আবার তুলতে হয়।
- ২৫ MB-এর বড় শেয়ার করা ছবি নীরবে বাদ যায়। একসাথে কয়েকটা ছবি শেয়ার করা যায় না (একটা করে)।
- iOS-এ শেয়ার টার্গেট নেই, আগের মতোই।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
