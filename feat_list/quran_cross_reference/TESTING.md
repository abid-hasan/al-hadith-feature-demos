# কুরআনের সাথে ক্রস-রেফারেন্স — টেস্টের ধাপ

ব্রাঞ্চ `feature/quran-cross-reference` · PR #264 · ডেমো ১ (`html/demo1.html`, "অ্যাপের ধরন")

## চালানোর আগে
```bash
git checkout feature/quran-cross-reference
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন কোনো প্যাকেজ বা পারমিশন নেই, তাই `pod install` লাগবে না। `pubspec.yaml`-এ শুধু ডেমো অ্যাসেট ফোল্ডার যোগ হয়েছে।
- অ্যাপের ভাষা বাংলা রাখুন। ডেমো ডেটায় শুধু বাংলা আর ইংরেজি আছে।
- অফলাইন টেস্টের জন্য সহীহ বুখারী আগে ডাউনলোড করে রাখুন।
- হাদিসে যাওয়ার সহজ উপায়: হোমে "জাম্প" → সহীহ বুখারী → হাদিস নম্বর দিন → "হাদিসে যান"।

## ধাপগুলো
- [ ] বুখারী ১৮৯৪ খুলুন → কার্ডের নিচে পাতলা দাগ, তার নিচে বইয়ের আইকনসহ "আয়াত" চিপ।
- [ ] পাশের ১৮৯৩ আর ১৮৯৫ দেখুন → চিপ নেই, দাগও নেই, কার্ড আগের মতো।
- [ ] ১৮৯৪-এর চিপে ট্যাপ → নিচ থেকে শিট। শিরোনাম "কুরআনের আয়াত", নিচে "সহীহ বুখারী · হাদিস: ১৮৯৪"।
- [ ] শিটের ভেতরে দেখুন → "সম্পর্কিত আয়াত" লেবেল, আরবি, বাংলা অর্থ, "সূরা আল-বাকারা, আয়াত ১৮৩", নিচে "কপি" আর "শেয়ার"।
- [ ] শিট নিচে টেনে নামানোর চেষ্টা করুন → নামে না (ড্র্যাগ বন্ধ)। ✕ বা শিটের বাইরে ট্যাপ করুন → বন্ধ হয়।
- [ ] চিপে খুব দ্রুত দুবার ট্যাপ করুন → শিট একবারই খোলে।
- [ ] বুখারী ৩২ → চিপে "আয়াত ২"। শিটে দুটো আলাদা বাক্স, প্রথমে আল-আনআম ৮২, তারপর লুকমান ১৩, দুটোতেই "হাদিসে উল্লেখিত আয়াত"।
- [ ] বুখারী ৫০ আর ৪৪৭৪ → একটা করে আয়াত, লেবেল "হাদিসে উল্লেখিত আয়াত"।
- [ ] শিটে "কপি" চাপুন → "কপি হয়েছে" টোস্ট। অন্য অ্যাপে পেস্ট করুন → আরবি, অর্থ আর রেফারেন্স, মাঝে ফাঁকা লাইন।
- [ ] শিটে "শেয়ার" চাপুন → ফোনের শেয়ার মেনুতে একই লেখা।
- [ ] চিপের বাইরে কার্ডে ট্যাপ করে "হাদিসের বিস্তারিত" খুলুন → হাদিস কার্ডের ঠিক পরে "সম্পর্কিত আয়াত" অংশ। কার্ডে কোনো চিপ নেই।
- [ ] বুখারী ৩২-এর বিস্তারিত → অংশে দুটো আয়াত, মাঝে একটা দাগ। কপি/শেয়ার শিটের মতোই কাজ করে।
- [ ] বিস্তারিত পেজে আয়াত নেই এমন হাদিসে সোয়াইপ করুন → অংশটা নেই, বাড়তি ফাঁকা জায়গাও নেই।
- [ ] সেটিংসে "আরবি ফন্ট" আর "আরবি ফন্ট সাইজ" বদলান → আয়াতের আরবিও একই ফন্ট আর সাইজে আসে। প্রতিটা ফন্টে উসমানি চিহ্ন (ছোট মীম, ছোট আলিফ, ওয়াসলা) ভাঙছে কিনা দেখুন।
- [ ] "অনুবাদ ফন্ট সাইজ" বদলান → আয়াতের অর্থের সাইজও বদলায়।
- [ ] "আরবি দেখান" বন্ধ করুন → শিটে আর বিস্তারিত অংশে আয়াতের আরবি লুকায়। তখন "কপি" করুন → পেস্টে তবু আরবি থাকে।
- [ ] বুখারী ডাউনলোড করা অবস্থায় ইন্টারনেট বন্ধ করুন, অ্যাপ বন্ধ করে আবার খুলুন → একই হাদিসে চিপ, শিট আর বিস্তারিত অংশ সব আসে।
- [ ] ডাউনলোড না করা অবস্থায় অনলাইনে বুখারী পড়ুন → একই হাদিসে চিপ আসে।
- [ ] ভাষা ইংরেজি করুন → চিপ "Verse" / বুখারী ৩২-এ "2 verses"। শিট "Quran verses", অর্থ Saheeh International-এর, রেফারেন্স "Surah Al-Baqarah, verse 183"। বিস্তারিত অংশের নাম "Related verses"।
- [ ] ভাষা আরবি বা উর্দু (RTL) বা অন্য যেকোনো ভাষা করুন → কোথাও চিপ বা অংশ নেই, কোনো এরর নেই।
- [ ] আবার বাংলায় ফিরুন → রিস্টার্ট ছাড়াই চিপ ফিরে আসে।
- [ ] বিষয়ভিত্তিক তালিকা বা পড়ার প্ল্যানের রিডারে এই হাদিসগুলো এলে → সেখানেও চিপ।
- [ ] বুকমার্ক/পিন/সর্বশেষ পড়া থেকে রিডারে গেলে → রিডারে চিপ আসে। কিন্তু বুকমার্ক পেজের নিজের কার্ড, সার্চ, ফিড, ডেইলি হাদিস, ফ্ল্যাশকার্ডে চিপ নেই।
- [ ] কার্ডের ⋮ থেকে ছবি হিসেবে শেয়ার করুন → ছবিতে চিপ বা দাগ নেই।
- [ ] ডার্ক মোড → চিপের হালকা সবুজ পটভূমি আর লেখা পড়া যায়। শিটের আয়াত-বাক্স পেজের রঙে, বর্ডার নেই। গ্রেডের রং চিপে আসে না।
- [ ] ট্যাবলেট (portrait আর landscape) → চিপ হাদিসের লেখার সাথে এক লাইনে, শিট সর্বোচ্চ ৫২০ চওড়া মাঝখানে, বিস্তারিত অংশ অন্য অংশের কার্ডের মতো।
- [ ] স্ক্রিন রিডার চালু → চিপে "আয়াত ২, কুরআনের আয়াত দেখুন" (একটা হলে "আয়াত, কুরআনের আয়াত দেখুন"), ✕-তে "বন্ধ করুন"।

## অ্যানালিটিক্স (DebugView)
- `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "কুরআনের আয়াত (ক্রস-রেফারেন্স)" অংশ ধরে চলুন।
- চিপে ট্যাপ → `quran_ayah_open{book_id, book_slug, hadith_ref, chapter_id, content_source, ayah_count}`। বুখারী ৩২-এ `book_id: 1, book_slug: bukhari, ayah_count: 2`। ১ সেকেন্ডের মধ্যে দ্বিতীয় ট্যাপে কিছু আসে না।
- "কপি" → `quran_ayah_copy{হাদিস-প্যারাম সেট, ayah_key, ayah_kind, source}`। বুখারী ৩২-এর প্রথম আয়াতে `ayah_key: 6:82, ayah_kind: quoted`; ১৮৯৪-এ `2:183, related`।
- "শেয়ার" → `share{content_type: quran_ayah, item_id: <surah:ayah>, method: system, source, book_slug: bukhari}`। শেয়ার মেনু বাতিল করলেও আসে।
- `source`: শিট থেকে `ayah_sheet`, বিস্তারিত পেজ থেকে `hadith_details`।
- বিস্তারিত পেজে অংশটা দেখা গেলে আলাদা কোনো ইভেন্ট নেই। বাংলা-ইংরেজি ছাড়া অন্য ভাষায় কোনো ইভেন্টই আসে না।

## জানা সীমাবদ্ধতা
- সব জোড়া ডেমো, আলেমদের যাচাই বাকি (`"status": "demo_pending_scholarly_review"`)। ডেমো ফাইল রিলিজ বিল্ডেও যাবে।
- আয়াতের অর্থ alquran.cloud থেকে (বাংলা মুহিউদ্দীন খান, ইংরেজি Saheeh International)। আসল উৎস আর লাইসেন্স প্রোডাক্টকে ঠিক করতে হবে। ইংরেজি ২:১৮৩-এর শেষে " -" ইচ্ছা করে রাখা।
- ডেটা না পড়া গেলে চিপ শুধু আসে না, কোনো এরর বা লোডিং দেখায় না (লগে যায়)।
- জোড়া মেলে বইয়ের id আর হাদিস id দিয়ে। অন্য বইয়ে ভাষাভেদে id আলাদা হলে আসল ডেটায় বদল লাগবে।
- "শিক্ষণীয় বিষয়" অংশ এখন লুকানো, তাই আয়াতের অংশ সরাসরি হাদিস কার্ডের পরে বসে।
- `feature/shan-e-wurud`-এর সাথে বিস্তারিত পেজ আর রিডারের দুই লিস্ট ফাইলে একই জায়গা বদলায়, merge-এ মেলাতে হবে।
- ফোন বা সিমুলেটরে এখনো চালানো হয়নি।
