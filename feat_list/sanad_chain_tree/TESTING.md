# সনদ চেইন ট্রি — টেস্টের ধাপ

ব্রাঞ্চ `feature/sanad-chain-tree` · ডেমো ১ (অ্যাপের ধরন: বিস্তারিত পেজে "সনদ" সেকশন, আলাদা ট্রি পেজ, রাবির বটমশিট)

## চালানোর আগে
```bash
git checkout feature/sanad-chain-tree
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন কোনো প্যাকেজ নেই। ট্রি আঁকা হয়েছে সাধারণ Flutter উইজেট দিয়ে (`InteractiveViewer` আর `CustomPaint`)।
- ডেমো ডেটা অ্যাপের সাথেই আছে: `assets/demo/sanad_chain_tree/narrators.json` (রাবির তালিকা, স্থির id সহ) আর `chains.json` (হাদিস ধরে সূত্রগুলো)। নেট লাগে না।
- ডেটা আছে শুধু **সহীহ বুখারী ১, ২ আর ৬**-এ, আর শুধু **বাংলা আর English**-এ। অন্য হাদিস বা অন্য ভাষায় সেকশনই আসবে না।
- বুখারী বই ডাউনলোড থাকুক বা অনলাইনে পড়ুন, দুটোতেই চলার কথা। দুটোই একবার দেখুন।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| বুখারী → অধ্যায় → হাদিস কার্ডে ট্যাপ → বিস্তারিত পেজ | হাদিস কার্ডের নিচে "সনদ" কার্ড। ডানে "৩টি সূত্র · ১১ জন রাবি" |
| "সনদ" কার্ড | নামের লাইন, প্রতিটা নামের নিচে স্তর (সাহাবি, তাবেঈ …), "এখান থেকে ৩টি সূত্রে ভাগ হয়েছে", পাশাপাশি সূত্রের বাক্স, নিচে "পুরো সনদ দেখুন" |
| "পুরো সনদ" পেজ | অ্যাপ বারে "পুরো সনদ", নিচে "সহীহ বুখারী · হাদিস: ১"। ওপরে "৩টি সূত্র · ১১ জন রাবি · নামে ট্যাপ করে পরিচিতি দেখুন"। ডান-নিচে বড়/ছোট/পুরো ট্রি বাটন আর শতাংশ |
| রাবির বটমশিট | নাম, স্তর, পুরো নাম, মৃত্যু, কোথায় ছিলেন, এই সনদে শুনেছেন/শুনিয়েছেন, কাদের কাছে শিখেছেন, নির্ভরযোগ্যতার মতামত, "বন্ধ করুন" |

## ধাপগুলো
- [ ] বুখারী ১-এর বিস্তারিত পেজ → হাদিস কার্ডের নিচে "সনদ" কার্ড। উপরে থেকে: উমর ইবনুল খাত্তাব (রাঃ) → আলকামা → মুহাম্মাদ আত-তাইমি → ইয়াহইয়া আল-আনসারি, তারপর "এখান থেকে ৩টি সূত্রে ভাগ হয়েছে"।
- [ ] তিনটা বাক্সে: সুফিয়ান ইবনু উয়াইনা → আল-হুমাইদি, মালিক ইবনু আনাস → আল-কানাবি, আব্দুল ওয়াহহাব → কুতাইবা ইবনু সাঈদ। শেষে ইমাম বুখারি, স্তর "বইয়ের ইমাম"। নামগুলো বিন্দু আর দাগে জোড়া।
- [ ] প্রথমবার পেজ খুললে কার্ডের জায়গায় এক ঝলক ধূসর শিমার আসতে পারে, তারপর নাম। খুব দ্রুত হলে চোখে নাও পড়তে পারে।
- [ ] "ইয়াহইয়া ইবনু সাঈদ আল-আনসারি" নামে ট্যাপ → বটমশিট। পুরো নাম, "১৪৩ হিজরি", "মদিনা", এই সনদে শুনেছেন: মুহাম্মাদ ইবনু ইবরাহিম আত-তাইমি; শুনিয়েছেন: সুফিয়ান, মালিক, আব্দুল ওয়াহহাব (আলাদা লাইনে)।
- [ ] একই শিটে "কাদের কাছে শিখেছেন": আনাস ইবনু মালিক (রাঃ), সাঈদ ইবনুল মুসাইয়্যিব, মুহাম্মাদ ইবনু ইবরাহিম আত-তাইমি। নিচে "নির্ভরযোগ্যতা নিয়ে মুহাদ্দিসদের মতামত" আর "মতামতের সারাংশ আলেমদের যাচাইয়ের অপেক্ষায়…"। কোথাও গ্রেডের রং নেই।
- [ ] "বন্ধ করুন", ওপরের ✕, শিটের বাইরে ট্যাপ আর Back → শিট বন্ধ। নিচে টেনে বন্ধ হয় না (অ্যাপের অন্য শিটের মতো)।
- [ ] "আলকামা ইবনু ওয়াক্কাস" → মৃত্যু "খলিফা আব্দুল মালিকের সময়ে"। "উমর ইবনুল খাত্তাব (রাঃ)" → "এই সনদে শুনেছেন" আর "কাদের কাছে শিখেছেন" সারি নেই, বাকিগুলো আছে।
- [ ] বাক্সের ভেতরের নামে (যেমন "আল-কানাবি") ট্যাপ → সেই রাবির শিট।
- [ ] "পুরো সনদ দেখুন" → ট্রি পেজ। ওপরে উমর (রাঃ), নিচে ইমাম বুখারি, দুটো সবুজ বর্ডারে হালকা সবুজ। ইয়াহইয়া থেকে তিন ডালে ভাগ, শেষে আবার বুখারিতে মেলে। প্রথমে পুরো প্রস্থ দেখা যায়, ওপর থেকে শুরু।
- [ ] এক আঙুলে টেনে সরানো, দুই আঙুলে পিঞ্চ করে বড়-ছোট। "+" / "−" চাপলে মাঝখান ঘিরে বড়-ছোট হয়, নিচের শতাংশ বদলায় (৪০% থেকে ২২০% পর্যন্ত)। চার কোনার বাটন → পুরো ট্রি মাঝখানে।
- [ ] ট্রির কোনো নামে ট্যাপ → একই বটমশিট। টেনে সরানোর সময় ভুল করে শিট খোলে না।
- [ ] ট্রি পেজ থেকে Back → বিস্তারিত পেজ, স্ক্রল যেমন ছিল।
- [ ] বুখারী ২ → "১টি সূত্র · ৬ জন রাবি", আয়েশা (রাঃ) → উরওয়া → হিশাম → মালিক → আত-তিন্নিসি → ইমাম বুখারি। ভাগ নেই, তাই "পুরো সনদ দেখুন" বাটনও নেই।
- [ ] বুখারী ৬ → "৩টি সূত্র · ৯ জন রাবি"। আয-যুহরির পরে "২টি সূত্রে ভাগ" (ইউনুস / মা'মার), ইবনুল মুবারকে মেলে, আবার "২টি সূত্রে ভাগ" (আবদান / বিশর), শেষে বুখারি। ট্রি পেজে মা'মার থেকে শুধু ইবনুল মুবারকে দাগ, ইবনুল মুবারক থেকে আবদান আর বিশরে।
- [ ] উবাইদুল্লাহর শিটে "মৃত্যু" সারি নেই (ডেটায় সাল দেওয়া নেই)।
- [ ] বুখারী ৩ বা অন্য বইয়ের হাদিস → "সনদ" কার্ড নেই, ফাঁকা জায়গাও নেই।
- [ ] বিস্তারিত পেজে ডানে-বাঁয়ে সোয়াইপ করে ১ → ২ → ৩ → ... ৬ → প্রতিটা পাতায় নিজের সনদ, ভুল হাদিসের সনদ আসে না।
- [ ] অ্যাপের ভাষা English → বুখারী ১-এ "Sanad", "Routes: 3 · Narrators: 11", ইংরেজি নাম, "Full sanad" পেজ, শিটে "143 AH"।
- [ ] অ্যাপের ভাষা আরবি বা উর্দু → সেকশন নেই (ডেমো ডেটায় এই ভাষা নেই)। ভাষা বদলে আবার বাংলা → সেকশন ফেরে।
- [ ] ডার্ক মোড: কার্ড, বিন্দু-দাগ, "এখান থেকে … ভাগ হয়েছে" লেখা (সবুজ), বাক্স, ট্রির বক্স আর দাগ, জুম বাটন, শিট পড়া যায়।
- [ ] সেটিংসে অনুবাদের ফন্ট বড়-ছোট করলে "সনদ" শিরোনাম বাকি সেকশনের মতো বদলায়; নাম আর স্তরের লেখা অ্যাপের সাধারণ সাইজে থাকে।
- [ ] ছোট ফোন (৩৬০ প্রস্থ): পাশাপাশি বাক্সে লম্বা নাম ভেঙে দুই লাইনে যায়, বাইরে বেরোয় না। ট্রির বক্সে নাম দুই লাইনের বেশি হলে "…"।
- [ ] ট্যাবলেট (portrait আর landscape): "সনদ" কার্ড বাকি সেকশনের মাপে, ট্রি পেজ পুরো চওড়া, ঘোরালে ট্রি আবার প্রস্থে বসে।
- [ ] TalkBack/VoiceOver: নামগুলো বাটন হিসেবে পড়ে, ট্রির বক্স "নাম, স্তর" পড়ে, জুম বাটনে "বড় করুন" / "ছোট করুন" / "পুরো ট্রি দেখুন"।

## অ্যানালিটিক্স (DebugView)
- সেকশনের নামে ট্যাপ → `sanad_narrator_open{narrator_id, source: sanad_section}` + হাদিস-প্যারাম সেট (`book_id`, `book_slug`, `hadith_ref`, `chapter_id`, `content_source`)।
- "পুরো সনদ দেখুন" → `sanad_tree_open{route_count, narrator_count}` + হাদিস-প্যারাম সেট, তারপর `screen_view{screen_name: sanad_tree}`। বুখারী ১-এ ৩ আর ১১, বুখারী ৬-এ ৩ আর ৯।
- ট্রি পেজের নামে ট্যাপ → `sanad_narrator_open{source: sanad_tree}`।
- সেকশন শুধু দেখা গেলে, শিট বন্ধ করলে, জুম বা সরালে কোনো ইভেন্ট নেই। বটমশিটে `screen_view` নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "সনদ চেইন ট্রি" সেকশন।

## জানা সীমাবদ্ধতা
- সব ডেটা ডেমো, আলেমরা যাচাই করেননি। রাবির তথ্য খুব কম রাখা। নির্ভরযোগ্যতার মতামত কারো নামে নেই, শুধু "যাচাইয়ের অপেক্ষায়" লেখা।
- ডেমো ডেটা অ্যাপের সাথে বান্ডেল করা, তাই "সনদ আনা যায়নি … আবার চেষ্টা করুন" নোটিশ এখন হাতে আনা যায় না। আসল API এলে বিমান মোডে দেখতে হবে।
- আসল ডেটা এলে বদলাতে হবে শুধু `SanadChainDemoDataSource` (`lib/data/data_sources/sanad_chain_data_source.dart`), রেজিস্টার হয় `lib/core/di/modules/sanad_chain/sanad_chain_module.dart`-এ।
- বুখারী ১-এর তিন সূত্রের দুটো আসলে বুখারির অন্য জায়গার সনদ (একই হাদিস, ভিন্ন সূত্র), ডেমোর মতোই রাখা।
- সাহাবিদের "কাদের কাছে শিখেছেন" দেখায় না, কারণ ডেটায় শিক্ষক হিসেবে শুধু রাবিদের id থাকে।
- ট্রিতে রাবির জায়গা ঠিক হয় সাহাবি থেকে ধাপ গুনে। খুব জটিল সনদে দাগ একে অপরকে কাটতে পারে।
