## চালানোর আগে
```bash
git checkout feature/shan-e-wurud
flutter pub get && flutter gen-l10n
flutter run
# ব্যাজ দেখতে (শুধু debug/profile):
flutter run --dart-define=HADITH_CONTEXT_PREVIEW_BADGE=true
```
- নতুন কোনো প্যাকেজ নেই, তাই `pod install` লাগবে না। নতুন কোনো permission-ও নেই।
- অ্যাপের ভাষা বাংলা রাখুন। ডেমো ডেটা শুধু বাংলায়।

## ধাপগুলো
- [ ] বুখারীর প্রথম অধ্যায় খুলুন → ১ নম্বর হাদিসের কার্ডে আরবির ওপরে হালকা সবুজ "প্রেক্ষাপট" বক্স। দুই লাইনের সংক্ষেপ, নিচে "আরো পড়ুন" ⌄।
- [ ] পরের হাদিসগুলো দেখুন → কার্ড আগের মতো, কোনো ফাঁকা জায়গা নেই।
- [ ] "আরো পড়ুন" ট্যাপ → বক্স খোলে। কে / কোথায় / কী ঘটেছিল আলাদা সারিতে, তারপর নোট, তারপর দাগের নিচে "সূত্র: …"। "আলেমদের যাচাই করা" ব্যাজ নেই।
- [ ] "কম দেখান" ট্যাপ → বক্স আবার দুই লাইনে ফেরে।
- [ ] বক্স খোলা রেখে অনেক নিচে স্ক্রল করে ফিরে আসুন → বক্স খোলাই থাকে।
- [ ] বক্সের লেখার ওপর ট্যাপ করুন (বাটনে নয়) → কিছু খোলে না, কার্ডের নিজের ট্যাপ চলে না।
- [ ] "জাম্প" দিয়ে বুখারী ১০, ২৪৪৩, ৩৬৭৩-এ যান → প্রতিটাতে বক্স। খুললে ১০ আর ৩৬৭৩-এ "কোথায়" সারি নেই।
- [ ] ১ নম্বর হাদিসের ⋮ মেনু → "হাদিসের বিস্তারিত" → অধ্যায়ের কার্ডের পরে "প্রেক্ষাপট" নামে আলাদা কার্ড, পুরো খোলা, কোনো বাটন নেই। নিচের হাদিস কার্ডে কোনো বক্স নেই।
- [ ] বিস্তারিত পেজে পাশের হাদিসে সোয়াইপ করুন → প্রেক্ষাপট না থাকলে সেকশন আসে না, ফাঁকা জায়গাও না।
- [ ] ১ নম্বর হাদিসের ⋮ মেনু → "সম্পূর্ণ হাদিস কপি" → টোস্ট আগের মতোই "সম্পূর্ণ হাদিস কপি হয়েছে"। কোথাও paste করুন → ওপরে "প্রেক্ষাপট: …" লাইন নেই, লেখা আগের মতো। (কোডে `HadithContextConfig.includeInShare = false`।)
- [ ] একই হাদিসে "স্ক্রিনশট শেয়ার" → ছবিতে বক্স বা "প্রেক্ষাপট:" লাইন নেই, ছবি আগের মতো। বিস্তারিত পেজ থেকেও একই।
- [ ] "আরবি কপি" আর "অনুবাদ কপি" → আগের মতো।
- [ ] বিষয়ভিত্তিক তালিকা থেকে বুখারী ১ খুলুন → কার্ডে বক্স নেই।
- [ ] সার্চে বুখারী ১ খুঁজুন → রেজাল্ট কার্ডে বক্স নেই। সেখান থেকে বিস্তারিত পেজ খুললে "প্রেক্ষাপট" সেকশন আসে (এই পেজে সেকশন সবসময় আসে)।
- [ ] পড়ার প্ল্যানের রিডারে বুখারীর প্রথম অধ্যায় → ১ নম্বর হাদিসে বক্স আসে (একই অধ্যায়-লিস্ট)।
- [ ] অ্যাপের ভাষা ইংরেজি করুন → কোথাও বক্স বা সেকশন নেই। আবার বাংলা করুন → বক্স ফিরে আসে।
- [ ] নেট বন্ধ করে অ্যাপ বন্ধ করে আবার খুলুন → ডাউনলোড করা বুখারীতে বক্স আর বিস্তারিত পেজের সেকশন আসে।
- [ ] ডার্ক মোড → বক্সের tint, শিরোনামের সবুজ, নোটের ধূসর আর সূত্রের ওপরের দাগ ঠিক দেখায়।
- [ ] পড়ার ফন্ট বড় করুন → বক্সের লেখা বদলায় না (শুধু বিস্তারিত পেজের সেকশনের শিরোনাম বদলায়)।
- [ ] ট্যাবলেটে আড়াআড়ি (আরবি আর অনুবাদ পাশাপাশি) → বক্স দুই কলামের ওপরে পুরো চওড়া। বিস্তারিত পেজে সেকশন কার্ড পাশের কার্ডের সাথে লাইনে।
- [ ] TalkBack / VoiceOver → "প্রেক্ষাপট", সংক্ষেপ আর "আরো পড়ুন" বাটন পড়ে। বাটন ট্যাপ করা সহজ।
- [ ] `--dart-define=HADITH_CONTEXT_PREVIEW_BADGE=true` দিয়ে debug চালান → খোলা বক্স আর বিস্তারিত পেজে সূত্রের পাশে "আলেমদের যাচাই করা" ব্যাজ।
- [ ] define ছাড়া, বা release বিল্ডে define দিয়ে → ব্যাজ আসে না।
- [ ] (ঐচ্ছিক, শুধু লোকালে, কমিট করবেন না) `hadith_contexts_bn.json` কপি করে `hadith_contexts_ur.json` বানান, নতুন করে `flutter run` দিন, উর্দুতে বুখারী ১ খুলুন → লেবেল ডানে, লেখা RTL-এ ঠিক।

## অ্যানালিটিক্স (DebugView)
- "আরো পড়ুন" → `hadith_context_toggle{book_id: 1, book_slug: bukhari, hadith_ref, chapter_id, content_source, expanded: true}`।
- "কম দেখান" → একই ইভেন্ট, `expanded: false`।
- বক্স শুধু দেখা গেলে, বা বিস্তারিত পেজের খোলা সেকশনে কোনো ইভেন্ট নেই।
- "সম্পূর্ণ হাদিস কপি" → আগের মতো একটা `hadith_copy{copy_type: full}`। "স্ক্রিনশট শেয়ার" → আগের `share`।
- নতুন প্যারাম নেই, `expanded` আগে থেকেই আছে। বিস্তারিত: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "প্রেক্ষাপট (শানে উরুদ)" সেকশন।

## জানা সীমাবদ্ধতা
- ডেমো ডেটা মাত্র ৪টা হাদিস, আলেমদের যাচাই করা নয়। বুখারী ১-এর প্রেক্ষাপট নিয়ে মতভেদ আছে, তাই "নিশ্চিত নয়" নোট।
- ডেটা শুধু বাংলায়। অন্য ভাষায় বক্স নেই।
- কপি আর স্ক্রিনশটে প্রেক্ষাপটের লাইন বন্ধ (`includeInShare = false`)। এক লাইন `true` করলে চালু হবে, তখন নতুন টোস্ট "সম্পূর্ণ হাদিস কপি হয়েছে, প্রেক্ষাপটের লাইনসহ"।
- আসল ডেটা বা API এখনো নেই, ডেটা অ্যাপে বান্ডেল করা JSON থেকে আসে।
- বক্স খোলা আছে কি না, তা শুধু অ্যাপ চালু থাকা পর্যন্ত মনে থাকে।
- `feature/quran-cross-reference`-এর সাথে `hadith_details_page.dart` আর `hadith_list_item.dart`-এ কনফ্লিক্ট হতে পারে।
- ফোন বা সিমুলেটরে এখনো চালানো হয়নি।
