## চালানোর আগে
```bash
git checkout feature/shan-e-wurud
```

## ধাপগুলো
- [ ] বুখারীর প্রথম অধ্যায় খুলুন → ১ নম্বর হাদিসের কার্ডে আরবির ওপরে হালকা সবুজ "প্রেক্ষাপট" বক্স। দুই লাইনের সংক্ষেপ, নিচে "আরো পড়ুন" ⌄।
- [ ] পরের হাদিসগুলো দেখুন → কার্ড আগের মতো, কোনো ফাঁকা জায়গা নেই।
- [ ] "আরো পড়ুন" ট্যাপ → বক্স খোলে। কে / কখন / কোথায় / কী ঘটেছিল / কী উদ্দেশ্যে আলাদা সারিতে, তারপর নোট, তারপর দাগের নিচে "সূত্র: …"। "আলেমদের যাচাই করা" ব্যাজ নেই। সনদ, তাহকিক বা ফিকহি দিক বক্সে আসে না।
- [ ] খোলা বক্সের নিচে "কম দেখান" ⌃-এর পাশে "হাদিসের বিস্তারিত" › লিংক। বক্স বন্ধ থাকলে লিংক নেই।
- [ ] "কম দেখান" ট্যাপ → বক্স আবার দুই লাইনে ফেরে।
- [ ] বক্স খোলা রেখে অনেক নিচে স্ক্রল করে ফিরে আসুন → বক্স খোলাই থাকে।
- [ ] বক্সের লেখার ওপর ট্যাপ করুন (বাটনে নয়) → কিছু খোলে না, কার্ডের নিজের ট্যাপ চলে না।
- [ ] "জাম্প" দিয়ে বুখারী ১০, ২৪৪৩, ৩৬৭৩-এ যান → প্রতিটাতে বক্স। খুললে ১০ আর ৩৬৭৩-এ "কোথায়" সারি নেই। তিনটাতেই "হাদিসের বিস্তারিত" লিংক নেই (সনদ, তাহকিক, ফিকহি দিক নেই বলে)।
- [ ] বুখারী ১-এর খোলা বক্সে "হাদিসের বিস্তারিত" ট্যাপ → বিস্তারিত পেজ খোলে, মেনুর "হাদিসের বিস্তারিত"-এর মতোই। পাশের হাদিসে সোয়াইপ করা যায়। খুব তাড়াতাড়ি দুবার ট্যাপ করলেও পেজ একবারই খোলে।
- [ ] ১ নম্বর হাদিসের ⋮ মেনু → "হাদিসের বিস্তারিত" → অধ্যায়ের কার্ড, তারপর হাদিস কার্ড (কোনো বক্স নেই), তার নিচে "প্রেক্ষাপট" নামে আলাদা কার্ড, পুরো খোলা। ক্রম: কে / কখন / কোথায় / কী ঘটেছিল / কী উদ্দেশ্যে, নোট, তারপর দাগ দিয়ে আলাদা "সনদ", "তাহকিক", "ফিকহি দিক" (প্রতিটার ছোট আইকন আর সবুজ শিরোনাম), শেষে "সূত্র: …"।
- [ ] "তাহকিক" অংশে হাদিস কার্ডের ওপরের গ্রেড চিপটাই (একই লেখা, একই রং), নিচে ছোট লেখা। চিপ ট্যাপ → কার্ডের গ্রেড চিপের মতোই তাহকিকের পপআপ, "ঠিক আছে" চাপলে বন্ধ। চিপ পুরো চওড়া হয় না।
- [ ] "ফিকহি দিক"-এ ৩টা পয়েন্ট, প্রতিটার আগে বুলেট। দুই লাইনের পয়েন্টে দ্বিতীয় লাইন বুলেটের নিচে না গিয়ে লেখার সাথে লাইনে।
- [ ] বুখারী ১০-এর বিস্তারিত পেজ → প্রেক্ষাপট কার্ডে শুধু কে / কী ঘটেছিল আর সূত্র। সনদ, তাহকিক, ফিকহি দিকের কোনো দাগ বা শিরোনাম নেই।
- [ ] বিস্তারিত পেজে পাশের হাদিসে সোয়াইপ করুন → প্রেক্ষাপট না থাকলে হাদিস কার্ডের নিচে সেকশন আসে না, ফাঁকা জায়গাও না।
- [ ] ১ নম্বর হাদিসের ⋮ মেনু → "সম্পূর্ণ হাদিস কপি" → টোস্ট আগের মতোই "সম্পূর্ণ হাদিস কপি হয়েছে"। কোথাও paste করুন → ওপরে "প্রেক্ষাপট: …" লাইন নেই, লেখা আগের মতো। (কোডে `HadithContextConfig.includeInShare = false`।)
- [ ] একই হাদিসে "স্ক্রিনশট শেয়ার" → ছবিতে বক্স বা "প্রেক্ষাপট:" লাইন নেই, ছবি আগের মতো। বিস্তারিত পেজ থেকেও একই।
- [ ] "আরবি কপি" আর "অনুবাদ কপি" → আগের মতো।
- [ ] বিষয়ভিত্তিক তালিকা থেকে বুখারী ১ খুলুন → কার্ডে বক্স নেই।
- [ ] সার্চে বুখারী ১ খুঁজুন → রেজাল্ট কার্ডে বক্স নেই। সেখান থেকে বিস্তারিত পেজ খুললে হাদিসের নিচে "প্রেক্ষাপট" সেকশন সব অংশসহ আসে (এই পেজে সেকশন সবসময় আসে)।
- [ ] পড়ার প্ল্যানের রিডারে বুখারীর প্রথম অধ্যায় → ১ নম্বর হাদিসে বক্স আসে (একই অধ্যায়-লিস্ট)। খুললে "হাদিসের বিস্তারিত" লিংক নেই, কারণ এখানে মেনুতেও "হাদিসের বিস্তারিত" নেই।
- [ ] অ্যাপের ভাষা ইংরেজি করুন → কোথাও বক্স বা সেকশন নেই। আবার বাংলা করুন → বক্স ফিরে আসে।
- [ ] নেট বন্ধ করে অ্যাপ বন্ধ করে আবার খুলুন → ডাউনলোড করা বুখারীতে বক্স আর বিস্তারিত পেজের সেকশন আসে।

## অ্যানালিটিক্স (DebugView)
- "আরো পড়ুন" → `hadith_context_toggle{book_id: 1, book_slug: bukhari, hadith_ref, chapter_id, content_source, expanded: true}`।
- "কম দেখান" → একই ইভেন্ট, `expanded: false`।
- খোলা বক্সের "হাদিসের বিস্তারিত" → `hadith_details_open{book_id: 1, book_slug: bukhari, hadith_ref, chapter_id, content_source, source: context_box}`। মেনুর "হাদিসের বিস্তারিত" আগের মতোই `source: more_menu`।
- বিস্তারিত পেজের তাহকিক অংশের চিপ → `grade_info_open{grade_id, grade_name, source: context_section}`। কার্ডের চিপ আগের মতোই `grade` / `validity`।
- বক্স শুধু দেখা গেলে, বা বিস্তারিত পেজের খোলা সেকশন দেখলে কোনো ইভেন্ট নেই।
- "সম্পূর্ণ হাদিস কপি" → আগের মতো একটা `hadith_copy{copy_type: full}`। "স্ক্রিনশট শেয়ার" → আগের `share`।
- নতুন প্যারাম নেই। `source`-এ দুটো নতুন মান: `context_box` আর `context_section`। বিস্তারিত: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "প্রেক্ষাপট (শানে উরুদ)" সেকশন।

## জানা সীমাবদ্ধতা
- ডেমো ডেটা মাত্র ৪টা হাদিস, আলেমদের যাচাই করা নয়। বুখারী ১-এর প্রেক্ষাপট নিয়ে মতভেদ আছে, তাই "নিশ্চিত নয়" নোট। সনদ, তাহকিক আর ফিকহি দিকের লেখাও ডেমো, শুধু বুখারী ১-এ।
- সনদ শুধু ছোট সারাংশ। পুরো সনদ গাছের মতো দেখানো আলাদা ফিচার (#৪২), এখান থেকে সেখানে যাওয়ার লিংক এখনো নেই।
- বক্সের লিংক বিস্তারিত পেজের ওপর থেকে খোলে, সেকশন পর্যন্ত নিজে থেকে স্ক্রল করে না। লম্বা হাদিসে সেকশন দেখতে নিচে স্ক্রল করতে হয়।
- ডেটা শুধু বাংলায়। অন্য ভাষায় বক্স নেই।
- কপি আর স্ক্রিনশটে প্রেক্ষাপটের লাইন বন্ধ (`includeInShare = false`)। এক লাইন `true` করলে চালু হবে, তখন নতুন টোস্ট "সম্পূর্ণ হাদিস কপি হয়েছে, প্রেক্ষাপটের লাইনসহ"।
- আসল ডেটা বা API এখনো নেই, ডেটা অ্যাপে বান্ডেল করা JSON থেকে আসে।
- বক্স খোলা আছে কি না, তা শুধু অ্যাপ চালু থাকা পর্যন্ত মনে থাকে।
- `feature/quran-cross-reference`-এর সাথে `hadith_details_page.dart` আর `hadith_list_item.dart`-এ কনফ্লিক্ট হতে পারে। মেনুর "হাদিসের বিস্তারিত" খোলার কোড এখন `MoreOptionBottomSheet.openHadithDetails`-এ, তাই `more_option_bottom_sheet.dart` বদলানো অন্য ব্রাঞ্চের সাথেও কনফ্লিক্ট হতে পারে।
- ফোন বা সিমুলেটরে এখনো চালানো হয়নি।
