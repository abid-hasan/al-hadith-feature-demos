# শরাহ / ব্যাখ্যা — টেস্টের ধাপ

ব্রাঞ্চ `feature/sharh-explanation` · PR #275 · ডেমো ১ (অ্যাপের ধরন: কার্ডে ছোট "ব্যাখ্যা", বিস্তারিত পেজে কিতাব ধরে পুরো ব্যাখ্যা)

## চালানোর আগে
```bash
git checkout feature/sharh-explanation
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ বা permission নেই। নতুন অ্যাসেট ফোল্ডার `assets/demo/sharh_explanation/`, তাই hot reload না, পুরো রিস্টার্ট দিন।
- অ্যাপের ভাষা বাংলা। ডেমো ডেটায় শরাহ আছে শুধু **সহীহ বুখারী, হাদিস ১**-এ (দুটো কিতাব: ফাতহুল বারী আর শরহে মুসলিম, তিনটা শিক্ষণীয় বিষয়)। বাকি সব হাদিসে কিছু দেখানোর কথা না।
- ডেটা অ্যাপের ভেতরে থাকে, তাই নেট ছাড়াও দেখায়। বুখারী ডাউনলোড করা থাকুক বা না থাকুক, দুই অবস্থাতেই দেখুন।
- লোডিং আর এরর অবস্থা ডেমো ফাইলে দেখা যায় না (ফাইল সাথে সাথে পড়া হয়)। এগুলো আসল API এলে দেখতে হবে।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোম → সহীহ বুখারী → প্রথম অধ্যায় → হাদিস ১-এর কার্ড | অনুবাদের নিচে দাগ, "ব্যাখ্যা", তিন লাইন লেখা, বই আইকনসহ "ফাতহুল বারী · খণ্ড ১ · পৃষ্ঠা ১৩ · আরো ১টি কিতাব", তারপর সবুজ "আরো পড়ুন" |
| ওই কার্ডের "আরো পড়ুন" বা ⋮ → "বিস্তারিত" | হাদিস কার্ডের নিচে "ব্যাখ্যা" কার্ড (দুই কিতাবের ভাগ), "শিক্ষণীয় বিষয়" কার্ড (১-২-৩), ঢাল আইকনসহ "আলেমদের অনুবাদ ও যাচাই করা ব্যাখ্যা" |
| প্রতিটা কিতাবের ভাগে | কিতাবের নাম, "খণ্ড ১ · পৃষ্ঠা ১৩", বাংলা অনুবাদ, "মূল আরবি দেখুন" আর নিচমুখী তীর |
| বিস্তারিত পেজের একদম নিচে | "আগের" / "পরের" দুটো বাটন (সব হাদিসে, শরাহ না থাকলেও) |

## ধাপগুলো
- [ ] বুখারী → প্রথম অধ্যায় → হাদিস ১-এর কার্ডে "ব্যাখ্যা" অংশ আছে। লেখা তিন লাইনের বেশি হলে "…" দিয়ে কাটে।
- [ ] একই অধ্যায়ের অন্য হাদিস, আর অন্য বইয়ের কার্ড একদম আগের মতো, বাড়তি দাগ বা ফাঁকা জায়গা নেই।
- [ ] "আরো পড়ুন" → বিস্তারিত পেজ খোলে হাদিস ১-এ। বাঁয়ে-ডানে সোয়াইপ করে অধ্যায়ের অন্য হাদিসে যাওয়া যায়।
- [ ] কার্ডের বাকি জায়গায় ট্যাপ করলে কিছু হয় না (আগের মতো)। শুধু "আরো পড়ুন" পেজ খোলে।
- [ ] "আরো পড়ুন" খুব দ্রুত দুবার চাপলে একটাই পেজ খোলে।
- [ ] ⋮ → "বিস্তারিত" দিয়ে খুললেও একই পেজ, একই ব্যাখ্যা।
- [ ] বিস্তারিত পেজে প্রথম ভাগ "ফাতহুল বারী", "খণ্ড ১ · পৃষ্ঠা ১৩"। দ্বিতীয় ভাগ "শরহে মুসলিম", "খণ্ড ১৩ · পৃষ্ঠা ৫৩"। দুই ভাগের মাঝে পাতলা দাগ।
- [ ] প্রথম ভাগে "মূল আরবি দেখুন" → নিচে হালকা ধূসর বক্সে আরবি, ডান থেকে বাঁয়ে, অ্যাপের আরবি ফন্টে। বাটনের লেখা "মূল আরবি লুকান", তীর ওপরমুখী।
- [ ] আবার চাপলে আরবি বন্ধ। দুই ভাগের আরবি আলাদা আলাদা খোলে-বন্ধ হয়।
- [ ] সেটিংসে আরবি ফন্ট বদলালে শরাহের আরবিও বদলায়। আরবি ফন্ট সাইজ বাড়ালে শরাহের আরবিও বড় হয় (হাদিসের আরবির চেয়ে একটু ছোট থাকে)।
- [ ] "শিক্ষণীয় বিষয়"-এ নম্বর সবুজ, তিনটা পয়েন্ট, লম্বা লাইন নম্বরের পরে একই জায়গা থেকে শুরু হয়।
- [ ] "পরের" → পাশের হাদিসে স্লাইড করে যায়। "আগের" → ফিরে আসে। অধ্যায়ের প্রথম হাদিসে "আগের" ধূসর, শেষ হাদিসে "পরের" ধূসর।
- [ ] অনলাইন (ডাউনলোড না করা) অধ্যায়ে "পরের" চাপতে থাকলে লোড না হওয়া পাতায় গেলে আগের মতো ধূসর কার্ড, তারপর হাদিস।
- [ ] বিস্তারিত পেজে সোয়াইপ করার মতো একটাই হাদিস থাকলে (যেমন একটা হাদিসের অধ্যায়) আগের/পরের বার নেই।
- [ ] হাদিস ১ থেকে সোয়াইপ করে সরে আবার ফিরলে আরবি বন্ধ অবস্থায় ফেরে কিনা দেখে রাখুন (পাতা নতুন করে বানালে বন্ধ হয়ে যায়)।
- [ ] মিনি সেটিংস থেকে পড়ার ফন্ট সাইজ বাড়ান-কমান → কার্ডের "ব্যাখ্যা", বিস্তারিত পেজের লেখা, বাটন সব ছোট-বড় হয়। রেফারেন্স আর যাচাইয়ের লেখা ছোটই থাকে।
- [ ] কার্ড ⋮ → ছবি হিসেবে শেয়ার → ছবিতে "ব্যাখ্যা" অংশ নেই।
- [ ] হাদিস ১-এ নিজের নোট থাকলে কার্ডে আগে "ব্যাখ্যা", তার নিচে "আমার নোট"।
- [ ] ডার্ক মোড: দাগ, ধূসর আরবি বক্স, সবুজ বাটন আর ধূসর রেফারেন্স পরিষ্কার পড়া যায়।
- [ ] অ্যাপের ভাষা English (বা অন্য যেকোনো) → বুখারী ১-এ কোনো ব্যাখ্যা নেই, কার্ড আর পেজ আগের মতো। বিস্তারিত পেজে আগের/পরের বার ("Previous" / "Next") থাকে।
- [ ] উর্দু / আরবি (RTL): বিস্তারিত পেজে আগের/পরের বারের তীর ঠিক দিকে, কিছু ভাঙে না।
- [ ] ট্যাবলেট (পোর্ট্রেট আর ল্যান্ডস্কেপ): কার্ড দুই কলামে থাকলে "ব্যাখ্যা" দুই কলামের নিচে পুরো চওড়ায়। বিস্তারিত পেজে ব্যাখ্যার কার্ড আর আগের/পরের বার হাদিস কার্ডের সাথে একই লাইনে।
- [ ] বিষয়ভিত্তিক হাদিস, সার্চ রেজাল্ট, বুকমার্ক, রিডিং প্ল্যান আর হাদিস ফিডের কার্ডে "ব্যাখ্যা" অংশ নেই (ইচ্ছা করে)।
- [ ] TalkBack/VoiceOver: "আরো পড়ুন" আর "মূল আরবি দেখুন" বাটন হিসেবে পড়ে, আরবি বাটন খোলা/বন্ধ বলে।

## অ্যানালিটিক্স (DebugView)
- কার্ডের "আরো পড়ুন" → `hadith_details_open{source: sharh_more, book_slug: bukhari, hadith_ref}`, তারপর `screen_view{screen_name: hadith_details}`।
- বিস্তারিত পেজে বুখারী ১-এর পাতায় পৌঁছালে `sharh_view{passage_count: 2, teachings_count: 3}` আর হাদিস-প্যারাম। সোয়াইপ করে ফিরলে আবার আসে। শরাহ না থাকা হাদিসে আসে না।
- "মূল আরবি দেখুন" → `sharh_arabic_toggle{expanded: true}`, "মূল আরবি লুকান" → `expanded: false`।
- "পরের" / "আগের" → `hadith_details_neighbour{direction: next / previous}`, `hadith_ref` যে হাদিস থেকে চাপা হলো তার। এই সময় `hadith_details_swipe` আসে না; হাতে সোয়াইপ করলে আগের মতো আসে।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "শরাহ / ব্যাখ্যা" সেকশন।

## জানা সীমাবদ্ধতা
- ডেমো ডেটা যাচাই করা নয়: বুখারী ১-এর অনুবাদ, আরবি, খণ্ড আর পৃষ্ঠা ডেমোর লেখা। তবু "আলেমদের অনুবাদ ও যাচাই করা ব্যাখ্যা" দেখায়, আর ডেটা রিলিজেও যায়। রিলিজের আগে আসল ডেটা বসাতে হবে বা ডেমো সরাতে হবে।
- ডেটা শুধু বাংলায়, শুধু একটা হাদিসে।
- আসল ডেটার জন্য বদলাতে হবে শুধু `HadithSharhModule`-এর `HadithSharhDataSource`। কার্ড প্রতিটা হাদিসের জন্য আলাদা করে চায়, তাই আসল API প্রতি হাদিসে আলাদা কল হলে লিস্টে অনেক রিকোয়েস্ট যাবে।
- লোডিংয়ের ধূসর লাইন আসে ৩০০ ms-এর বেশি লাগলে, আর এরর মেসেজ আসে লোড ব্যর্থ হলে। ডেমো ফাইলে দুটোর কোনোটাই হয় না।
- কার্ডে লোড হওয়ার সময় বা ব্যর্থ হলে কিছু দেখায় না, কার্ড আগের মতো থাকে।
- অ্যাপে আরবি বন্ধ থাকলেও "মূল আরবি দেখুন" থাকে। তাশকিল বন্ধের সেটিং শরাহের আরবিতে লাগে না।
- আরবি খোলা আছে কিনা মনে রাখা হয় না; পাতা নতুন করে বানালে বন্ধ হয়ে যায়।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
