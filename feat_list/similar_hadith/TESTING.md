# একই রকম হাদিস — টেস্টের ধাপ

ব্রাঞ্চ `feature/similar-hadith` · ডেমো ১ (অ্যাপের ধরন: লুকানো "সম্পর্কিত হাদিস" কার্ড চালু, পুরো সারি ট্যাপ, সাথে প্রথম লাইন)

## চালানোর আগে
```bash
git checkout feature/similar-hadith
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ বা অনুমতি নেই। নতুন অ্যাসেট `assets/demo/similar_hadith/similar_hadiths.json` (ডেমো তালিকা, আলেমদের যাচাই এখনো হয়নি)।
- তালিকা আছে শুধু বাংলা আর English-এ। অন্য ভাষায় কার্ড দেখাবে না, এটাই ঠিক।
- অ্যাপের ভাষা বাংলা। নেট চালু রাখুন। অফলাইন ধাপের জন্য একটা ফোনে সহীহ বুখারী ডাউনলোড থাকুক, সহীহ মুসলিম আর রিয়াদুস সালেহীন ডাউনলোড না থাকুক।
- তালিকা থাকা হাদিস (বাংলা):
  - সহীহ বুখারী ৬১১৬ (রাগ করো না) → রিয়াদুস সালেহীন ৪৯, সহীহ মুসলিম ৬৫৩৭, সহীহ বুখারী ৬১১৪
  - সহীহ বুখারী ১ (নিয়ত) → সহীহ মুসলিম ৪৮২১, রিয়াদুস সালেহীন ১
  - সহীহ বুখারী ৬০১৮ (প্রতিবেশী, ভালো কথা) → সহীহ মুসলিম ৭৮, ৭৭
  - সহীহ বুখারী ১৮৯৪ (সিয়াম ঢাল) → সহীহ মুসলিম ২৫৯৫
  - উল্টো দিকেও আছে, যেমন মুসলিম ৬৫৩৭ খুললে বুখারী ৬১১৪ আর ৬১১৬।
- English-এ বুখারীর নম্বর একই। মুসলিম আর রিয়াদুস সালেহীনের নম্বর আলাদা: 2609a, 1907a, 47b / 47a, 1151c, Riyad 48।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হাদিস কার্ডে ট্যাপ, বা ⋯ মেনু → "বিস্তারিত" | "হাদিসের বিস্তারিত" পেজ |
| বিস্তারিত পেজে হাদিস কার্ডের নিচে | "সম্পর্কিত হাদিস" কার্ড, শুধু তালিকা থাকা হাদিসে |
| কার্ডের প্রতিটা সারি | বইয়ের নাম › "হাদিস নং …" (সবুজ, মোটা), নিচে হাদিসের প্রথম এক লাইন |

## ধাপগুলো
- [ ] সহীহ বুখারী → ৬১১৬ নম্বর হাদিস → কার্ডে ট্যাপ → বিস্তারিত পেজ। নিচে নামলে "সম্পর্কিত হাদিস" কার্ড, তিনটা সারি: রিয়াদুস সালেহীন › হাদিস নং ৪৯, সহীহ মুসলিম › হাদিস নং ৬৫৩৭, সহীহ বুখারী › হাদিস নং ৬১১৪।
- [ ] সারিগুলোর মাঝে পাতলা দাগ। প্রতিটা সারির নিচে হাদিসের প্রথম লাইন, লম্বা হলে শেষে "…"।
- [ ] বই ডাউনলোড না থাকলে প্রথম লাইনের জায়গায় কিছুক্ষণ ধূসর ঝিলমিল লাইন, তারপর লেখা আসে।
- [ ] সারির যেকোনো জায়গায় ট্যাপ (বইয়ের নাম, নম্বর বা প্রথম লাইন) → ওই হাদিসের নিজের বিস্তারিত পেজ খোলে, অ্যাপ বারে বইয়ের নাম আর নম্বর।
- [ ] নতুন পেজেও নিচে তার নিজের "সম্পর্কিত হাদিস" কার্ড (যেমন মুসলিম ৬৫৩৭-এ বুখারী ৬১১৪ আর ৬১১৬)। সেখান থেকে আরেকটা খুলুন।
- [ ] Back চাপলে এক ধাপ করে আগের হাদিসে ফেরে, শেষে প্রথম বিস্তারিত পেজে।
- [ ] তালিকা নেই এমন হাদিস (যেমন বুখারী ২) খুলুন → কার্ড নেই, নিচে ফাঁকা জায়গাও নেই।
- [ ] বিস্তারিত পেজে ডানে-বাঁয়ে সোয়াইপ করে ৬১১৪ আর ৬১১৬-এ যান → প্রতিটা পাতায় নিজের তালিকা।
- [ ] সারিতে খুব দ্রুত দুবার ট্যাপ → একটাই পেজ খোলে।
- [ ] অফলাইন: বিমান মোড, মুসলিম আর রিয়াদুস সালেহীন ডাউনলোড নেই → বুখারী ৬১১৬ খুলুন। বুখারী ৬১১৪-এর সারিতে প্রথম লাইন আসে, বাকি দুটোয় শুধু বই আর নম্বর। ওই সারিতে ট্যাপ → "হাদিস খুঁজে পাওয়া যায়নি", পেজ খোলে না।
- [ ] এরপর নেট চালু করে আবার ওই সারিতে ট্যাপ → এবার হাদিস খোলে। ফিরলে সারিতে প্রথম লাইনও আসে।
- [ ] মুসলিম ডাউনলোড করে বিমান মোডে আবার দেখুন → ফোন থেকেই খোলে।
- [ ] অ্যাপের ভাষা English → বুখারী 6116: "Related hadith", সারি "Riyad as-Salihin › Hadith No. 48", "Sahih Muslim › Hadith No. 2609a", "Sahih Bukhari › Hadith No. 6114"। ট্যাপ করলে ইংরেজি হাদিস খোলে।
- [ ] অ্যাপের ভাষা আরবি বা উর্দু → কার্ড দেখায় না (এই ভাষায় তালিকা নেই)।
- [ ] পড়ার ফন্ট সাইজ বড়-ছোট করুন (মিনি সেটিংস) → কার্ডের শিরোনাম আর সারির লেখাও সাথে বদলায়।
- [ ] ডার্ক মোড: সারির লেখা, দাগ আর ধূসর লাইন পড়া যায়।
- [ ] ট্যাবলেট (পোর্ট্রেট আর ল্যান্ডস্কেপ): কার্ড হাদিস কার্ডের সাথে এক লাইনে, কিছু ভাঙে না।
- [ ] TalkBack/VoiceOver: প্রতিটা সারি একটা বাটন হিসেবে পড়ে (বই, নম্বর, প্রথম লাইন একসাথে)।

## অ্যানালিটিক্স (DebugView)
- সারিতে ট্যাপ, হাদিস পাওয়া গেলে: `related_hadith_open{from_book_slug: bukhari, to_book_slug: muslim, to_hadith_id: 6537, found: true}`, তারপর খোলা হাদিসের প্যারাম নিয়ে `hadith_details_open{source: related}` আর `screen_view{screen_name: hadith_details}`।
- না পাওয়া গেলে: `related_hadith_open{…, found: false}`, আর কিছু না।
- কার্ড দেখা, স্ক্রল বা প্রথম লাইন লোড হওয়ায় কোনো ইভেন্ট নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "সম্পর্কিত হাদিস" সেকশন।

## জানা সীমাবদ্ধতা
- তালিকা ডেমো ডেটা, আলেমদের যাচাই করা না। একই হাদিসের অন্য বর্ণনা বেছে নেওয়া হয়েছে, অ্যাপের আসল বইয়ের ডেটা থেকে। আসল তালিকা এলে শুধু `SimilarHadithDemoDataSource` বদলাবে (`similar_hadith_module.dart`)।
- তালিকা শুধু বাংলা আর English-এ, কারণ মুসলিম আর রিয়াদুস সালেহীনের নম্বর ভাষাভেদে আলাদা।
- তালিকা অ্যাপের ভেতরে আছে বলে লোডিং-এর আলাদা ধূসর কার্ড নেই; ধূসর লাইন শুধু প্রথম লাইন আনার সময়। তালিকা পড়াই ব্যর্থ হলে "ব্যাখ্যা ও সম্পর্কিত হাদিস আনা যায়নি…" আর "আবার চেষ্টা করুন" দেখায়; বান্ডেল ফাইলে এটা প্রায় হয় না।
- অফলাইনে না পাওয়া হাদিসের সারিতে শুধু বই আর নম্বর থাকে; ট্যাপ করলে আবার খোঁজে।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
