# পরিস্থিতি দিয়ে শেখা — টেস্টের ধাপ

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোম → "পরিস্থিতি" → "জীবনের পরিস্থিতি" পেজ | ওপরের লাইনের নিচে "সব পরিস্থিতি" শিরোনাম, ডানে "সব পাঠ ›" |
| পরিস্থিতির পেজ (চাকরি, রাগ, সংসার) | দোয়া আর হাদিসের পরে "পাঠ" ভাগ, ডানে "২টি পাঠ" / "৩টি পাঠ" |
| "সব পাঠ" পেজ | চাকরি, রাগ, সংসার ভাগ; প্রতিটায় ছোট আইকন, নাম, পাঠের সংখ্যা আর পাঠের সারি |
| পাঠের পেজ | অ্যাপবারে "পাঠ", নিচে "রাগ · ১/২", ডানে শেয়ার আইকন; "ঘটনা" কার্ড, "সংশ্লিষ্ট হাদিস", "শিক্ষণীয় বিষয়" বক্স, "পরের পাঠ" |

## ধাপগুলো
- [ ] হোম → "পরিস্থিতি" → ওপরের লাইনের নিচে "সব পরিস্থিতি" আর ডানে "সব পাঠ ›"। নিচে আগের মতো সাতটা পরিস্থিতি।
- [ ] "ঋণ", "দুশ্চিন্তা", "পরীক্ষা", "অসুস্থতা" → পেজের নিচে কোনো "পাঠ" ভাগ নেই।
- [ ] "রাগ" → দোয়া আর দুটো হাদিসের পরে "পাঠ" ভাগ, ডানে "২টি পাঠ"। সারিতে বইয়ের আইকন, প্রশ্ন আর তীর।
- [ ] "ভিড়ে কেউ ধাক্কা দিয়ে উল্টো আমার সাথেই ঝগড়া করছে, কী করব?" → পাঠের পেজ। অ্যাপবারে "পাঠ", নিচে "রাগ · ১/২"।
- [ ] ওপরে "ঘটনা" ট্যাগ, প্রশ্ন বড় করে, নিচে দুই লাইনের ঘটনা।
- [ ] "সংশ্লিষ্ট হাদিস": বুখারি ৬১১৬ অ্যাপের চেনা কার্ডে (বইয়ের ব্যাজ, গ্রেড চিপ, ⋮; বুকমার্ক আইকন নেই)।
- [ ] হাদিসে ট্যাপ → অধ্যায়সহ পুরো হাদিস। ব্যাক → আবার পাঠে।
- [ ] "শিক্ষণীয় বিষয়" বক্স: সবুজ বর্ডার, ডানে ছোট "আলেমদের যাচাই করা", নিচে ১, ২, ৩ নম্বর দেওয়া তিন লাইন।
- [ ] নিচে "পরের পাঠ: রোজা রেখে আছি, কেউ গালি দিল, কী বলব?" আর "পরের পাঠ" বাটন।
- [ ] "পরের পাঠ" → একই পেজে রোজার পাঠ, ওপরে ফিরে যায়, অ্যাপবারে "রাগ · ২/২", হাদিস বুখারি ১৮৯৪।
- [ ] আবার "পরের পাঠ" → প্রথম পাঠে ফেরে ("১/২")।
- [ ] এবার ব্যাক → সরাসরি রাগের পেজে (মাঝের পাঠগুলোতে নয়)।
- [ ] অ্যাপবারের শেয়ার আইকন → ফোনের শেয়ার মেনু। লেখায় প্রশ্ন, ঘটনা, "হাদিস: …" আর "(সহীহ বুখারী, হাদিস নং ৬১১৬)", তারপর "শিক্ষণীয় বিষয়:" আর ১., ২., ৩.।
- [ ] তালিকায় ফিরে "সব পাঠ" → চাকরি (২), রাগ (২), সংসার (৩) — মোট সাতটা পাঠ, তালিকার ক্রমে।
- [ ] "সব পাঠ" থেকে সংসারের শেষ পাঠ → "সংসার · ৩/৩"। "পরের পাঠ" → "১/৩"। ব্যাক → "সব পাঠ" পেজ।
- [ ] "চাকরি" পেজ থেকে পাঠ খুললে দুটো পাঠেই বুখারি ১।
- [ ] বিমান মোড চালু রেখে পুরো পথ ঘুরুন: সব খোলে।
- [ ] সেটিংসে আরবি বন্ধ করলে পাঠের হাদিস কার্ডে আরবি নেই। লেখার সাইজ বদলালে হাদিস কার্ড বদলায়।
- [ ] ডার্ক মোড: সারির আইকন, "ঘটনা" ট্যাগ, শিক্ষার বক্সের বর্ডার আর নম্বর পড়া যায়।
- [ ] ট্যাবলেট আর ছোট ফোন (৩২০ চওড়া): লম্বা প্রশ্ন ভাঙে না, "শিক্ষণীয় বিষয়" আর "আলেমদের যাচাই করা" এক সারিতে বা ঠিকভাবে ভাঙে।
- [ ] অ্যাপের ভাষা English → হোমে "পরিস্থিতি" নেই, তাই পাঠও নেই।
- [ ] TalkBack/VoiceOver: পাঠের সারি আর "পরের পাঠ" বাটন পড়ে।

## অ্যানালিটিক্স (DebugView)
- পরিস্থিতির পেজের "পাঠ" ভাগ থেকে → `situation_lesson_open{lesson_id, situation_id, source: situation}`, তারপর `screen_view{screen_name: situation_lesson}`।
- "সব পাঠ" বাটন → শুধু `screen_view{screen_name: situation_lessons}`; সেখান থেকে পাঠ → `situation_lesson_open{source: all_lessons}`।
- "পরের পাঠ" → `situation_lesson_open{source: next}` আর নতুন `lesson_id`; কোনো `screen_view` নেই।
- শেয়ার আইকন → `share{content_type: situation_lesson, item_id: lesson:<id>, method: system, situation_id}`। শেয়ার মেনু বাতিল করলেও যায়।
- পাঠের হাদিসে ট্যাপ → `hadith_details_open{source: card_tap}`; ব্যাক → `screen_view{screen_name: situation_lesson}`।
- `lesson_id` = `l1`–`l7`; `situation_id` = `job` / `anger` / `home`।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "জীবনের পরিস্থিতি" সেকশন।

## জানা সীমাবদ্ধতা
- ডেমোর সাতটা পাঠের ঘটনা আর শিক্ষা আলেমদের যাচাই করা নয়, শুধু দেখানোর জন্য `verified: true`। তবু পেজে "আলেমদের যাচাই করা" লেখা দেখায়, রিলিজের আগে ঠিক করতে হবে।
- শুধু বাংলা। আসল API এলে বদলাতে হবে শুধু `SituationLessonDemoAssetDataSource` (আর `LifeSituationModule`-এর register লাইন)।
- শেয়ার শুধু লেখা, ছবি নয়। ডেমোর প্রিভিউ শিট নেই।
- পাঠের হাদিস কার্ড থেকে পুরো হাদিসের পেজে সোয়াইপ করলে অন্য হাদিস নেই (শুধু ওই পাঠের হাদিস)।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
