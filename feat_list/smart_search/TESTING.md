# AI সার্চ (ব্যাকএন্ডের AI অবস্থা) — টেস্টের ধাপ

ব্রাঞ্চ `feature/ai-search` · ভিত্তি: প্ল্যাটফর্ম টিমের AI সার্চ সারাংশ (`search.hadithSearch`, `aiSearch: true`, `ai.status`)

## চালানোর আগে
```bash
git checkout feature/ai-search
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ নেই, `pod install` লাগবে না।
- Firebase Remote Config-এ দুটো মান বদলে Publish করুন:
  - `ai_search_enabled` = `true` (ডিফল্ট `false`; বন্ধ থাকলে "AI সার্চ" অপশন দেখায় না)।
  - `ai_search_api_base_url` = `https://dev.ihadis.com/api/v1/trpc` (dev হোস্ট)। শেষে `/search.hadithSearch` লিখবেন না, অ্যাপ নিজে যোগ করে।
  - `ai_search_api_key` খালি রাখলেও dev-এ চলে।
- অ্যাপ মুছে আবার ইনস্টল করুন, বা অ্যাপ বন্ধ করে খুলুন, যাতে নতুন Remote Config আসে। প্রোফাইলে "AI সার্চ" কার্ড দেখালে বুঝবেন চালু হয়েছে।
- অ্যাপের ভাষা বাংলা। নেট চালু। একটা Google অ্যাকাউন্টে সাইন ইন করে রাখুন।
- প্রোফাইলের AI কার্ডে আজকের ব্যবহার দেখে রাখুন; প্রতি ধাপের পর মিলিয়ে দেখবেন।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোম → সার্চ পেজ → "সার্চের পদ্ধতি নির্বাচন করুন" | "স্বাভাবিক" (শুরুতে বাছা), "হুবহু মিল", "AI" ব্যাজসহ "AI সার্চ" |
| রেজাল্ট পেজের ওপরের কার্ড | "আপনি ( … ) লিখে সার্চ করেছেন", "সর্বমোট ফলাফল পাওয়া গেছে : N টি"; AI কাজে লাগলে গণনার পাশে "AI" ব্যাজ |
| ওপরের কার্ডের নিচের লাইন | AI কাজে না এলে: "এই সার্চে AI সার্চ কাজে আসেনি। স্বাভাবিক সার্চের ফল দেখানো হচ্ছে।" |
| প্রোফাইল → AI সার্চ কার্ড | আজকের ব্যবহার / দিনের সীমা (৩০) |

## ধাপগুলো
- [ ] `ai_search_enabled` = false → সার্চ পেজে শুধু "স্বাভাবিক" আর "হুবহু মিল"। প্রোফাইলে AI কার্ড নেই।
- [ ] `ai_search_enabled` = true → সার্চ পেজে তৃতীয় অপশন "AI সার্চ"। পেজ খুললে "স্বাভাবিক" বাছা থাকে, AI নয়।
- [ ] "AI সার্চ" বেছে লিখুন "দাঁত মাজার সুন্নত" → রেজাল্টে মিসওয়াকের হাদিস। গণনার পাশে "AI" ব্যাজ, নোটিশ নেই। আরবি অংশে মিসওয়াকের শব্দগুলো (যেমন السِّوَاكَ) হাইলাইট। প্রোফাইলে ব্যবহার এক বাড়ে।
- [ ] "AI সার্চ"-এ লিখুন "নামাজ" → সাধারণ রেজাল্ট (সার্ভার বলে AI দরকার নেই, `skipped`)। ব্যাজ নেই, নোটিশ নেই। প্রোফাইলে ব্যবহার বাড়ে না।
- [ ] "AI সার্চ"-এ আরবি লিখুন "سواك" → সাধারণ রেজাল্ট, ব্যাজ নেই, ব্যবহার বাড়ে না।
- [ ] "AI সার্চ"-এ শুধু নম্বর লিখুন, যেমন "1" → নম্বরের রেজাল্ট, ব্যাজ নেই, ব্যবহার বাড়ে না।
- [ ] এমন কিছু লিখুন যার কোনো ফল নেই (যেমন "ঝঝঝঝঝ") → অ্যাপের সাধারণ "কোন সার্চ রেজাল্ট পাওয়া যায়নি", কোনো ব্যাজ বা নোটিশ নেই।
- [ ] নোটিশ দেখা (`unavailable` / `fallback`): dev সার্ভারে AI সাময়িক বন্ধ বা ব্যর্থ থাকলে, অথবা এমন বাক্য যেটার আরবি শব্দে কিছু মেলে না → সাধারণ রেজাল্ট, নিচে নোটিশ লাইন, ব্যাজ নেই, ব্যবহার বাড়ে না। ইচ্ছা করে ঘটানো কঠিন; প্ল্যাটফর্ম টিম সার্ভারে AI কী বন্ধ করে দিলে সহজে দেখা যায়।
- [ ] "দাঁত মাজার সুন্নত"-এর রেজাল্টে নিচে স্ক্রল → পরের পাতা আসে, ব্যাজ থাকে, ব্যবহার আর বাড়ে না।
- [ ] রেজাল্ট পেজে গ্রেড ফিল্টার বদলান → নতুন রেজাল্ট, ব্যবহার বাড়ে না।
- [ ] "সেরা মিল" আর "বই অনুযায়ী" সাজানো → আগের মতো ফোনেই সাজায়, ব্যাজ থাকে।
- [ ] অনলাইন আর অফলাইন দুই স্কোপেই "দাঁত মাজার সুন্নত" চালান। অফলাইনে শুধু ডাউনলোড করা বইয়ের হাদিস আসে।
- [ ] সাইন আউট করে "AI সার্চ" → "AI সার্চ ব্যবহার করতে সাইন ইন করুন", সার্চ চলে না।
- [ ] দিনের সীমা শেষ (Remote Config-এ `ai_search_daily_limit` = 1 দিয়ে "দাঁত মাজার সুন্নত" দুবার) → দ্বিতীয়বার "আজকের ক্রেডিট শেষ।"। সীমা 1 রেখে আগে "নামাজ" চালালে ক্রেডিট কাটে না, তারপর "দাঁত মাজার সুন্নত" ঠিকঠাক চলে।
- [ ] বিমান মোডে "AI সার্চ" → "আপনার মোবাইলের ইন্টারনেট অন করা আছে কিনা দেখুন।", ব্যবহার বাড়ে না।
- [ ] ভুল হোস্ট দিলে (যেমন `ai_search_api_base_url`-এ ভুল ঠিকানা) → "সম্ভবত সার্ভারের সাথে সংযোগ স্থাপন করা সম্ভব হয়নি।" আর "আবার চেষ্টা করুন", ব্যবহার বাড়ে না।
- [ ] ডার্ক মোড আর আরবি/উর্দু (RTL): ব্যাজ গণনার পাশে, নোটিশ লাইন পড়া যায়। ছোট ফোনে গণনা লম্বা হলে ব্যাজ পরের লাইনে যায়, কাটে না।
- [ ] TalkBack/VoiceOver: ব্যাজকে "AI সার্চ" পড়ে।
- [ ] ট্যাবলেট (পোর্ট্রেট আর ল্যান্ডস্কেপ): ওপরের কার্ডে ব্যাজ আর নোটিশ ঠিক জায়গায়।

## অ্যানালিটিক্স (DebugView)
- AI সার্চের প্রথম পাতায় `search_result{effective_type: ai, ai_status}`। "দাঁত মাজার সুন্নত" → সাধারণত `used`; "নামাজ", "سواك", "1" → `skipped`।
- সাধারণ বা হুবহু সার্চের `search_result`-এ `ai_status` থাকে না।
- সার্ভার ব্যর্থ হলে আগের মতো `ai_search_failed{reason: timeout / serverError / invalidResponse}` আর `search_failed{error_type: ai_<reason>}`। `reason: unavailable` আর আসে না।
- সাইন আউট, সীমা শেষ, নেট নেই → আগের মতো `ai_search_blocked{reason}`।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "সার্চ" সেকশন।

## জানা সীমাবদ্ধতা
- AI সার্চ এখন সার্ভারে `type: normal` পাঠায় (আগে `partial`)। একই প্রশ্নে রেজাল্টের সংখ্যা আগের চেয়ে অনেক কম আসতে পারে; এটা ইচ্ছাকৃত।
- ক্রেডিট সার্চের আগে ধরে রাখা হয়, সার্ভার AI না চালালে ফেরত যায়। তাই সার্চ চলার সময় প্রোফাইলের সংখ্যা এক মুহূর্তের জন্য এক বেড়ে আবার কমতে পারে।
- সাজানো (`bestMatch` / `bookOrder`) এখনো ফোনে হয়, সার্ভারে `sort` পাঠানো হয় না; সার্ভারের AI-ভিত্তিক স্কোর ডিফল্ট ক্রমেই আসে।
- ব্যাজ আর নোটিশ ঠিক হয় প্রথম পাতার `ai.status` দেখে; পরের পাতা সেটা বদলায় না।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
