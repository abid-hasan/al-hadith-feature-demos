# ভয়েস সার্চ — টেস্টের ধাপ

ব্রাঞ্চ `feature/voice-search` · PR #263 · ডেমো ১ (অ্যাপের ধরন: মাইক সার্চ বক্সে, শোনার জন্য বটম শিট)

## চালানোর আগে
```bash
git checkout feature/voice-search
flutter pub get && flutter gen-l10n
(cd ios && pod install)   # নতুন প্যাকেজ speech_to_text, Podfile.lock বদলেছে
flutter run
```
- নতুন প্যাকেজ `speech_to_text: ^7.5.0`। Podfile বদলায়নি, কোনো permission macro লাগে না (প্রজেক্টে `permission_handler` নেই)।
- Android: `RECORD_AUDIO` অনুমতি আর `<queries>`-এ `android.speech.RecognitionService`। iOS: `NSMicrophoneUsageDescription` আর `NSSpeechRecognitionUsageDescription` (লেখা ইংরেজিতে)।
- ফোন লাগবে: একটা Android (Google অ্যাপ আছে এমন) আর একটা আসল iPhone। সিমুলেটরে মাইক ঠিকমতো চলে না।
- অ্যাপের ভাষা বাংলা। নেট চালু রাখুন। অফলাইন সার্চে টেস্ট করলে অন্তত একটা বই ডাউনলোড থাকতে হবে।
- প্রথমবারের ডায়ালগ আবার দেখতে অ্যাপ মুছে নতুন করে ইনস্টল করুন (ফ্ল্যাগ লোকাল ক্যাশে থাকে)।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হোম → সার্চ পেজ ("সার্চ") | বক্স খালি থাকলে ডানে সবুজ মাইক, টুলটিপ "বলে খুঁজুন" |
| শোনার শিট | চিপ: বাংলা / English / العربية, "শুনছি…", "হাদিসের বিষয় বা নাম্বার বলুন", "বাতিল করুন" |
| রেজাল্ট পেজের ওপরের কার্ড | "লেখা ভুল হলে ঠিক করুন" (শুধু ভয়েস সার্চে) |

## ধাপগুলো
- [ ] হোম → সার্চ → বক্স খালি: ডানে সবুজ মাইক। কিছু টাইপ করুন → মাইকের জায়গায় ✕। মুছলে আবার মাইক।
- [ ] নতুন ইনস্টলে প্রথম মাইক ট্যাপ → "মাইকের অনুমতি দিন" ডায়ালগ, লেখা "কথা বলে হাদিস খুঁজতে মাইকের অনুমতি লাগবে।"
- [ ] "এখন না" (বা ডায়ালগের বাইরে ট্যাপ) → ডায়ালগ বন্ধ, আর কিছু হয় না। আবার মাইক → ডায়ালগ আবার আসে।
- [ ] "অনুমতি দিন" → সিস্টেম প্রম্পট (iOS-এ মাইক আর Speech Recognition, দুটো) → Allow → শিট খোলে, "বাংলা" চিপ বাছা, মাইকে ঢেউ, "শুনছি…"।
- [ ] বলুন "রোজার ফজিলত" → বলার সাথে লেখা ভাসে, কথা এলে দ্বিতীয় ঢেউ যোগ হয়। চুপ থাকলে কয়েক সেকেন্ডে শিট বন্ধ, বক্সে "রোজার ফজিলত", রেজাল্ট পেজ খোলে।
- [ ] রেজাল্টে "লেখা ভুল হলে ঠিক করুন" → সার্চ পেজে ফেরে, লেখা বক্সে, কীবোর্ড খোলা, কার্সর শেষে।
- [ ] ভয়েস রেজাল্ট থেকে Back → লেখা বক্সে থেকে যায়। টাইপ করে সার্চ করলে রেজাল্টে লিংক নেই, ফিরলে বক্স খালি (আগের মতো)।
- [ ] এমন কিছু বলুন যার রেজাল্ট নেই → ওপরের কার্ডই নেই, তাই লিংকও নেই। Back → লেখা বক্সে।
- [ ] শোনার মাঝে "English" চিপ → শোনা নতুন করে শুরু। "virtue of fasting" বলুন → ইংরেজি লেখা, সার্চ চলে।
- [ ] "العربية" চিপ বেছে আরবিতে বলুন → লেখা ডান থেকে বাঁয়ে।
- [ ] মাইক চেপে চুপ থাকুন → "কিছু শোনা যায়নি, আরেকবার বলুন", চিপ আর "আবার চেষ্টা করুন"। এখানে চিপ বদলালে শোনা শুরু হয় না; "আবার চেষ্টা করুন" চাপলে নতুন ভাষায় শোনে।
- [ ] বিমান মোড → মাইক → শোনার আগেই "ইন্টারনেট সংযোগ নেই", "কথা বুঝতে ইন্টারনেট লাগে। আপাতত টাইপ করে খুঁজুন।" → "টাইপ করে খুঁজুন" → শিট বন্ধ, বক্সে কার্সর আর কীবোর্ড।
- [ ] প্রথম সিস্টেম প্রম্পটে Deny → শিট সরাসরি "মাইকের অনুমতি দেওয়া নেই" আর "সেটিংস" বাটন।
- [ ] iPhone: সেটিংস থেকে অ্যাপের মাইক বন্ধ → মাইক → সরাসরি "মাইকের অনুমতি দেওয়া নেই" → "সেটিংস" অ্যাপের সেটিংস খোলে। অনুমতি বদলালে iOS অ্যাপ বন্ধ করে দেয়, তাই অ্যাপ খুলে আবার মাইক চাপুন।
- [ ] Android: সেটিংস থেকে মাইক বন্ধ → মাইক → সম্ভবত আবার সিস্টেম প্রম্পট আসবে (প্যাকেজ নিজে অনুমতি চায়)। Deny → "মাইকের অনুমতি দেওয়া নেই" → "সেটিংস" → অ্যাপের App info খোলে। মাইক চালু করে ফিরলে শিট নিজে শোনা শুরু করে।
- [ ] শোনার মাঝে "বাতিল করুন", শিটের বাইরে ট্যাপ, আর Back → শিট বন্ধ, স্ট্যাটাস বারের মাইক চিহ্ন নিভে যায়, বক্স আগের মতো। শিট নিচে টেনে বন্ধ হয় না (drag বন্ধ)।
- [ ] মাইক খুব দ্রুত দুবার ট্যাপ → একটাই শিট খোলে।
- [ ] অফলাইন সার্চ বাছুন, কোনো বই ডাউনলোড নেই → মাইক দেখায় না, সার্চ বাটনও বন্ধ।
- [ ] নাম্বার বলুন, যেমন "বারোশো চুরানব্বই" → রিকগনাইজার অঙ্কে না লিখলে নাম্বার সার্চ হবে না (জানা সীমা, শুধু দেখে রাখুন)।
- [ ] অ্যাপের ভাষা English → শিটে "English" চিপ বাছা। আরবি → "العربية" বাছা, পেজ/শিট/ডায়ালগ RTL ঠিক আছে।
- [ ] অ্যাপের ভাষা উর্দু (বা ইন্দোনেশিয়ান) → মাইক দেখায়, শিটে "English" বাছা, RTL লেআউট ঠিক।
- [ ] ডার্ক মোড: মাইক, চিপ, "শুনছি…", অবস্থার আইকন আর বাটন পড়া যায়।
- [ ] ট্যাবলেট: শিট মাঝখানে, চওড়া ৫২০-এর বেশি না।
- [ ] Android-এ "Remove animations" (iOS-এ Reduce Motion) চালু → মাইকের ঢেউ নেই, বাকি সব চলে।
- [ ] TalkBack/VoiceOver: মাইক বাটন "বলে খুঁজুন" পড়ে, শিট "ভয়েস সার্চ", ভাসা লেখা নিজে পড়ে শোনায়।
- [ ] iPhone-এ "বাংলা" চিপে বলুন → লেখা আসে কিনা দেখুন। না এলে "এই ভাষায় কথা বোঝা যাচ্ছে না" আর চিপ দেখাবে; English চিপ বাছলে সাথে সাথে শোনা শুরু হয়। ফল PR-এ লিখে দিন।

## অ্যানালিটিক্স (DebugView)
- `voice_search`: `outcome` = `recognized` / `no_speech` / `permission_denied` / `offline` / `language_unavailable` / `unavailable` / `cancelled`, `language` = `bn` / `en` / `ar`, `duration_ms`, `query_length` (শুধু `recognized`-এ)।
- `voice_search_permission`: `action` = `allow` / `later`, `granted` (শুধু `allow`-এ)। ডায়ালগের বাইরে ট্যাপ করলেও `later` যায়।
- `voice_search_action`: `action` = `retry` / `open_settings` / `type_instead` / `edit_query`।
- `search` ইভেন্টে `source: voice`, `search_term` স্যানিটাইজড; পরে আগের মতো `search_result`।
- শোনার মাঝে চিপ বদলালে আগের চেষ্টার `voice_search` যায় না। কোনো অবস্থা দেখানোর পর শিট বন্ধ করলে বাড়তি `voice_search` নেই। শিট বা ডায়ালগে `screen_view` নেই।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "ভয়েস সার্চ" সেকশন।

## জানা সীমাবদ্ধতা
- সবচেয়ে বড় ঝুঁকি: iPhone-এ Apple-এর রিকগনাইজার বাংলা বোঝে কিনা জানা নেই। iOS-এর ভাষার তালিকায় বাংলা না থাকলে "এই ভাষায় কথা বোঝা যাচ্ছে না" আসবে।
- কথা বোঝে ফোনের রিকগনাইজার (Android-এ Google, iOS-এ Apple)। অডিও তাদের সার্ভারে যেতে পারে; প্রাইভেসি পলিসিতে লেখা লাগবে কিনা ঠিক হয়নি।
- শোনার আগে নেট চেক হয়, তাই অফলাইন মডেল থাকলেও নেট ছাড়া চলবে না।
- iOS অনুমতির লেখা শুধু ইংরেজি; বাংলা `InfoPlist.strings` এই ব্রাঞ্চে নেই।
- চুপ থাকার সীমা ৩ সেকেন্ড, এক সেশন সর্বোচ্চ ৩০ সেকেন্ড, ৪০ সেকেন্ডে সেফটি টাইমার। বাছা ভাষা মনে রাখা হয় না।
- ব্লুটুথ হেডসেটের অনুমতি যোগ হয়নি। বলা নাম্বার অঙ্কে বদলানো নেই।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
