# শেখা শব্দের কুইজ — টেস্টের ধাপ

ব্রাঞ্চ `feature/word-quiz` · PR #281 · ডেমো ১ (অ্যাপের ধরন: হাদিস কুইজের খেলা আর ফলাফলের পেজ, শব্দে শব্দে ভাগের নিচে টোনাল বাটন, কুইজ পেজে "শব্দের কুইজ" কার্ড)

## চালানোর আগে
```bash
git checkout feature/word-quiz
flutter pub get && flutter gen-l10n
flutter run
```
- নতুন প্যাকেজ বা অনুমতি নেই। কোনো বান্ডেল ডেটাবেস বদলায়নি, ডেমো ডেটাও নেই।
- শব্দ আসে অ্যাপের এখনকার শব্দে শব্দে ডেটা থেকে: ডাউনলোড করা বই, না থাকলে `hadith.wordByWord` API (৩০ দিনের ক্যাশসহ)। (#২৫ বড় word-by-word বাদ পড়েছে, তাই এটাই ব্যবহার হয়েছে।)
- অ্যাপের ভাষা বাংলা। সেটিংসে আরবি আর "শব্দে শব্দে অর্থ" চালু থাকতে হবে। নেট চালু রাখুন।
- বাটন দেখা যায় শুধু হাদিস ডিটেইলস পেজে: রিডারে কোনো হাদিস কার্ডে ট্যাপ করলে যে পেজ খোলে (বা ⋮ → বিস্তারিত)। রিডারের তালিকায় বাটন নেই।
- "শব্দের কুইজ" কার্ড হাদিস কুইজ পেজে, তাই শুধু `bn` / `en` / `id` / `ur`-এ দেখা যায়।
- দেখা হাদিসের হিসাব ফোনের লোকাল ক্যাশে (`word_quiz_seen_hadiths_v1`) থাকে। শূন্য থেকে দেখতে অ্যাপ মুছে নতুন করে ইনস্টল করুন।

## কোথায় দেখবেন
| জায়গা | কী আছে |
|---|---|
| হাদিস ডিটেইলস → "শব্দে শব্দে" ট্যাব | শব্দগুলোর নিচে হালকা সবুজ বাটন "এই হাদিসের শব্দ দিয়ে কুইজ" (অর্থসহ চারটার কম শব্দ হলে নেই) |
| হোম → "কুইজ" → হিরো ব্যানারের নিচে | "শব্দের কুইজ" কার্ড, "নতুন" ব্যাজ, কয়েকটা আরবি শব্দ, "আগে দেখা Nটি শব্দ", "Nটি প্রশ্ন", "কুইজ শুরু করুন"। চারটার কম শব্দ দেখা হলে শুধু ব্যাখ্যার লেখা |
| শব্দের কুইজ পেজ | অ্যাপ বারে "শব্দের কুইজ", নিচে উৎস ("সহীহ বুখারী ১-এর শব্দ" / "আগে দেখা শব্দ" / "ভুলগুলোর প্র্যাকটিস"), ডানে টাইমার |
| প্রশ্ন | "প্রশ্ন ১ / N", "স্কিপ", ভাগ করা প্রোগ্রেস বার, "এই শব্দের অর্থ কী?", বড় আরবি শব্দ, ক/খ/গ/ঘ চারটা অর্থ |
| উত্তরের প্যানেল | "সঠিক উত্তর" / "ভুল উত্তর" / "প্রশ্নটি এড়িয়ে গেছেন", "মূল শব্দ: … · মূলের সাধারণ অর্থ: …", "হাদিসের সূত্র: বই নম্বর", "পরবর্তী" / "কুইজ শেষ করুন" |
| ফলাফল | স্কোরের রিং, মেসেজ, সঠিক / ভুল / সময়, "ভুলগুলো প্র্যাকটিস করুন", "আবার শুরু করুন" |

## ধাপগুলো
- [ ] রিডারে সহীহ বুখারী ১ খুলে কার্ডে ট্যাপ → ডিটেইলস → "শব্দে শব্দে" ট্যাব। শব্দগুলোর নিচে "এই হাদিসের শব্দ দিয়ে কুইজ"।
- [ ] খুব ছোট হাদিস (অর্থসহ চারটার কম আলাদা শব্দ) → বাটন নেই। "আরবি" ট্যাবে গেলে বাটন নেই।
- [ ] হাদিস শেয়ার (ছবি) করুন → ছবিতে কুইজের বাটন নেই।
- [ ] বাটন → কুইজ খোলে, অ্যাপ বারে "শব্দের কুইজ" আর "সহীহ বুখারী ১-এর শব্দ", টাইমার চলে। প্রশ্ন হাদিসের শব্দের ক্রমে, সর্বোচ্চ ১০টা। একই শব্দ দুবার আসে না।
- [ ] চারটা অপশনই আসল অর্থ (অন্য শব্দের), কোনোটা ফাঁকা বা "—" না। দুটো অপশন হুবহু এক না।
- [ ] অপশন বাছলে নিচে "উত্তর যাচাই করুন"। চাপলে ঠিক হলে সবুজ, ভুল হলে লাল আর ঠিকটা সবুজ। প্যানেলে মূল শব্দ আর মূলের অর্থ (যে শব্দের মূল নেই, সেখানে এই লাইন নেই, প্যানেলে ফাঁকা জায়গাও নেই)।
- [ ] "স্কিপ" → "প্রশ্নটি এড়িয়ে গেছেন", ঠিক উত্তর দেখায়, প্রোগ্রেস বারে লাল।
- [ ] "হাদিসের সূত্র" → সেই হাদিসের ডিটেইলস খোলে। ফিরলে কুইজ সেই প্রশ্নেই, টাইমার মাঝের সময়টা গোনেনি।
- [ ] শেষ প্রশ্নে "কুইজ শেষ করুন" → ফলাফল: রিং, মেসেজ (১০০% "মাশাআল্লাহ! পুরো নম্বর", ৭০%+ "চমৎকার!", ৪০%+ "ভালো চেষ্টা", কম হলে "ইনশাআল্লাহ, পরেরবার আরও ভালো হবে"), সঠিক / ভুল / সময়। ৮০%-এর বেশি হলে কনফেটি।
- [ ] ভুল থাকলে "ভুলগুলো প্র্যাকটিস করুন" → শুধু ভুল আর স্কিপ করা শব্দ, অপশনের ক্রম নতুন, সাবটাইটেল "ভুলগুলোর প্র্যাকটিস"। ফলাফলে "প্র্যাকটিস" ব্যাজ, কনফেটি নেই।
- [ ] "আবার শুরু করুন" → একই হাদিসের নতুন রাউন্ড (প্র্যাকটিসের পরেও আসল রাউন্ড)।
- [ ] খেলার মাঝে অন্তত একটা উত্তর দিয়ে Back → "কুইজ থেকে বের হবেন?" ডায়ালগ। "বের হই" → বের হয়। কিছু না করে Back → সরাসরি বের হয়। ফলাফল থেকে Back → সরাসরি।
- [ ] আরও ৩–৪টা হাদিসের ডিটেইলসে "শব্দে শব্দে" দেখুন (ডিটেইলসে সোয়াইপ করলেও গোনে)।
- [ ] হোম → "কুইজ" → "শব্দের কুইজ" কার্ড: সাম্প্রতিক কয়েকটা আরবি শব্দ, "আগে দেখা Nটি শব্দ", "১০টি প্রশ্ন" (কম হলে যত শব্দ)। নতুন ইনস্টলে (কিছু দেখা নেই) কার্ডে শুধু ব্যাখ্যা, শুরু করার বাটন নেই।
- [ ] "কুইজ শুরু করুন" → একটু লোডিং, তারপর "আগে দেখা শব্দ" রাউন্ড, বিভিন্ন হাদিসের শব্দ মিশিয়ে। "হাদিসের সূত্র" ঠিক হাদিস খোলে।
- [ ] ফলাফল থেকে ফিরলে কার্ডের সংখ্যা নতুন দেখা হাদিস মিলিয়ে বাড়ে।
- [ ] ডাউনলোড করা বইয়ের হাদিস দেখে বিমান মোডে কার্ড থেকে শুরু → চলে।
- [ ] কখনো ডাউনলোড না করা, আর ৩০ দিনের ক্যাশে না থাকা হাদিসই শুধু দেখা থাকলে বিমান মোডে শুরু → "প্রশ্ন আনা যায়নি। ইন্টারনেট সংযোগ দেখে আবার চেষ্টা করুন।" আর "আবার চেষ্টা করুন"। নেট চালু করে চাপলে চলে। (সাধারণত ক্যাশ থাকে বলে এটা পেতে অ্যাপ ডেটা মুছে শুধু অনলাইনে দুটো হাদিস দেখে নিন।)
- [ ] অ্যাপের ভাষা English → অর্থ ইংরেজিতে, "Word quiz", "Words from …"। বাংলায় দেখা হাদিস ইংরেজির কার্ডে গোনা হয় না (ভাষা আলাদা)।
- [ ] উর্দু (RTL): কার্ড, প্রশ্ন, প্যানেল, ফলাফল ঠিক দিকে। অপশন ব্যাজ উর্দুর অক্ষরে।
- [ ] অ্যাপের ভাষা আরবি → শব্দে শব্দে নেই, বাটনও নেই।
- [ ] ডার্ক মোড: বাটন, কার্ড, আরবি শব্দ, প্যানেল পড়া যায়।
- [ ] ট্যাবলেট (পোর্ট্রেট/ল্যান্ডস্কেপ): কুইজ পেজ মাঝখানে, চওড়া ৬০০-এর বেশি না। ডিটেইলসে বাটন কার্ডের ভেতরে ঠিক বসে।
- [ ] খুব লম্বা শব্দ (কয়েক শব্দের বাক্যাংশ) → আরবি ভেঙে দুই লাইনে যায়, কাটে না।

## অ্যানালিটিক্স (DebugView)
- কুইজ পেজ খুললে `screen_view{screen_name: word_quiz}`।
- হাদিস পেজের বাটন → `word_quiz_start{scope: hadith, source: start, question_count, book_slug, hadith_id}`।
- কার্ডের "কুইজ শুরু করুন" → `word_quiz_load{status: loaded / failed, word_count, hadith_count}`; `loaded` হলে তারপর `word_quiz_start{scope: seen_words, source: start, question_count}`। "আবার চেষ্টা করুন" চাপলে আবার `word_quiz_load`।
- উত্তর আর স্কিপে কোনো ইভেন্ট নেই। শেষে `word_quiz_complete{scope, source, question_count, correct_count, skipped_count, score, duration_sec}`; মাঝপথে বের হলে কিছু নেই।
- প্র্যাকটিস → `word_quiz_start{source: practice}`, আবার শুরু → `source: play_again`।
- "হাদিসের সূত্র" → `word_quiz_reference_open{scope, book_slug, hadith_id}`, তারপর `screen_view{hadith_details}`।
- মিলিয়ে দেখুন: `docs/analytics/09_DEBUGVIEW_CHECKLIST.md`-এর "শব্দের কুইজ" সেকশন।

## জানা সীমাবদ্ধতা
- "শেখা শব্দ" এখন মানে: হাদিস ডিটেইলস পেজে যে হাদিসের "শব্দে শব্দে" খোলা হয়েছে, তার সব অর্থসহ শব্দ। রিডারের তালিকায় দেখা বা শব্দে ট্যাপ গোনা হয় না। টিম ঠিক করলে বদলাতে হবে।
- ভাষাপ্রতি সর্বশেষ ৪০টা হাদিস মনে রাখে। প্রতিবার কুইজ শুরুর সময় সেগুলোর শব্দ আবার পড়ে (ডাউনলোড করা বই বা API ক্যাশ), তাই অনেক হাদিস অনলাইনে থাকলে প্রথমবার একটু সময় লাগতে পারে।
- ভুল অপশন অন্য শব্দের আসল অর্থ, তবে মানে কাছাকাছি (প্রায় সমার্থক) অর্থও আসতে পারে। ডেটা "পরীক্ষামূলক", আলেমদের যাচাই এখনো বাকি।
- রাউন্ড থামানো বা পরে চালানো যায় না, হাদিস কুইজের অগ্রগতি বা সেরা স্কোরে যোগ হয় না। ফলাফল শেয়ারের বাটন নেই।
- রেফারেন্স খুললে ডেমোর মতো শব্দটা হাইলাইট হয় না।
- কার্ডের আরবি শব্দ KFGQ ফন্টে, সেটিংসের আরবি ফন্টে নয় (প্রশ্নের শব্দ সেটিংসের ফন্টে)।
- "নতুন" ব্যাজ সবসময় থাকে, কখন সরবে ঠিক হয়নি।
- এখনো কোনো ফোন বা সিমুলেটরে চালানো হয়নি।
